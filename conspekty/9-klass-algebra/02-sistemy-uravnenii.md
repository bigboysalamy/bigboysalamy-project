Перед каждой карточкой вставляй блок СТИЛЬ из `00-shablon-stilya.md`. Названия тем — как на yaklass.ru.

## Тема 2.1. Основные понятия

### Карточка 1 из 4 — «Уравнение с двумя переменными»
ЗАГОЛОВОК: ОСНОВНЫЕ ПОНЯТИЯ / УРАВНЕНИЕ С ДВУМЯ ПЕРЕМЕННЫМИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Уравнение с двумя переменными x и y — равенство вида f(x;y)=0, содержащее две неизвестные.
- Решение такого уравнения — пара чисел (x;y), при подстановке которой равенство становится верным.

Иллюстрация: уравнение 2x+y=7 и рядом несколько пар-решений (1;5), (3;1), показанных как точки.

### Карточка 2 из 4 — «Система уравнений и её решение»
ЗАГОЛОВОК: ОСНОВНЫЕ ПОНЯТИЯ / СИСТЕМА УРАВНЕНИЙ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Система уравнений — несколько уравнений с общими переменными, объединённых фигурной скобкой.
- Решение системы — пара (или набор) значений переменных, обращающая в верное равенство КАЖДОЕ уравнение системы одновременно.

Иллюстрация: фигурная скобка с двумя уравнениями, точка пересечения их графиков как геометрический смысл решения.

### Карточка 3 из 4 — «Равносильные системы»
ЗАГОЛОВОК: ОСНОВНЫЕ ПОНЯТИЯ / РАВНОСИЛЬНЫЕ СИСТЕМЫ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Две системы уравнений называются равносильными, если они имеют одно и то же множество решений (в частности, обе не имеют решений).
- Решение системы методом подстановки или сложения — это цепочка равносильных преобразований к более простой системе.

Врезка «Запомни!»: Равносильные преобразования не должны терять и не должны добавлять посторонние решения.

Иллюстрация: цепочка из 2-3 систем, соединённых знаком «⇔».

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ОСНОВНЫЕ ПОНЯТИЯ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: проверить, является ли пара (2;3) решением системы {x+y=5; 2x−y=1}.
Решение в рамке: 2+3=5 ✓; 2·2−3=1 ✓ ⇒ (2;3) — решение системы.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Решение системы — пара чисел, удовлетворяющая всем уравнениям одновременно.
- Геометрически решение системы двух уравнений — точка пересечения их графиков.
- Равносильные преобразования системы не меняют множество её решений.

## Тема 2.2. Методы решения систем рациональных уравнений

### Карточка 1 из 4 — «Метод подстановки»
ЗАГОЛОВОК: МЕТОДЫ РЕШЕНИЯ СИСТЕМ УРАВНЕНИЙ / МЕТОД ПОДСТАНОВКИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. АЛГОРИТМ (по теории yaklass.ru)
- Выразить одну переменную через другую из более простого уравнения системы.
- Подставить полученное выражение вместо этой переменной в другое уравнение системы.
- Решить полученное уравнение с одной переменной и найти её значение.
- Подставить найденное значение в выражение из первого шага и найти вторую переменную.

Иллюстрация: система {y=2x−1; 3x+y=9}, стрелкой показана подстановка (2x−1) вместо y во второе уравнение.

### Карточка 2 из 4 — «Метод алгебраического сложения»
ЗАГОЛОВОК: МЕТОДЫ РЕШЕНИЯ СИСТЕМ УРАВНЕНИЙ / МЕТОД АЛГЕБРАИЧЕСКОГО СЛОЖЕНИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. АЛГОРИТМ (по теории yaklass.ru)
- Уравнять модули коэффициентов при одной из переменных (умножив одно или оба уравнения на подходящие числа).
- Сложить или вычесть уравнения так, чтобы эта переменная исчезла.
- Решить полученное уравнение с одной переменной.
- Подставить найденный корень в одно из исходных уравнений, найти вторую переменную, записать ответ парой значений.

Иллюстрация: два уравнения системы, коэффициенты при y выделены одинаковым цветом, знак «+» между уравнениями, y сокращается.

### Карточка 3 из 4 — «Решение систем уравнений второй степени»
ЗАГОЛОВОК: МЕТОДЫ РЕШЕНИЯ СИСТЕМ УРАВНЕНИЙ / СИСТЕМЫ С УРАВНЕНИЕМ ВТОРОЙ СТЕПЕНИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОСОБЕННОСТЬ
- Если система содержит уравнение второй степени (например, xy=c или x²+y²=c), обычно применяют метод подстановки: выражают одну переменную из линейного уравнения и подставляют в квадратное.
- Такая подстановка может дать квадратное уравнение с двумя корнями — значит, у системы может быть до двух пар решений.

Пример: {x+y=5; xy=6} ⇒ y=5−x ⇒ x(5−x)=6 ⇒ x²−5x+6=0 ⇒ x=2 или x=3.

Иллюстрация: система с двумя парами решений (2;3) и (3;2), отмеченными как две точки пересечения прямой и гиперболы.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: МЕТОДЫ РЕШЕНИЯ СИСТЕМ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: решить систему {2x+y=7; x−y=2} методом сложения.
Решение в рамке: складываем уравнения: 3x=9 ⇒ x=3; из второго: y=x−2=1. Ответ: (3;1).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Метод подстановки удобен, когда одну переменную легко выразить.
- Метод сложения удобен, когда коэффициенты при переменной легко уравнять.
- Для систем с уравнением второй степени решение через подстановку может дать несколько пар ответов.

## Тема 2.3. Использование систем рациональных уравнений для решения задач

### Карточка 1 из 4 — «Алгоритм составления системы по условию задачи»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ СИСТЕМ УРАВНЕНИЙ / АЛГОРИТМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Обозначить две неизвестные величины буквами x и y.
- Составить два уравнения, отражающие два независимых условия задачи.
- Решить полученную систему одним из изученных методов и проверить ответ по смыслу задачи.

Иллюстрация: схема из 3 шагов со стрелками — «обозначить x, y» → «составить систему» → «решить и проверить».

### Карточка 2 из 4 — «Задачи на движение»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ СИСТЕМ УРАВНЕНИЙ / ЗАДАЧИ НА ДВИЖЕНИЕ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: скорость катера по течению 24 км/ч, против течения — 16 км/ч. Найти скорость катера в неподвижной воде и скорость течения.
Решение в рамке: пусть x — скорость катера, y — течения: {x+y=24; x−y=16} ⇒ сложив: 2x=40 ⇒ x=20, y=4.

Иллюстрация: река со стрелкой течения, катер, идущий по течению и против, скорости подписаны.

### Карточка 3 из 4 — «Задачи на совместную работу и на числа»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ СИСТЕМ УРАВНЕНИЙ / ДРУГИЕ ТИПЫ ЗАДАЧ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРИМЕР (задача на числа)
Условие: сумма двух чисел равна 17, а их произведение равно 60. Найти числа.
Решение в рамке: {x+y=17; xy=60} ⇒ y=17−x ⇒ x(17−x)=60 ⇒ x²−17x+60=0 ⇒ x=5 или x=12. Числа: 5 и 12.

Иллюстрация: две неизвестные величины, представленные как отрезки разной длины, сумма и произведение которых заданы.

### Карточка 4 из 4 — «Итог темы и главы»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ СИСТЕМ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: периметр прямоугольника 26 см, площадь 40 см². Найти стороны.
Решение в рамке: {2(x+y)=26; xy=40} ⇒ x+y=13, y=13−x ⇒ x(13−x)=40 ⇒ x²−13x+40=0 ⇒ x=5 или x=8. Стороны: 5 см и 8 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 2)
- Систему уравнений составляют из двух независимых условий задачи.
- Методы подстановки и сложения — основные инструменты для решения систем.
- Системы, содержащие произведение переменных, часто сводятся к квадратному уравнению с двумя корнями.
