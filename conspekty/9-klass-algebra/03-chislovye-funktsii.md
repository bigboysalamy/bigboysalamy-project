## Тема 3.1. Определение числовой функции и способы её задания

### Карточка 1 из 4 — «Определение числовой функции»
ЗАГОЛОВОК: ЧИСЛОВАЯ ФУНКЦИЯ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (по теории yaklass.ru)
- Если каждому числу x множества X по правилу f поставлено в соответствие единственное число y, то говорят, что задана функция y=f(x) на области определения X.
- x называют независимой переменной (аргументом), y — зависимой переменной (значением функции).

Иллюстрация: схема «чёрного ящика» — стрелка x входит в блок f, стрелка y выходит из него.

### Карточка 2 из 4 — «Область определения и область значений»
ЗАГОЛОВОК: ЧИСЛОВАЯ ФУНКЦИЯ / ОБЛАСТЬ ОПРЕДЕЛЕНИЯ И ЗНАЧЕНИЙ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ (по теории yaklass.ru)
- Областью определения функции y=f(x) называют множество всех значений x, для которых функция имеет смысл; обозначают D(f).
- Множеством значений функции y=f(x), x∈X, называют множество всех значений y; обозначают E(f).

Иллюстрация: график функции с выделенным на оси Ox отрезком (область определения) и на оси Oy отрезком (область значений).

### Карточка 3 из 4 — «Способы задания функции»
ЗАГОЛОВОК: ЧИСЛОВАЯ ФУНКЦИЯ / СПОСОБЫ ЗАДАНИЯ. Индикатор: 3 из 4.

КОНТЕНТ:
1. СПОСОБЫ
- Аналитический — формулой: y=f(x).
- Табличный — таблицей пар значений x и y.
- Графический — графиком на координатной плоскости.
- Словесный — описанием правила словами.

Иллюстрация: четыре мини-блока, показывающие одну и ту же функцию четырьмя способами (формула, таблица, график, текст).

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ЧИСЛОВАЯ ФУНКЦИЯ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: найти область определения функции y = 1/(x−3).
Решение в рамке: знаменатель не может быть равен 0 ⇒ x≠3 ⇒ D(f) = (−∞;3)∪(3;+∞).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Каждому x из области определения соответствует ровно одно значение y.
- D(f) — множество допустимых x, E(f) — множество всех получаемых y.
- Функцию можно задать формулой, таблицей, графиком или словесно.

## Тема 3.2. Свойства функций

### Карточка 1 из 4 — «Возрастание и убывание функции»
ЗАГОЛОВОК: СВОЙСТВА ФУНКЦИЙ / ВОЗРАСТАНИЕ И УБЫВАНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ
- Функция возрастает на промежутке, если большему значению x соответствует большее значение y.
- Функция убывает на промежутке, если большему значению x соответствует меньшее значение y.

Иллюстрация: график с одним участком, идущим вверх слева направо (подписан «возрастает»), и другим, идущим вниз (подписан «убывает»).

### Карточка 2 из 4 — «Чётность и нечётность функции»
ЗАГОЛОВОК: СВОЙСТВА ФУНКЦИЙ / ЧЁТНОСТЬ И НЕЧЁТНОСТЬ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ
Формула в рамке: функция чётная, если f(−x)=f(x) для всех x из области определения (график симметричен относительно оси Oy).
Формула в рамке: функция нечётная, если f(−x)=−f(x) (график симметричен относительно начала координат).

Иллюстрация: два графика рядом — симметричный относительно оси Oy (чётная функция) и симметричный относительно точки O (нечётная функция).

### Карточка 3 из 4 — «Наибольшее и наименьшее значения функции, нули функции»
ЗАГОЛОВОК: СВОЙСТВА ФУНКЦИЙ / НАИБОЛЬШЕЕ, НАИМЕНЬШЕЕ ЗНАЧЕНИЯ И НУЛИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ
- Нуль функции — значение x, при котором y=f(x)=0 (точка пересечения графика с осью Ox).
- Наибольшее (наименьшее) значение функции — самое большое (маленькое) значение y на всей области определения или на заданном промежутке.

Иллюстрация: график параболы с отмеченной вершиной (наименьшее значение) и двумя точками пересечения с осью Ox (нули функции).

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СВОЙСТВА ФУНКЦИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: является ли функция f(x)=x² чётной, нечётной или ни той, ни другой?
Решение в рамке: f(−x)=(−x)²=x²=f(x) ⇒ функция чётная.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Возрастание/убывание описывают направление изменения y при увеличении x.
- f(−x)=f(x) — чётная (симметрия по Oy), f(−x)=−f(x) — нечётная (симметрия по O).
- Нули функции — точки пересечения графика с осью Ox.

## Тема 3.3. Степенная функция с натуральным показателем

### Карточка 1 из 4 — «Определение степенной функции»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С НАТУРАЛЬНЫМ ПОКАЗАТЕЛЕМ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (по теории yaklass.ru)
- Функции вида y=xⁿ, где n=1,2,3,4,5..., называются степенными функциями с натуральным показателем.
- Область определения такой функции — все действительные числа.

Иллюстрация: ряд графиков y=x, y=x², y=x³, y=x⁴ на одной координатной плоскости разными цветами.

### Карточка 2 из 4 — «Чётный показатель»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С НАТУРАЛЬНЫМ ПОКАЗАТЕЛЕМ / ЧЁТНЫЙ ПОКАЗАТЕЛЬ. Индикатор: 2 из 4.

КОНТЕНТ:
1. СВОЙСТВА y=x²ⁿ (по теории yaklass.ru)
- График проходит через начало координат; при x≠0 y>0; график расположен в I и II четвертях.
- Область определения — все числа; область значений — y≥0.
- Функция чётная: x²ⁿ=(−x)²ⁿ.
- Убывает при x<0, возрастает при x>0.

Иллюстрация: график y=x⁴, симметричный относительно оси Oy, с минимумом в точке (0;0), напоминающий по форме «котёл» (по описанию yaklass.ru).

### Карточка 3 из 4 — «Нечётный показатель»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С НАТУРАЛЬНЫМ ПОКАЗАТЕЛЕМ / НЕЧЁТНЫЙ ПОКАЗАТЕЛЬ. Индикатор: 3 из 4.

КОНТЕНТ:
1. СВОЙСТВА y=x²ⁿ⁻¹ (по теории yaklass.ru)
- График проходит через начало координат; при x>0 y>0, при x<0 y<0.
- Функция нечётная, возрастает на всей области определения.
- Чем больше показатель степени, тем круче ветви графика.

Иллюстрация: график y=x³, симметричный относительно начала координат, возрастающий на всей числовой прямой.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С НАТУРАЛЬНЫМ ПОКАЗАТЕЛЕМ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: сравнить значения функции y=x⁵ в точках x=−2 и x=2.
Решение в рамке: функция нечётная и возрастающая ⇒ (−2)⁵=−32 < 2⁵=32.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Чётный показатель ⇒ график симметричен по Oy, y≥0.
- Нечётный показатель ⇒ график симметричен по O, функция возрастает всюду.
- Обе группы графиков проходят через начало координат (0;0).

## Тема 3.4. Степенная функция с отрицательным целым показателем

### Карточка 1 из 4 — «Определение и область определения»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С ОТРИЦАТЕЛЬНЫМ ЦЕЛЫМ ПОКАЗАТЕЛЕМ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (по теории yaklass.ru)
Формула в рамке: степенная функция с целым отрицательным показателем имеет вид y=x⁻ⁿ=1/xⁿ.
- Область определения — все числа, кроме x=0 (на 0 делить нельзя).

Иллюстрация: функция y=1/x², с выколотой точкой на оси Ox при x=0.

### Карточка 2 из 4 — «Асимптоты и гипербола»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С ОТРИЦАТЕЛЬНЫМ ЦЕЛЫМ ПОКАЗАТЕЛЕМ / АСИМПТОТЫ. Индикатор: 2 из 4.

КОНТЕНТ:
1. СВОЙСТВА (по теории yaklass.ru)
- График асимптотически приближается к обеим осям координат: ось Ox — горизонтальная асимптота.
- Графики функций y=x⁻ⁿ называют степенными гиперболами; частный случай y=x⁻¹=1/x — обычная гипербола.
- Чем больше показатель степени n, тем быстрее график стремится к осям.

Иллюстрация: график y=1/x (классическая гипербола в I и III четвертях), рядом график y=1/x² (в I и II четвертях), обе оси подписаны как асимптоты.

### Карточка 3 из 4 — «Чётный и нечётный отрицательный показатель»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С ОТРИЦАТЕЛЬНЫМ ЦЕЛЫМ ПОКАЗАТЕЛЕМ / ЧЁТНЫЙ И НЕЧЁТНЫЙ СЛУЧАИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ДВА ВИДА ГРАФИКОВ (по теории yaklass.ru)
- Функции вида y=1/x²ⁿ — чётные, график расположен в I и II четвертях (y всегда положителен).
- Функции вида y=1/x²ⁿ⁺¹ — нечётные, график расположен в I и III четвертях.

Иллюстрация: два графика рядом — y=1/x² (в верхней полуплоскости) и y=1/x³ (в I и III четвертях), с подписанной чётностью/нечётностью.

### Карточка 4 из 4 — «Итог темы и главы»
ЗАГОЛОВОК: СТЕПЕННАЯ ФУНКЦИЯ С ОТРИЦАТЕЛЬНЫМ ЦЕЛЫМ ПОКАЗАТЕЛЕМ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: найти область определения функции y = 1/x³ и определить, чётная она или нечётная.
Решение в рамке: D(f): x≠0; f(−x)=1/(−x)³=−1/x³=−f(x) ⇒ функция нечётная.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 3)
- y=x⁻ⁿ=1/xⁿ никогда не определена в точке x=0.
- Оси координат — асимптоты графика такой функции («степенной гиперболы»).
- Чётность/нечётность показателя n определяет расположение графика по четвертям, как и для положительных степеней.
