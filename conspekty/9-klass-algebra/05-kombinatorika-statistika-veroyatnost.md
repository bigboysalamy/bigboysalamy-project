## Тема 5.1. Элементы комбинаторики. Комбинаторные задачи

### Карточка 1 из 4 — «Понятие комбинаторики»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ КОМБИНАТОРИКИ / ПОНЯТИЕ КОМБИНАТОРИКИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Комбинаторика — раздел математики, изучающий способы подсчёта числа возможных вариантов (комбинаций) объектов при заданных условиях.
- Комбинаторная задача — задача, в которой нужно найти количество способов выбора, расположения или сочетания объектов.

Иллюстрация: несколько разноцветных фишек и стрелки, показывающие разные способы их расположения в ряд.

### Карточка 2 из 4 — «Правило произведения»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ КОМБИНАТОРИКИ / ПРАВИЛО ПРОИЗВЕДЕНИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО (по теории yaklass.ru)
- Если объект A можно выбрать m способами, и после каждого такого выбора объект B можно выбрать n способами, то пару (A;B) в указанном порядке можно выбрать m·n способами.

Пример: 3 футболки и 4 пары брюк ⇒ 3·4=12 вариантов одежды.

Иллюстрация: дерево вариантов — 3 ветви от корня (футболки), от каждой ещё по 4 ветви (брюки), всего 12 конечных точек.

### Карточка 3 из 4 — «Правило суммы»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ КОМБИНАТОРИКИ / ПРАВИЛО СУММЫ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Если объект A можно выбрать m способами, а объект B — n способами, причём эти способы не пересекаются (нельзя выбрать одновременно и то, и другое), то выбор «A или B» можно осуществить m+n способами.

Пример: в шкафу 5 книг по математике и 3 книги по физике — выбрать одну книгу можно 5+3=8 способами.

Иллюстрация: две отдельные группы предметов (книги по математике и по физике), объединённые фигурной скобкой «или», с суммой под ней.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ КОМБИНАТОРИКИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: сколько трёхзначных чисел можно составить из цифр 1, 2, 3, 4, если цифры могут повторяться?
Решение в рамке: по правилу произведения: 4 варианта для каждой из 3 позиций ⇒ 4·4·4=64.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Правило произведения — для последовательного независимого выбора нескольких объектов (используют «И»).
- Правило суммы — для выбора одного объекта из непересекающихся групп (используют «ИЛИ»).
- Комбинаторика — основа для вычисления вероятностей событий.

## Тема 5.2. Элементы теории вероятности. Нахождение вероятности

### Карточка 1 из 4 — «Случайное событие и элементарные исходы»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ ТЕОРИИ ВЕРОЯТНОСТИ / СЛУЧАЙНОЕ СОБЫТИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОСНОВНЫЕ ПОНЯТИЯ
- Испытание — действие с неопределённым заранее результатом (бросок кубика, вытягивание карты).
- Элементарный исход — один из возможных результатов испытания.
- Событие — совокупность некоторых элементарных исходов.

Иллюстрация: игральный кубик с 6 гранями, каждая грань — отдельный элементарный исход, несколько граней закрашены как «событие: выпало чётное число».

### Карточка 2 из 4 — «Классическое определение вероятности»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ ТЕОРИИ ВЕРОЯТНОСТИ / КЛАССИЧЕСКОЕ ОПРЕДЕЛЕНИЕ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА (по теории yaklass.ru)
Формула в рамке: P(A) = m/n, где n — число всех равновозможных элементарных исходов испытания, m — число исходов, благоприятствующих событию A.

Врезка «Важно!»: Формула применима только тогда, когда все элементарные исходы равновозможны.

Иллюстрация: кубик с 6 гранями (n=6), 3 из них закрашены как благоприятные для события «выпало чётное число» (m=3), рядом P=3/6=1/2.

### Карточка 3 из 4 — «Свойства вероятности»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ ТЕОРИИ ВЕРОЯТНОСТИ / СВОЙСТВА ВЕРОЯТНОСТИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. СВОЙСТВА
- Вероятность любого события заключена между 0 и 1: 0 ≤ P(A) ≤ 1.
- Вероятность достоверного события (происходит всегда) равна 1.
- Вероятность невозможного события равна 0.

Иллюстрация: числовая шкала от 0 до 1 с отмеченными точками «невозможное событие» (0), «маловероятное», «равновероятное» (0,5), «наиболее вероятное», «достоверное» (1).

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ ТЕОРИИ ВЕРОЯТНОСТИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: в коробке 4 красных и 6 синих шаров. Найти вероятность того, что наугад вынутый шар окажется красным.
Решение в рамке: n=10 (всего шаров), m=4 (красных) ⇒ P=4/10=0,4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- P(A)=m/n — отношение благоприятных исходов к общему числу равновозможных исходов.
- 0 ≤ P(A) ≤ 1 для любого события.
- Число благоприятных и общее число исходов часто находят с помощью правил комбинаторики.

## Тема 5.3. Элементы статистики. Методы обработки информации

### Карточка 1 из 4 — «Статистические данные и их представление»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ СТАТИСТИКИ / ПРЕДСТАВЛЕНИЕ ДАННЫХ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОСНОВНЫЕ ПОНЯТИЯ
- Статистика — наука о сборе, обработке и анализе числовых данных.
- Данные удобно представлять в виде таблиц частот, столбчатых и круговых диаграмм, полигонов частот.

Иллюстрация: набор чисел, преобразованный в столбчатую диаграмму с подписанными частотами.

### Карточка 2 из 4 — «Среднее арифметическое, мода и медиана»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ СТАТИСТИКИ / СРЕДНЕЕ, МОДА И МЕДИАНА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ
- Среднее арифметическое — сумма всех значений, делённая на их количество.
- Мода — значение, встречающееся в наборе данных чаще всего.
- Медиана — значение, которое делит упорядоченный по возрастанию ряд данных пополам.

Пример: набор 2,3,3,5,7 — среднее=(2+3+3+5+7)/5=4; мода=3; медиана=3 (средний элемент).

Иллюстрация: упорядоченный ряд чисел с отмеченным средним элементом (медиана) и наиболее часто повторяющимся числом (мода).

### Карточка 3 из 4 — «Размах и отклонение данных»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ СТАТИСТИКИ / РАЗМАХ ДАННЫХ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
Формула в рамке: размах ряда данных — разность между наибольшим и наименьшим значениями ряда.
- Размах и другие показатели разброса используют, чтобы понять, насколько сильно данные различаются между собой, а не только их «среднее».

Пример: ряд 12, 15, 9, 20, 11 — размах=20−9=11.

Иллюстрация: числовая прямая с отмеченными минимальным и максимальным значениями ряда данных, между ними — фигурная скобка «размах».

### Карточка 4 из 4 — «Итог темы и главы»
ЗАГОЛОВОК: ЭЛЕМЕНТЫ СТАТИСТИКИ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: результаты контрольной работы (баллы): 3,4,4,5,5,5,2. Найти среднее арифметическое, моду и медиану.
Решение в рамке: сумма=28, среднее=28/7=4; мода=5 (встречается 3 раза); упорядоченный ряд 2,3,4,4,5,5,5 — медиана=4 (средний, 4-й элемент).
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 5)
- Правила произведения и суммы — база для подсчёта числа исходов в комбинаторике.
- P(A)=m/n — классическая вероятность события.
- Среднее, мода, медиана и размах — основные числовые характеристики набора статистических данных.
