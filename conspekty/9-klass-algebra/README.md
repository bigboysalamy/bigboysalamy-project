# Конспекты по алгебре, 9 класс

Промпты для генерации карточек-конспектов через ChatGPT (image generation) —
формат такой же, как для остальных конспектов, серия — **4 карточки на тему**.

Главы, темы и теоретическое содержание взяты из реальной структуры курса
**yaklass.ru → Алгебра → 9 класс** (раздел «Теория» под каждым уроком).
Прямой доступ к сайту у меня заблокирован (403 для автоматических запросов),
поэтому структура и формулировки восстановлены через поиск по
проиндексированным страницам сайта — при использовании сверяй формулировки
с оригиналом урока на yaklass.ru, если нужна дословная точность.

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Для каждой карточки вставь СТИЛЬ + КОНТЕНТ карточки одним сообщением в ChatGPT.
3. Указывай номер карточки в серии (X из 4).

## Содержание (главы по программе 9 класса, yaklass.ru)

- `01-neravenstva-i-sistemy-neravenstv.md` — Неравенства и системы неравенств (4 темы × 4 карточки = 16)
- `02-sistemy-uravnenii.md` — Системы уравнений. Равносильные преобразования (3 темы × 4 карточки = 12)
- `03-chislovye-funktsii.md` — Числовые функции. Свойства числовых функций (4 темы × 4 карточки = 16)
- `04-progressii.md` — Прогрессии (3 темы × 4 карточки = 12)
- `05-kombinatorika-statistika-veroyatnost.md` — Элементы комбинаторики, статистики и теории вероятностей (3 темы × 4 карточки = 12)

Итого: 17 тем, 68 карточек-промптов.
