# СТИЛЬ (вставлять перед каждым промптом-карточкой)

Тот же базовый шаблон, что и для остальных конспектов — приведён здесь ещё раз для самостоятельного использования. Серия — 4 карточки на тему.

```
Создай инфографику-конспект для подготовки школьника к уроку алгебры,
в формате вертикальной карточки A4, как обучающий плакат.

ОБЩИЙ СТИЛЬ:
— Белый фон, тонкая пунктирная рамка по периметру.
— Заголовок крупным жирным шрифтом тёмно-серым/чёрным цветом в две строки:
  первая строка — название большой темы заглавными буквами, вторая строка —
  название конкретной подтемы этой карточки, заглавными буквами, синим цветом (#1a3aab).
— Под заголовком — горизонтальный индикатор страниц: 4 кружка в ряд,
  один из них закрашен синим (текущая карточка), остальные — пустые контуры.
— Контент разбит на пронумерованные блоки-секции (1., 2., 3., 4...), каждый блок
  имеет заголовок капсом со значком (ромб ♦ синего цвета) и пунктирную линию-разделитель снизу.
— Внутри блоков — списки с маркерами-ромбиками, формулы и числовые примеры выделены
  в отдельные прямоугольники со скруглёнными углами и светло-голубой заливкой.
— Врезки-подсказки (где уместно) — прямоугольник со скруглёнными углами,
  светло-серая/светло-голубая заливка, синяя иконка восклицательного знака
  в кружке слева, заголовок врезки жирным («Важно!», «Запомни!», «Алгоритм!»).
— Справа или внизу — аккуратная иллюстрация по теме карточки: график функции,
  числовая прямая с методом интервалов, схема прогрессии, диаграмма — в зависимости
  от темы; подписи цифрами и буквами, разные цвета для наглядности.
— Внизу карточки (обычно на 4-й) — горизонтальный блок «ЧТО НУЖНО ЗАПОМНИТЬ»
  с иконкой мозга слева и 2–4 короткими тезисами-выводами с ромбовидными маркерами.
  На 1–3 карточках вместо этого блока — обычные тематические блоки.
— Палитра: тёмно-синий, голубой, серый текст, акцентные цвета иллюстрации —
  малиновый/зелёный/оранжевый (как в учебных плакатах), много воздуха, не перегружать.
— Весь текст — на русском языке, без ошибок в математических обозначениях.

ДАЛЕЕ — СОДЕРЖАНИЕ ЭТОЙ КОНКРЕТНОЙ КАРТОЧКИ:
```

После этого блока вставляй текст из поля «КОНТЕНТ» нужной карточки (см. файлы глав).
