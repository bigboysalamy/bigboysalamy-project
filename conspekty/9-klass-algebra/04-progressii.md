## Тема 4.1. Числовые последовательности

### Карточка 1 из 4 — «Понятие последовательности»
ЗАГОЛОВОК: ЧИСЛОВЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ / ПОНЯТИЕ ПОСЛЕДОВАТЕЛЬНОСТИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Числовая последовательность — функция, заданная на множестве натуральных чисел: каждому номеру n соответствует число aₙ, называемое n-м членом последовательности.
- Записывают: a₁, a₂, a₃, ..., aₙ, ... или (aₙ).

Иллюстрация: ряд пронумерованных точек a₁, a₂, a₃, a₄... на числовой прямой или в виде подписанных карточек по порядку.

### Карточка 2 из 4 — «Способы задания последовательности»
ЗАГОЛОВОК: ЧИСЛОВЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ / СПОСОБЫ ЗАДАНИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. СПОСОБЫ
- Формула n-го члена: aₙ выражается напрямую через номер n (например aₙ=2n−1).
- Рекуррентная формула: каждый следующий член выражается через предыдущий (например a₁=1, aₙ₊₁=aₙ+3).

Иллюстрация: два примера рядом — таблица значений по формуле n-го члена и цепочка стрелок «a₁→a₂→a₃» для рекуррентного способа.

### Карточка 3 из 4 — «Ограниченные, возрастающие и убывающие последовательности»
ЗАГОЛОВОК: ЧИСЛОВЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ / ВИДЫ ПОСЛЕДОВАТЕЛЬНОСТЕЙ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ
- Последовательность возрастающая, если каждый следующий член больше предыдущего: aₙ₊₁>aₙ.
- Последовательность убывающая, если каждый следующий член меньше предыдущего: aₙ₊₁<aₙ.
- Последовательность ограничена, если все её члены заключены между какими-то двумя числами.

Иллюстрация: три графика-точки на координатной плоскости (номер n по горизонтали, значение aₙ по вертикали) — возрастающая, убывающая, ограниченная последовательности.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ЧИСЛОВЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: последовательность задана формулой aₙ=3n−2. Найти первые три члена.
Решение в рамке: a₁=3·1−2=1; a₂=3·2−2=4; a₃=3·3−2=7.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- aₙ — значение последовательности при номере n.
- Последовательность можно задать формулой n-го члена или рекуррентно.
- Прогрессии (следующие темы) — частные виды последовательностей с особым правилом перехода к следующему члену.

## Тема 4.2. Арифметическая прогрессия. Свойства арифметической прогрессии

### Карточка 1 из 4 — «Определение и разность прогрессии»
ЗАГОЛОВОК: АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (по теории yaklass.ru)
- Арифметическая прогрессия — последовательность, каждый член которой, начиная со второго, равен предыдущему, к которому прибавляется одно и то же число d.
- Число d называется разностью прогрессии: d = aₙ − aₙ₋₁ (одинаково для всех n).

Пример: 2, 5, 8, 11, ... — d=3.

Иллюстрация: числовая прямая с равноотстоящими точками 2, 5, 8, 11, расстояние между соседними подписано как d=3.

### Карточка 2 из 4 — «Формула n-го члена»
ЗАГОЛОВОК: АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ / ФОРМУЛА N-ГО ЧЛЕНА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА (по теории yaklass.ru)
Формула в рамке: aₙ = a₁ + d(n−1), где a₁ — первый член, d — разность, n — номер члена.

Пример: a₁=4, d=3 ⇒ a₁₀=4+3·9=31.

Иллюстрация: формула с подписанными a₁, d, n и результатом на числовой прямой, отмеченной точкой a₁₀.

### Карточка 3 из 4 — «Свойство арифметической прогрессии и формула суммы»
ЗАГОЛОВОК: АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ / СВОЙСТВО И СУММА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ХАРАКТЕРИСТИЧЕСКОЕ СВОЙСТВО (по теории yaklass.ru)
- Каждый член арифметической прогрессии, начиная со второго, равен среднему арифметическому соседних с ним членов: aₙ=(aₙ₋₁+aₙ₊₁)/2.
2. ФОРМУЛА СУММЫ n ПЕРВЫХ ЧЛЕНОВ
Формула в рамке: Sₙ = (n/2)·(a₁+aₙ).

Иллюстрация: три последовательных члена прогрессии на числовой прямой, средний из них равноудалён от соседних; рядом формула суммы.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: a₁=3, d=4. Найти сумму первых 10 членов.
Решение в рамке: a₁₀=3+4·9=39; S₁₀=(10/2)·(3+39)=5·42=210.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- d — постоянная разность между соседними членами.
- aₙ=a₁+d(n−1) — формула n-го члена.
- Sₙ=(n/2)·(a₁+aₙ) — формула суммы n первых членов.

## Тема 4.3. Геометрическая прогрессия. Свойства геометрической прогрессии

### Карточка 1 из 4 — «Определение и знаменатель прогрессии»
ЗАГОЛОВОК: ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (по теории yaklass.ru)
- Геометрическая прогрессия — последовательность, каждый член которой, начиная со второго, равен предыдущему члену, умноженному на одно и то же число q — знаменатель прогрессии.
- Знаменатель находят делением любого члена на предыдущий: q = bₙ/bₙ₋₁.

Пример: 3, 6, 12, 24, ... — q=2.

Иллюстрация: ряд точек 3, 6, 12, 24 с увеличивающимся расстоянием, стрелками показано умножение на q=2 между соседними.

### Карточка 2 из 4 — «Формула n-го члена»
ЗАГОЛОВОК: ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ / ФОРМУЛА N-ГО ЧЛЕНА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА (по теории yaklass.ru)
Формула в рамке: bₙ = b₁ · qⁿ⁻¹, где b₁ — первый член, q — знаменатель, n — номер члена.

Пример: b₁=2, q=3 ⇒ b₅=2·3⁴=2·81=162.

Иллюстрация: формула с подписанными b₁, q, n и вычислением b₅.

### Карточка 3 из 4 — «Формула суммы и бесконечно убывающая прогрессия»
ЗАГОЛОВОК: ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ / СУММА ЧЛЕНОВ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛА СУММЫ n ПЕРВЫХ ЧЛЕНОВ (по теории yaklass.ru)
Формула в рамке: Sₙ = b₁·(qⁿ−1)/(q−1), при q≠1.
2. БЕСКОНЕЧНО УБЫВАЮЩАЯ ПРОГРЕССИЯ
Формула в рамке: если |q|<1, сумма всех членов бесконечной прогрессии: S = b₁/(1−q).

Иллюстрация: убывающий ряд отрезков (например половина, четверть, восьмая часть) и общая сумма, стремящаяся к целому.

### Карточка 4 из 4 — «Итог темы и главы»
ЗАГОЛОВОК: ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: b₁=1, q=1/2. Найти сумму бесконечно убывающей прогрессии.
Решение в рамке: S = 1/(1−1/2) = 1/(1/2) = 2.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 4)
- q — постоянное отношение между соседними членами.
- bₙ=b₁·qⁿ⁻¹ — формула n-го члена; Sₙ=b₁(qⁿ−1)/(q−1) — сумма n первых членов.
- При |q|<1 существует конечная сумма всех бесконечных членов прогрессии: S=b₁/(1−q).
