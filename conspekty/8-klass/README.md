# Конспекты по геометрии, 8 класс

Промпты для генерации карточек-конспектов через ChatGPT (image generation) —
формат и правила использования такие же, как для 7 класса
(см. `conspekty/7-klass/README.md`). Источник материала: yaklass.ru →
Геометрия, 8 класс, структура совпадает с программой (учебник Атанасяна).

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Для каждой карточки вставь СТИЛЬ + КОНТЕНТ карточки одним сообщением в ChatGPT.
3. Не забывай указывать номер карточки в серии (X из 4).

## Содержание (главы по программе 8 класса)

- `01-chetyrehugolniki.md` — Четырёхугольники (6 тем × 4 карточки = 24)
- `02-ploshchad.md` — Площадь (4 темы × 4 карточки = 16)
- `03-podobnye-treugolniki.md` — Подобные треугольники (5 тем × 4 карточки = 20)
- `04-okruzhnost.md` — Окружность (4 темы × 4 карточки = 16)

Итого: 19 тем, 76 карточек-промптов.
