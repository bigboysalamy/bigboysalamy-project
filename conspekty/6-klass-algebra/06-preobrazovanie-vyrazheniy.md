## Тема 6.1. Упрощение выражений. Раскрытие скобок

### Карточка 1 из 3 — «Раскрытие скобок»
ЗАГОЛОВОК: УПРОЩЕНИЕ ВЫРАЖЕНИЙ / РАСКРЫТИЕ СКОБОК. Индикатор: 1 из 3.

КОНТЕНТ:
1. ПРАВИЛА
Формула в рамке: «+» перед скобками — знаки внутри сохраняются: a+(b−c)=a+b−c.
Формула в рамке: «−» перед скобками — все знаки внутри меняются на противоположные: a−(b−c)=a−b+c.

Врезка «Частая ошибка!»: При раскрытии скобок со знаком «−» меняют знак только у первого слагаемого — это неверно, знак меняется у ВСЕХ слагаемых.

Иллюстрация: выражение 10 − (4 − 7), стрелками показано изменение знаков 4 и 7 на противоположные.

### Карточка 2 из 3 — «Коэффициент и подобные слагаемые»
ЗАГОЛОВОК: УПРОЩЕНИЕ ВЫРАЖЕНИЙ / КОЭФФИЦИЕНТ И ПОДОБНЫЕ СЛАГАЕМЫЕ. Индикатор: 2 из 3.

КОНТЕНТ:
1. КОЭФФИЦИЕНТ
- Числовой множитель перед буквенной частью называется коэффициентом: в 5x коэффициент 5, в −a коэффициент −1.
2. ПОДОБНЫЕ СЛАГАЕМЫЕ
Формула в рамке: слагаемые с одинаковой буквенной частью складывают, складывая их коэффициенты: 3x+5x=(3+5)x=8x.

Иллюстрация: выражение 3x + 5x − 2x с обведёнными коэффициентами, стрелками сходящимися в сумму 6x.

### Карточка 3 из 3 — «Итог темы»
ЗАГОЛОВОК: УПРОЩЕНИЕ ВЫРАЖЕНИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: раскрыть скобки и упростить: 8 − (2x − 5) + (x − 3).
Решение в рамке: 8−2x+5+x−3 = (8+5−3)+(−2x+x) = 10 − x.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- «+» перед скобками не меняет знаки, «−» — меняет все на противоположные.
- Коэффициент — числовой множитель перед буквой.
- Приведение подобных: складываем коэффициенты, буквенную часть не трогаем.

## Тема 6.2. Решение уравнений

### Карточка 1 из 3 — «Понятие уравнения. Перенос слагаемых»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ПОНЯТИЕ И ПЕРЕНОС СЛАГАЕМЫХ. Индикатор: 1 из 3.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Уравнение — равенство с неизвестным числом (буквой). Корень уравнения — значение буквы, при котором равенство верно.
2. ПРАВИЛО ПЕРЕНОСА
Формула в рамке: при переносе слагаемого в другую часть уравнения его знак меняется на противоположный.

Пример: 3x+7=22 ⇒ 3x=22−7 ⇒ 3x=15.

Иллюстрация: уравнение с числом 7, «перепрыгивающим» через знак равенства и меняющим знак с + на −.

### Карточка 2 из 3 — «Деление на коэффициент»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ДЕЛЕНИЕ НА КОЭФФИЦИЕНТ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРАВИЛО
- После переноса слагаемых уравнение приводится к виду a·x=b; чтобы найти x, обе части делят на a.

Пример (продолжение): 3x=15 ⇒ x=15:3=5.

Врезка «Запомни!»: Всегда можно сделать проверку — подставить найденный корень в исходное уравнение.

Иллюстрация: уравнение 3x=15 с обеими частями, делящимися на 3, стрелками показано сокращение до x=5.

### Карточка 3 из 3 — «Итог темы»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: решить уравнение 5x − 3 = 2x + 9.
Решение в рамке: 5x−2x=9+3 ⇒ 3x=12 ⇒ x=4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- При переносе через «=» знак слагаемого меняется на противоположный.
- Уравнение вида ax=b решается делением на a.
- Проверка — подстановка найденного корня в исходное уравнение.

## Тема 6.3. Решение задач с помощью уравнений

### Карточка 1 из 3 — «Алгоритм составления уравнения»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / АЛГОРИТМ. Индикатор: 1 из 3.

КОНТЕНТ:
1. АЛГОРИТМ
- Обозначить неизвестную величину буквой x.
- Выразить через x остальные величины из условия.
- Составить уравнение, используя данное в условии соотношение.

Иллюстрация: схема из 3 шагов со стрелками — «обозначить x» → «выразить через x» → «составить уравнение».

### Карточка 2 из 3 — «Пример: задача на части»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / ЗАДАЧА НА ЧАСТИ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРИМЕР
Условие: в двух пакетах 54 кг картофеля, причём в первом в 2 раза больше, чем во втором. Сколько кг в каждом пакете?
Решение в рамке: пусть во втором x кг, тогда в первом 2x: x+2x=54 ⇒ 3x=54 ⇒ x=18. Значит во втором 18 кг, в первом 36 кг.

Иллюстрация: два пакета с картофелем разного размера, подписанные x и 2x, рядом уравнение и решение.

### Карточка 3 из 3 — «Итог темы и всего курса»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ КУРСА. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: периметр прямоугольника 40 см, длина на 4 см больше ширины. Найти стороны.
Решение в рамке: ширина x, длина x+4: 2(x+x+4)=40 ⇒ 2x+4=20 ⇒ x=8. Ширина 8 см, длина 12 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог курса 6 класса)
- Неизвестную величину удобно обозначать через x, остальные — выражать через неё.
- Курс 6 класса: делимость и НОД/НОК → дроби → отношения/пропорции/проценты → рациональные числа → координаты → уравнения — единый фундамент для алгебры 7 класса.
- Всегда проверяй, отвечает ли найденное число на вопрос задачи.
