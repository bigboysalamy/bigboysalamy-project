## Тема 2.1. Координаты на прямой. Отрицательные числа

### Карточка 1 из 4 — «Зачем нужны отрицательные числа»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / ЗАЧЕМ ОНИ НУЖНЫ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРИМЕРЫ ИЗ ЖИЗНИ
- Температура ниже нуля (−5°C), долг (−100 рублей), глубина ниже уровня моря (−200 м) — все эти величины удобно записывать отрицательными числами.
- Число со знаком «+» (или без знака) называется положительным, со знаком «−» — отрицательным.

Иллюстрация: термометр с делениями от −10 до +10, стрелка на −5°C, рядом схема «глубина/высота» относительно уровня моря.

### Карточка 2 из 4 — «Координатная прямая»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / КООРДИНАТНАЯ ПРЯМАЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Координатная прямая — прямая с выбранным направлением, началом отсчёта (точка O, координата 0) и единичным отрезком.
- Каждой точке прямой соответствует число — её координата.
- Числа справа от 0 — положительные, слева — отрицательные.

Иллюстрация: горизонтальная прямая с делениями от −5 до 5, точка O в нуле, несколько точек с подписанными координатами (A(-3), B(2)).

### Карточка 3 из 4 — «Противоположные числа»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / ПРОТИВОПОЛОЖНЫЕ ЧИСЛА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Числа, отличающиеся только знаком, называются противоположными: 5 и −5, −2,7 и 2,7.
- Число, противоположное числу a, обозначается −a. Число, противоположное нулю, — сам ноль.

Врезка «Запомни!»: На координатной прямой противоположные числа расположены симметрично относительно точки 0.

Иллюстрация: координатная прямая с точками −4 и 4, симметричными относительно 0, соединёнными дугой через точку 0.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: отметить на координатной прямой точки A(-3) и число, противоположное координате точки A.
Решение в рамке: противоположное число к −3 — это 3; отмечаем A(-3) слева от 0 и точку 3 справа, на одинаковом расстоянии от 0.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Отрицательные числа используют для величин «меньше нуля» или «в противоположную сторону».
- На координатной прямой положительные числа — справа от 0, отрицательные — слева.
- Противоположные числа симметричны относительно 0.

## Тема 2.2. Модуль числа

### Карточка 1 из 4 — «Определение модуля»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Модуль числа a (обозначается |a|) — это расстояние от точки с координатой a до точки 0 на координатной прямой.
- Модуль — всегда неотрицательное число: |5| = 5, |−5| = 5, |0| = 0.

Иллюстрация: координатная прямая, точки −5 и 5, от каждой до точки 0 отмечено расстояние 5 одинаковыми фигурными скобками.

### Карточка 2 из 4 — «Модуль положительного и отрицательного числа»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / ПРАВИЛО ВЫЧИСЛЕНИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Модуль положительного числа и нуля равен самому этому числу: |a| = a, если a ≥ 0.
- Модуль отрицательного числа равен противоположному ему числу: |a| = −a, если a < 0.

Врезка «Важно!»: Знак «−» перед a в формуле |a| = −a не означает, что результат отрицательный — он превращает отрицательное a в положительное число.

Иллюстрация: две карточки-примера рядом: |7| = 7 и |−7| = 7, с одинаковым результатом.

### Карточка 3 из 4 — «Свойства модуля»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / СВОЙСТВА. Индикатор: 3 из 4.

КОНТЕНТ:
1. СВОЙСТВА
- Модули противоположных чисел равны: |a| = |−a|.
- Модуль числа никогда не бывает отрицательным: |a| ≥ 0.
- Из двух отрицательных чисел больше то, модуль которого меньше.

Иллюстрация: сравнение −8 и −3 на координатной прямой, стрелками показаны модули |−8|=8 и |−3|=3, вывод «−3 > −8», так как 3<8.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: сравнить |−12| и |9|.
Решение в рамке: |−12| = 12, |9| = 9, 12 > 9 ⇒ |−12| > |9|.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- |a| — расстояние от a до 0, всегда ≥ 0.
- |a| = |−a| — модули противоположных чисел равны.
- Модуль помогает сравнивать отрицательные числа.

## Тема 2.3. Сравнение чисел

### Карточка 1 из 4 — «Сравнение чисел на координатной прямой»
ЗАГОЛОВОК: СРАВНЕНИЕ ЧИСЕЛ / ПРАВИЛО ПО КООРДИНАТНОЙ ПРЯМОЙ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Из двух чисел больше то, которое на координатной прямой расположено правее.
- Любое положительное число больше любого отрицательного числа.
- Ноль больше любого отрицательного числа и меньше любого положительного.

Иллюстрация: координатная прямая с несколькими точками (−4, −1, 0, 2, 5), стрелка направления «увеличение» слева направо.

### Карточка 2 из 4 — «Сравнение двух отрицательных чисел»
ЗАГОЛОВОК: СРАВНЕНИЕ ЧИСЕЛ / ДВА ОТРИЦАТЕЛЬНЫХ ЧИСЛА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: из двух отрицательных чисел больше то, модуль которого меньше.

Пример: сравнить −7 и −2: |−7|=7, |−2|=2, 7>2 ⇒ −7 < −2.

Иллюстрация: координатная прямая, точки −7 и −2, показано, что −2 правее −7, хотя «7» как число больше «2».

### Карточка 3 из 4 — «Частые ошибки при сравнении»
ЗАГОЛОВОК: СРАВНЕНИЕ ЧИСЕЛ / ЧАСТЫЕ ОШИБКИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ЧАСТАЯ ОШИБКА
- Ошибочно думать, что «−10 больше −3», потому что 10 больше 3 — на самом деле всё наоборот: −10 < −3.

Врезка «Запомни!»: Чем «глубже» отрицательное число (чем больше его модуль), тем оно меньше.

Иллюстрация: перечёркнутое неверное сравнение «−10 > −3 ✗» и рядом верное «−10 < −3 ✓» с координатной прямой.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СРАВНЕНИЕ ЧИСЕЛ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: расположить числа −5, 3, −1, 0, −8 в порядке возрастания.
Решение в рамке: −8 < −5 < −1 < 0 < 3.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Правее на координатной прямой — значит больше.
- Любое положительное больше любого отрицательного, 0 — посередине.
- Из двух отрицательных больше то, у которого модуль меньше.

## Тема 2.4. Сложение положительных и отрицательных чисел

### Карточка 1 из 4 — «Сложение чисел с одинаковыми знаками»
ЗАГОЛОВОК: СЛОЖЕНИЕ ЧИСЕЛ / ОДИНАКОВЫЕ ЗНАКИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Чтобы сложить два числа с одинаковыми знаками, нужно сложить их модули и поставить перед суммой общий знак.

Пример: (−3) + (−5) = −(3+5) = −8; 4 + 7 = 11.

Иллюстрация: координатная прямая, два шага влево от 0 (для отрицательных) на 3 и ещё на 5 — итог в точке −8.

### Карточка 2 из 4 — «Сложение чисел с разными знаками»
ЗАГОЛОВОК: СЛОЖЕНИЕ ЧИСЕЛ / РАЗНЫЕ ЗНАКИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Чтобы сложить два числа с разными знаками, нужно из большего модуля вычесть меньший и поставить знак числа с большим модулем.

Пример: (−9) + 4 = −(9−4) = −5, так как |−9| > |4|; (−3) + 8 = +(8−3) = 5.

Иллюстрация: координатная прямая — шаг влево на 9, затем шаг вправо на 4, итоговая точка −5, стрелками показано направление шагов.

### Карточка 3 из 4 — «Сложение с нулём и противоположными числами»
ЗАГОЛОВОК: СЛОЖЕНИЕ ЧИСЕЛ / С НУЛЁМ И ПРОТИВОПОЛОЖНЫМИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ЧАСТНЫЕ СЛУЧАИ
- Сумма противоположных чисел равна нулю: a + (−a) = 0.
- Сложение с нулём не меняет число: a + 0 = a.

Иллюстрация: координатная прямая, точки 6 и −6 соединены дугами, встречающимися в точке 0.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СЛОЖЕНИЕ ЧИСЕЛ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: вычислить (−14) + 20 + (−6).
Решение в рамке: (−14) + 20 = 6; 6 + (−6) = 0.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Одинаковые знаки — складываем модули, знак сохраняем.
- Разные знаки — из большего модуля вычитаем меньший, знак берём от большего модуля.
- Сумма противоположных чисел всегда равна 0.

## Тема 2.5. Вычитание положительных и отрицательных чисел

### Карточка 1 из 4 — «Правило вычитания»
ЗАГОЛОВОК: ВЫЧИТАНИЕ ЧИСЕЛ / ПРАВИЛО. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: чтобы вычесть из одного числа другое, нужно к уменьшаемому прибавить число, противоположное вычитаемому: a − b = a + (−b).

Врезка «Запомни!»: Вычитание всегда можно заменить сложением с противоположным числом.

Иллюстрация: пример 5 − 8 = 5 + (−8) = −3, показанный стрелкой-заменой знака.

### Карточка 2 из 4 — «Вычитание отрицательного числа»
ЗАГОЛОВОК: ВЫЧИТАНИЕ ЧИСЕЛ / ВЫЧИТАНИЕ ОТРИЦАТЕЛЬНОГО. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- При вычитании отрицательного числа два минуса дают плюс: a − (−b) = a + b.

Пример: 5 − (−3) = 5 + 3 = 8; (−4) − (−9) = (−4) + 9 = 5.

Иллюстрация: запись 5 − (−3), два знака минус рядом обведены и соединены со знаком «+».

### Карточка 3 из 4 — «Вычисление длины отрезка на координатной прямой»
ЗАГОЛОВОК: ВЫЧИТАНИЕ ЧИСЕЛ / РАССТОЯНИЕ НА ПРЯМОЙ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: расстояние между точками с координатами a и b на координатной прямой равно |a − b|.

Пример: расстояние между точками −3 и 5: |−3 − 5| = |−8| = 8.

Иллюстрация: координатная прямая с точками −3 и 5, отмеченное расстояние между ними подписано как 8.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ВЫЧИТАНИЕ ЧИСЕЛ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: вычислить (−7) − (−15) − 4.
Решение в рамке: (−7) + 15 = 8; 8 − 4 = 4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- a − b = a + (−b) — вычитание через сложение с противоположным.
- Минус на минус даёт плюс: a − (−b) = a + b.
- Расстояние между точками на прямой: |a − b|.

## Тема 2.6. Умножение и деление положительных и отрицательных чисел

### Карточка 1 из 4 — «Правило знаков при умножении»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ ЧИСЕЛ / ПРАВИЛО ЗНАКОВ ПРИ УМНОЖЕНИИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРАВИЛО ЗНАКОВ
- Произведение двух чисел с одинаковыми знаками — положительно: (+)·(+) = +, (−)·(−) = +.
- Произведение двух чисел с разными знаками — отрицательно: (+)·(−) = −, (−)·(+) = −.
2. ПРАВИЛО МОДУЛЕЙ
- Модуль произведения равен произведению модулей: |a·b| = |a|·|b|.

Иллюстрация: таблица знаков 2×2 (плюс-плюс, плюс-минус, минус-плюс, минус-минус) с итоговым знаком результата в каждой ячейке.

### Карточка 2 из 4 — «Примеры умножения»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ ЧИСЕЛ / ПРИМЕРЫ УМНОЖЕНИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРИМЕРЫ
- (−6) · (−4) = +24 (одинаковые знаки).
- (−6) · 4 = −24 (разные знаки).
- 6 · (−4) = −24 (разные знаки).

Врезка «Запомни!»: При умножении нескольких отрицательных чисел знак результата — минус, если их количество нечётное, и плюс, если чётное.

Иллюстрация: строка (−2)·(−2)·(−2) = −8 с подсчётом количества минусов (3 — нечётное, результат отрицательный).

### Карточка 3 из 4 — «Правило знаков при делении»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ ЧИСЕЛ / ДЕЛЕНИЕ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Правило знаков при делении такое же, как при умножении: одинаковые знаки — частное положительно, разные — отрицательно.

Пример: (−36) : (−6) = 6; (−36) : 6 = −6; 36 : (−6) = −6.

Иллюстрация: те же три примера в виде карточек с подписанными знаками результата.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ ЧИСЕЛ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: вычислить (−2) · (−3) · (−5) : (−6).
Решение в рамке: (−2)·(−3)=6; 6·(−5)=−30; −30 : (−6) = 5.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Одинаковые знаки при умножении/делении дают «+», разные — «−».
- Чётное число минусов в произведении даёт «+», нечётное — «−».
- Модуль результата всегда равен произведению/частному модулей.
