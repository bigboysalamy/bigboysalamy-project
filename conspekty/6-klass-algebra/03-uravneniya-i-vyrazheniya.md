## Тема 3.1. Раскрытие скобок

### Карточка 1 из 4 — «Раскрытие скобок со знаком плюс»
ЗАГОЛОВОК: РАСКРЫТИЕ СКОБОК / СО ЗНАКОМ ПЛЮС. Индикатор: 1 из 4.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: если перед скобками стоит знак «+», скобки можно опустить, сохранив знаки всех слагаемых: a + (b − c) = a + b − c.

Пример: 5 + (3 − 8) = 5 + 3 − 8 = 0.

Иллюстрация: выражение 5 + (3 − 8) с исчезающими на глазах скобками (пунктирная рамка вокруг них перечёркнута стрелкой).

### Карточка 2 из 4 — «Раскрытие скобок со знаком минус»
ЗАГОЛОВОК: РАСКРЫТИЕ СКОБОК / СО ЗНАКОМ МИНУС. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: если перед скобками стоит знак «−», скобки опускают, меняя знак каждого слагаемого внутри на противоположный: a − (b − c) = a − b + c.

Врезка «Частая ошибка!»: Меняют знак только у первого слагаемого в скобках, забывая про остальные — это неверно, менять нужно у ВСЕХ слагаемых.

Иллюстрация: выражение 10 − (4 − 7), под скобкой стрелками показано, как знаки 4 и 7 меняются на противоположные при раскрытии.

### Карточка 3 из 4 — «Вынесение общего множителя за скобки»
ЗАГОЛОВОК: РАСКРЫТИЕ СКОБОК / ВЫНЕСЕНИЕ ЗА СКОБКИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛО (ОБРАТНОЕ ДЕЙСТВИЕ)
Формула в рамке: a·b + a·c = a·(b + c) — распределительное свойство умножения, применённое «в обратную сторону».

Пример: 7·12 + 7·8 = 7·(12+8) = 7·20 = 140.

Иллюстрация: выражение 7·12 + 7·8 с обведённым общим множителем 7, стрелкой выносимым за скобку.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: РАСКРЫТИЕ СКОБОК / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: раскрыть скобки и упростить: 8 − (2x − 5) + (x − 3).
Решение в рамке: 8 − 2x + 5 + x − 3 = (8+5−3) + (−2x+x) = 10 − x.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- «+» перед скобками — знаки внутри не меняются.
- «−» перед скобками — все знаки внутри меняются на противоположные.
- Вынесение общего множителя — обратное действие к раскрытию скобок.

## Тема 3.2. Коэффициент. Подобные слагаемые

### Карточка 1 из 4 — «Понятие коэффициента»
ЗАГОЛОВОК: КОЭФФИЦИЕНТ. ПОДОБНЫЕ СЛАГАЕМЫЕ / КОЭФФИЦИЕНТ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- В произведении числа и буквы (или нескольких букв) числовой множитель называют коэффициентом.
- Если коэффициент равен 1, его обычно не пишут: 1·x = x.
- Если коэффициент равен −1, пишут просто минус: −1·x = −x.

Иллюстрация: выражения 5x, −3y, x, −a с подписанными и обведёнными коэффициентами (5, −3, 1, −1).

### Карточка 2 из 4 — «Умножение выражений на число (упрощение коэффициента)»
ЗАГОЛОВОК: КОЭФФИЦИЕНТ. ПОДОБНЫЕ СЛАГАЕМЫЕ / УМНОЖЕНИЕ НА ЧИСЛО. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Чтобы умножить выражение вида a·x на число k, нужно умножить коэффициент a на k: k·(a·x) = (k·a)·x.

Пример: 4 · (3x) = 12x; (−2) · (5y) = −10y.

Иллюстрация: пример 4·(3x)=12x с обведёнными числами 4 и 3, соединёнными стрелкой в 12.

### Карточка 3 из 4 — «Подобные слагаемые и приведение подобных»
ЗАГОЛОВОК: КОЭФФИЦИЕНТ. ПОДОБНЫЕ СЛАГАЕМЫЕ / ПРИВЕДЕНИЕ ПОДОБНЫХ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ И ПРАВИЛО
- Слагаемые, имеющие одинаковую буквенную часть, называются подобными.
Формула в рамке: чтобы привести подобные слагаемые, нужно сложить их коэффициенты и умножить на общую буквенную часть: 3x + 5x = (3+5)x = 8x.

Пример: 7a − 2a + a = (7−2+1)a = 6a.

Иллюстрация: выражение 3x + 5x − 2x с обведёнными коэффициентами 3, 5, −2, стрелками сходящимися в общую сумму 6x.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: КОЭФФИЦИЕНТ. ПОДОБНЫЕ СЛАГАЕМЫЕ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: упростить выражение 6x + 3 − 2x − 8.
Решение в рамке: (6x−2x) + (3−8) = 4x − 5.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Коэффициент — числовой множитель перед буквенной частью.
- Подобные слагаемые имеют одинаковую буквенную часть.
- Приведение подобных: складываем коэффициенты, буквенную часть не трогаем.

## Тема 3.3. Решение уравнений

### Карточка 1 из 4 — «Что такое уравнение и его корень»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ПОНЯТИЕ УРАВНЕНИЯ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Уравнение — равенство, содержащее неизвестное число, обозначенное буквой.
- Корень уравнения — значение буквы, при котором равенство становится верным.
- Решить уравнение — значит найти все его корни или доказать, что их нет.

Иллюстрация: уравнение x + 5 = 12 с подставленным значением x=7, показывающим верное числовое равенство 7+5=12.

### Карточка 2 из 4 — «Перенос слагаемых из одной части в другую»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ПЕРЕНОС СЛАГАЕМЫХ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: при переносе слагаемого из одной части уравнения в другую его знак меняется на противоположный.

Пример: 3x + 7 = 22 ⇒ 3x = 22 − 7 ⇒ 3x = 15.

Иллюстрация: уравнение с числом 7, «перепрыгивающим» через знак равенства на другую сторону и меняющим знак с + на −.

### Карточка 3 из 4 — «Деление на коэффициент»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ДЕЛЕНИЕ НА КОЭФФИЦИЕНТ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- После переноса слагаемых уравнение приводится к виду a·x = b; чтобы найти x, обе части делят на коэффициент a.

Пример (продолжение предыдущего): 3x = 15 ⇒ x = 15 : 3 = 5.

Врезка «Запомни!»: Всегда можно сделать проверку — подставить найденный корень в исходное уравнение.

Иллюстрация: уравнение 3x=15 с обеими частями, делящимися на 3, стрелками показано сокращение до x=5.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: РЕШЕНИЕ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: решить уравнение 5x − 3 = 2x + 9.
Решение в рамке: 5x − 2x = 9 + 3 ⇒ 3x = 12 ⇒ x = 4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- При переносе через «=» знак слагаемого меняется на противоположный.
- Уравнение вида ax=b решается делением на a.
- Проверка — подстановка найденного корня в исходное уравнение.

## Тема 3.4. Решение задач с помощью уравнений

### Карточка 1 из 4 — «Алгоритм составления уравнения»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / АЛГОРИТМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Обозначить неизвестную величину буквой x (обычно ту, о которой спрашивают, или самую маленькую).
- Выразить через x остальные величины из условия.
- Составить уравнение, используя данное в условии соотношение (сумма, разница, во сколько раз и т.п.).

Иллюстрация: схема из 3 шагов со стрелками — «обозначить x» → «выразить через x» → «составить уравнение».

### Карточка 2 из 4 — «Пример: задача на части»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / ЗАДАЧА НА ЧАСТИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: в двух пакетах 54 кг картофеля, причём в первом в 2 раза больше, чем во втором. Сколько кг в каждом пакете?
Решение в рамке: пусть во втором x кг, тогда в первом 2x кг: x + 2x = 54 ⇒ 3x = 54 ⇒ x = 18. Значит во втором 18 кг, в первом 36 кг.

Иллюстрация: два пакета с картофелем разного размера, подписанные x и 2x, рядом уравнение и решение.

### Карточка 3 из 4 — «Пример: задача на возраст»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / ЗАДАЧА НА ВОЗРАСТ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: отец старше сына на 24 года, а вместе им 48 лет. Сколько лет каждому?
Решение в рамке: пусть сыну x лет, отцу x+24: x + (x+24) = 48 ⇒ 2x = 24 ⇒ x = 12. Сыну 12 лет, отцу 36 лет.

Иллюстрация: две фигуры (взрослый и ребёнок) с подписанными возрастами x и x+24.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: РЕШЕНИЕ ЗАДАЧ С ПОМОЩЬЮ УРАВНЕНИЙ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: периметр прямоугольника 40 см, а длина на 4 см больше ширины. Найти стороны.
Решение в рамке: ширина x, длина x+4: 2(x + x+4) = 40 ⇒ 2x+4 = 20 ⇒ x = 8. Ширина 8 см, длина 12 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Неизвестную величину удобно обозначать через x, остальные — выражать через неё.
- Уравнение отражает главное числовое соотношение из условия задачи.
- В конце всегда проверяй, отвечает ли найденное число на вопрос задачи.
