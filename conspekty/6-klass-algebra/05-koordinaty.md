## Тема 5.1. Координатная плоскость. Координаты точки

### Карточка 1 из 3 — «Устройство координатной плоскости»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / УСТРОЙСТВО. Индикатор: 1 из 3.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Координатная плоскость образована двумя перпендикулярными координатными прямыми: горизонтальной осью абсцисс (Ox) и вертикальной осью ординат (Oy), пересекающимися в точке O — начале координат.
- Оси разбивают плоскость на 4 координатные четверти, нумеруемые против часовой стрелки от правой верхней.

Иллюстрация: координатная плоскость с подписанными осями Ox, Oy, точкой O, четыре четверти пронумерованы I, II, III, IV.

### Карточка 2 из 3 — «Координаты точки и знаки по четвертям»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / КООРДИНАТЫ ТОЧКИ И ЗНАКИ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРАВИЛО
- Положение точки задаётся упорядоченной парой (x; y): x — абсцисса, y — ордината. Порядок чисел важен.
2. ЗНАКИ ПО ЧЕТВЕРТЯМ
- I: (+;+), II: (−;+), III: (−;−), IV: (+;−).

Иллюстрация: точка A(2;5) с пунктирными перпендикулярами к осям; рядом координатная плоскость со знаками в каждой четверти.

### Карточка 3 из 3 — «Итог темы»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / ОТРАБОТКА И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: в какой четверти лежит точка A(−3; 4)?
Решение в рамке: x=−3<0, y=4>0 ⇒ точка A во II четверти.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Точка на плоскости задаётся парой (x;y): сначала абсцисса, потом ордината.
- Четыре четверти нумеруются против часовой стрелки от правой верхней.
- Знаки координат определяют, в какой четверти находится точка.

## Тема 5.2. Построение фигур по координатам. Симметрия точек

### Карточка 1 из 3 — «Построение точки и фигур по координатам»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / АЛГОРИТМ. Индикатор: 1 из 3.

КОНТЕНТ:
1. АЛГОРИТМ ПОСТРОЕНИЯ ТОЧКИ
- От начала координат отсчитать по оси Ox значение абсциссы, из полученной точки отложить по вертикали значение ординаты.
2. ПОСТРОЕНИЕ ФИГУР
- Отметив несколько точек по координатам и соединив их отрезками по порядку, получают многоугольник.

Иллюстрация: пошаговое построение точки B(−4;3), рядом координатная плоскость с 5 точками, соединёнными в пятиугольник.

### Карточка 2 из 3 — «Симметрия точек в координатах»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / СИММЕТРИЯ ТОЧЕК. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРАВИЛА
- Точка, симметричная A(x;y) относительно оси Ox: (x; −y).
- Точка, симметричная A(x;y) относительно оси Oy: (−x; y).
- Точка, симметричная A(x;y) относительно начала координат: (−x; −y).

Иллюстрация: точка A(3;2) и три её симметричных образа относительно Ox, Oy и точки O, каждый подписан своими координатами.

### Карточка 3 из 3 — «Итог темы и главы»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: найти координаты точки, симметричной точке M(−5; 2) относительно оси Oy.
Решение в рамке: при симметрии относительно Oy знак x меняется ⇒ (5; 2).
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 5)
- Построение точки — сначала шаг по оси Ox, затем по Oy.
- Симметрия относительно Ox меняет знак y, относительно Oy — знак x, относительно O — оба знака.
- Координатная плоскость связывает алгебру (числа, координаты) с геометрией (фигуры, симметрия).
