## Тема 4.1. Координатная плоскость

### Карточка 1 из 4 — «Устройство координатной плоскости»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / УСТРОЙСТВО. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Координатная плоскость образована двумя перпендикулярными координатными прямыми: горизонтальной осью абсцисс (Ox) и вертикальной осью ординат (Oy), пересекающимися в точке O — начале координат.
- Оси разбивают плоскость на 4 координатные четверти, которые нумеруют против часовой стрелки, начиная с правой верхней.

Иллюстрация: координатная плоскость с подписанными осями Ox, Oy, точкой O, четыре четверти пронумерованы римскими цифрами I, II, III, IV.

### Карточка 2 из 4 — «Координаты точки»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / КООРДИНАТЫ ТОЧКИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРАВИЛО
- Положение точки на плоскости задаётся упорядоченной парой чисел (x; y): x — абсцисса (расстояние вдоль Ox), y — ордината (расстояние вдоль Oy).
- Порядок чисел в записи важен: (2;5) и (5;2) — разные точки.

Иллюстрация: точка A(2;5), от неё пунктирные перпендикуляры к обеим осям, показывающие, как определяются координаты.

### Карточка 3 из 4 — «Знаки координат в четвертях»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / ЗНАКИ КООРДИНАТ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТАБЛИЦА ЗНАКОВ ПО ЧЕТВЕРТЯМ
- I четверть: x > 0, y > 0.
- II четверть: x < 0, y > 0.
- III четверть: x < 0, y < 0.
- IV четверть: x > 0, y < 0.

Врезка «Запомни!»: Если точка лежит на самой оси Ox, её ордината равна 0; если на оси Oy — абсцисса равна 0.

Иллюстрация: координатная плоскость, в каждой из четырёх четвертей подписаны знаки (+;+), (−;+), (−;−), (+;−).

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: КООРДИНАТНАЯ ПЛОСКОСТЬ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: в какой четверти лежит точка A(−3; 4)?
Решение в рамке: x=−3<0, y=4>0 ⇒ точка A лежит во II четверти.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Точка на плоскости задаётся парой (x;y): сначала абсцисса, потом ордината.
- Четыре четверти нумеруются против часовой стрелки от правой верхней.
- Знаки координат определяют, в какой четверти находится точка.

## Тема 4.2. Построение точек и фигур по координатам

### Карточка 1 из 4 — «Алгоритм построения точки»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / АЛГОРИТМ ПОСТРОЕНИЯ ТОЧКИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- От начала координат отсчитать по оси Ox значение абсциссы (вправо, если положительная, влево — если отрицательная).
- Из полученной точки отложить по вертикали значение ординаты (вверх — положительная, вниз — отрицательная).
- Отметить точку пересечения — это и есть искомая точка.

Иллюстрация: пошаговая схема построения точки B(−4;3): сначала шаг влево на 4, затем шаг вверх на 3.

### Карточка 2 из 4 — «Построение многоугольников по координатам вершин»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / ФИГУРЫ ИЗ ТОЧЕК. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРИМЕНЕНИЕ
- Если последовательно отметить несколько точек по их координатам и соединить их отрезками в заданном порядке, получится многоугольник — так «зашифровывают» рисунки и фигуры.

Иллюстрация: координатная плоскость с 5 точками, соединёнными по порядку в пятиугольник, рядом список координат этих точек.

### Карточка 3 из 4 — «Симметричные точки в координатах»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / СИММЕТРИЯ ТОЧЕК. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛА
- Точка, симметричная A(x;y) относительно оси Ox, имеет координаты (x; −y).
- Точка, симметричная A(x;y) относительно оси Oy, имеет координаты (−x; y).
- Точка, симметричная A(x;y) относительно начала координат, имеет координаты (−x; −y).

Иллюстрация: точка A(3;2) и три её симметричных образа относительно Ox, Oy и точки O, каждый подписан своими координатами.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПОСТРОЕНИЕ ПО КООРДИНАТАМ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: найти координаты точки, симметричной точке M(−5; 2) относительно оси Oy.
Решение в рамке: при симметрии относительно Oy знак x меняется: получаем точку (5; 2).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Построение точки — сначала шаг по оси Ox, затем по Oy.
- Соединяя точки по координатам, можно строить любые фигуры.
- Симметрия относительно Ox меняет знак y, относительно Oy — знак x, относительно O — оба знака.

## Тема 4.3. Графики зависимостей

### Карточка 1 из 4 — «Что такое график зависимости»
ЗАГОЛОВОК: ГРАФИКИ ЗАВИСИМОСТЕЙ / ПОНЯТИЕ ГРАФИКА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Если одна величина зависит от другой (например, расстояние от времени), эту зависимость можно показать таблицей, формулой или графиком — множеством точек на координатной плоскости.
- По горизонтальной оси обычно откладывают независимую величину (время), по вертикальной — зависимую (расстояние, температура и т.п.).

Иллюстрация: координатная плоскость с осями «Время, ч» и «Расстояние, км», несколько точек, соединённых ломаной линией.

### Карточка 2 из 4 — «Чтение графика»
ЗАГОЛОВОК: ГРАФИКИ ЗАВИСИМОСТЕЙ / ЧТЕНИЕ ГРАФИКА. Индикатор: 2 из 4.

КОНТЕНТ:
1. КАК ЧИТАТЬ ГРАФИК
- Чтобы найти значение y при данном x, находят точку на оси Ox, проводят вертикальную линию до графика, а затем — горизонтальную до оси Oy.
- Возрастание графика (линия идёт вверх слева направо) означает увеличение величины; убывание — уменьшение.

Иллюстрация: график температуры в течение суток с восходящим и нисходящим участками, пунктирными линиями показано считывание значения в конкретной точке.

### Карточка 3 из 4 — «Построение графика по таблице»
ЗАГОЛОВОК: ГРАФИКИ ЗАВИСИМОСТЕЙ / ПОСТРОЕНИЕ ПО ТАБЛИЦЕ. Индикатор: 3 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Составить таблицу пар значений (x; y) по условию задачи.
- Отметить каждую пару как точку на координатной плоскости.
- Соединить точки линией (если зависимость непрерывная) или оставить отдельными точками (если величина x принимает только отдельные значения).

Иллюстрация: таблица значений времени и температуры рядом с построенным по ней графиком на координатной плоскости.

### Карточка 4 из 4 — «Итог темы и итог главы»
ЗАГОЛОВОК: ГРАФИКИ ЗАВИСИМОСТЕЙ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: по графику температуры видно, что в 6:00 было −2°C, а в 14:00 — 8°C. Насколько изменилась температура?
Решение в рамке: 8 − (−2) = 10 — температура выросла на 10°C.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 4)
- Координатная плоскость задаётся парой перпендикулярных осей и точкой отсчёта.
- Координаты точки — упорядоченная пара (x;y), знаки определяют четверть.
- График — наглядный способ представить зависимость одной величины от другой.
