# Конспекты по математике, 6 класс

Промпты для генерации карточек-конспектов через ChatGPT (image generation) —
формат такой же, как для конспектов по геометрии (см. `conspekty/7-klass/README.md`),
но серия сокращена до **3 карточек на тему**.

Темы и их группировка по главам взяты из реальной структуры курса
**yaklass.ru → Математика → 6 класс** (проверено по проиндексированным
страницам сайта: главы «Натуральные числа», «Рациональные числа»,
«Отношения, пропорции, проценты», «Преобразование буквенных выражений»).

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Для каждой карточки вставь СТИЛЬ + КОНТЕНТ карточки одним сообщением в ChatGPT.
3. Указывай номер карточки в серии (X из 3).

## Содержание (главы по программе 6 класса, yaklass.ru)

- `01-naturalnye-chisla.md` — Натуральные числа (3 темы × 3 карточки = 9)
- `02-obyknovennye-drobi.md` — Дробные выражения (3 темы × 3 карточки = 9)
- `03-otnosheniya-proportsii-protsenty.md` — Отношения, пропорции, проценты (4 темы × 3 карточки = 12)
- `04-ratsionalnye-chisla.md` — Рациональные числа: положительные и отрицательные числа (4 темы × 3 карточки = 12)
- `05-koordinaty.md` — Координаты. Координатная плоскость (2 темы × 3 карточки = 6)
- `06-preobrazovanie-vyrazheniy.md` — Преобразование буквенных выражений (3 темы × 3 карточки = 9)

Итого: 19 тем, 57 карточек-промптов.
