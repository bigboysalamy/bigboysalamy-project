## Тема 4.1. Положительные и отрицательные числа. Координатная прямая

### Карточка 1 из 3 — «Зачем нужны отрицательные числа»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / ЗАЧЕМ ОНИ НУЖНЫ. Индикатор: 1 из 3.

КОНТЕНТ:
1. ПРИМЕРЫ ИЗ ЖИЗНИ
- Температура ниже нуля (−5°C), долг (−100 рублей), глубина ниже уровня моря (−200 м) — эти величины удобно записывать отрицательными числами.
- Число со знаком «+» (или без знака) — положительное, со знаком «−» — отрицательное.

Иллюстрация: термометр с делениями от −10 до +10, стрелка на −5°C.

### Карточка 2 из 3 — «Координатная прямая»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / КООРДИНАТНАЯ ПРЯМАЯ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Координатная прямая — прямая с выбранным направлением, началом отсчёта (точка O, координата 0) и единичным отрезком.
- Числа справа от 0 — положительные, слева — отрицательные.

Иллюстрация: горизонтальная прямая с делениями от −5 до 5, точка O в нуле, несколько точек с подписанными координатами.

### Карточка 3 из 3 — «Итог темы»
ЗАГОЛОВОК: ПОЛОЖИТЕЛЬНЫЕ И ОТРИЦАТЕЛЬНЫЕ ЧИСЛА / ОТРАБОТКА И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: отметить на координатной прямой точку A(-3).
Решение в рамке: считаем 3 деления влево от точки O.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Отрицательные числа используют для величин «меньше нуля» или «в противоположную сторону».
- На координатной прямой положительные числа — справа от 0, отрицательные — слева.
- Координата точки — число, которое ей соответствует на прямой.

## Тема 4.2. Противоположные числа. Модуль числа. Сравнение рациональных чисел

### Карточка 1 из 3 — «Противоположные числа»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / ПРОТИВОПОЛОЖНЫЕ ЧИСЛА. Индикатор: 1 из 3.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Числа, отличающиеся только знаком, называются противоположными: 5 и −5.
- Число, противоположное a, обозначается −a. Число, противоположное нулю, — сам ноль.
- Целые числа — натуральные, противоположные им и ноль. Рациональные числа — числа, которые можно записать в виде дроби a/b.

Иллюстрация: координатная прямая с точками −4 и 4, симметричными относительно 0.

### Карточка 2 из 3 — «Модуль числа»
ЗАГОЛОВОК: МОДУЛЬ ЧИСЛА / ОПРЕДЕЛЕНИЕ И СВОЙСТВА. Индикатор: 2 из 3.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Модуль числа a (|a|) — расстояние от точки a до точки 0 на координатной прямой; модуль всегда ≥ 0.
Формула в рамке: |a| = a, если a ≥ 0; |a| = −a, если a < 0.
2. СВОЙСТВО
- Модули противоположных чисел равны: |a| = |−a|.

Иллюстрация: координатная прямая, точки −5 и 5, от каждой до точки 0 отмечено расстояние 5.

### Карточка 3 из 3 — «Сравнение рациональных чисел. Итог темы»
ЗАГОЛОВОК: СРАВНЕНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ПРАВИЛО И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. ПРАВИЛО СРАВНЕНИЯ
- Из двух чисел больше то, которое на координатной прямой расположено правее.
- Любое положительное число больше любого отрицательного и больше нуля.
- Из двух отрицательных чисел больше то, модуль которого меньше.
2. РАЗБОР ЗАДАЧИ
Условие: сравнить −7 и −2.
Решение в рамке: |−7|=7, |−2|=2, 7>2 ⇒ −7 < −2.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- |a| — расстояние от a до 0, всегда неотрицательно.
- Правее на координатной прямой — значит больше.
- Из двух отрицательных больше то, у которого модуль меньше.

## Тема 4.3. Сложение и вычитание рациональных чисел

### Карточка 1 из 3 — «Сложение чисел с одинаковыми и разными знаками»
ЗАГОЛОВОК: СЛОЖЕНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ПРАВИЛА СЛОЖЕНИЯ. Индикатор: 1 из 3.

КОНТЕНТ:
1. ОДИНАКОВЫЕ ЗНАКИ
- Складываем модули, ставим общий знак: (−3)+(−5) = −(3+5) = −8.
2. РАЗНЫЕ ЗНАКИ
- Из большего модуля вычитаем меньший, ставим знак числа с большим модулем: (−9)+4 = −(9−4) = −5.

Иллюстрация: координатная прямая с шагами-стрелками, иллюстрирующими оба примера.

### Карточка 2 из 3 — «Вычитание рациональных чисел»
ЗАГОЛОВОК: СЛОЖЕНИЕ И ВЫЧИТАНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ВЫЧИТАНИЕ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРАВИЛО
Формула в рамке: a − b = a + (−b) — вычитание заменяется сложением с противоположным числом.
- При вычитании отрицательного числа два минуса дают плюс: a − (−b) = a + b.

Пример: 5 − (−3) = 5+3 = 8; (−4) − (−9) = (−4)+9 = 5.

Иллюстрация: запись 5 − (−3), два знака минус рядом обведены и соединены со знаком «+».

### Карточка 3 из 3 — «Итог темы»
ЗАГОЛОВОК: СЛОЖЕНИЕ И ВЫЧИТАНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ОТРАБОТКА И ИТОГ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: вычислить (−14) + 20 − (−6).
Решение в рамке: (−14)+20 = 6; 6 − (−6) = 6+6 = 12.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Одинаковые знаки — складываем модули, знак сохраняем; разные знаки — вычитаем модули, знак берём от большего.
- a − b = a + (−b); минус на минус даёт плюс.
- Сумма противоположных чисел всегда равна 0.

## Тема 4.4. Умножение и деление рациональных чисел

### Карточка 1 из 3 — «Правило знаков»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ПРАВИЛО ЗНАКОВ. Индикатор: 1 из 3.

КОНТЕНТ:
1. ПРАВИЛО ЗНАКОВ (одинаково для умножения и деления)
- Одинаковые знаки — результат положительный: (+)·(+)=+, (−)·(−)=+.
- Разные знаки — результат отрицательный: (+)·(−)=−, (−)·(+)=−.
2. МОДУЛЬ РЕЗУЛЬТАТА
- Модуль произведения (частного) равен произведению (частному) модулей.

Иллюстрация: таблица знаков 2×2 с итоговым знаком результата в каждой ячейке.

### Карточка 2 из 3 — «Примеры умножения и деления»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ПРИМЕРЫ. Индикатор: 2 из 3.

КОНТЕНТ:
1. ПРИМЕРЫ
- (−6)·(−4) = +24; (−6)·4 = −24; 6·(−4) = −24.
- (−36):(−6) = 6; (−36):6 = −6; 36:(−6) = −6.

Врезка «Запомни!»: При умножении нескольких чисел знак результата — минус, если отрицательных множителей нечётное количество, и плюс — если чётное.

Иллюстрация: строка (−2)·(−2)·(−2) = −8 с подсчётом трёх минусов (нечётное количество ⇒ результат отрицательный).

### Карточка 3 из 3 — «Итог темы и главы»
ЗАГОЛОВОК: УМНОЖЕНИЕ И ДЕЛЕНИЕ РАЦИОНАЛЬНЫХ ЧИСЕЛ / ОТРАБОТКА И ИТОГ ГЛАВЫ. Индикатор: 3 из 3.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: вычислить (−2)·(−3)·(−5) : (−6).
Решение в рамке: (−2)·(−3)=6; 6·(−5)=−30; −30:(−6)=5.
2. ЧТО НУЖНО ЗАПОМНИТЬ (итог главы 4)
- Одинаковые знаки при умножении/делении дают «+», разные — «−».
- |a| — основа всех правил сравнения и действий с рациональными числами.
- Действия с рациональными числами подчиняются тем же правилам порядка действий, что и с натуральными.
