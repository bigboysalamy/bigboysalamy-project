## § 19. Квадратные уравнения. Решение неполных квадратных уравнений

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 19. КВАДРАТНЫЕ УРАВНЕНИЯ. НЕПОЛНЫЕ УРАВНЕНИЯ / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ (в рамке)
- Квадратным уравнением называют уравнение вида ax² + bx + c = 0, где x — переменная, a, b, c — числа, причём a ≠ 0.
- a — первый коэффициент, b — второй коэффициент, c — свободный член.
2. ПРИВЕДЁННОЕ УРАВНЕНИЕ
- Если a = 1, уравнение x² + bx + c = 0 называют приведённым.
3. НЕПОЛНЫЕ КВАДРАТНЫЕ УРАВНЕНИЯ (в рамках)
- ax² = 0 ⇒ x = 0 (один корень).
- ax² + bx = 0 ⇒ x(ax+b) = 0 ⇒ x = 0 или x = −b/a (два корня).
- ax² + c = 0 ⇒ x² = −c/a: два корня при −c/a > 0 и корней нет при −c/a < 0.

Врезка «Частая ошибка!»: В уравнении ax² + bx = 0 нельзя делить обе части на x — потеряешь корень x = 0. Только вынесение x за скобку!

Иллюстрация: три вида неполных уравнений в трёх блоках с их способами решения.

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 19. КВАДРАТНЫЕ УРАВНЕНИЯ. НЕПОЛНЫЕ УРАВНЕНИЯ / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ
- Определить вид уравнения (полное или неполное).
- Для ax²+bx=0 — вынести x за скобку; для ax²+c=0 — выразить x² и извлечь корень с ±.
2. РАЗБОР ПРИМЕРОВ
- 3x² − 12x = 0 ⇒ 3x(x−4) = 0 ⇒ x = 0 или x = 4.
- 2x² − 18 = 0 ⇒ x² = 9 ⇒ x = ±3.
- 5x² + 20 = 0 ⇒ x² = −4 ⇒ корней нет.
- 7x² = 0 ⇒ x = 0.
3. ЧТО НУЖНО ЗАПОМНИТЬ
- В квадратном уравнении обязательно a ≠ 0.
- ax²+bx=0 всегда имеет корень x=0.
- ax²+c=0 имеет корни, только если x² получается положительным.

Иллюстрация: четыре решения в две колонки, ответы в зелёных рамках.

## § 20. Формула корней квадратного уравнения

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 20. ФОРМУЛА КОРНЕЙ КВАДРАТНОГО УРАВНЕНИЯ / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. ДИСКРИМИНАНТ (в рамке)
- Для уравнения ax² + bx + c = 0 число D = b² − 4ac называют дискриминантом.
2. ФОРМУЛА КОРНЕЙ (в рамке)
- x = (−b ± √D) / (2a).
3. ЧИСЛО КОРНЕЙ ПО ЗНАКУ ДИСКРИМИНАНТА
- D > 0 — два различных корня.
- D = 0 — один корень: x = −b/(2a).
- D < 0 — корней нет.
4. ФОРМУЛА ДЛЯ ЧЁТНОГО ВТОРОГО КОЭФФИЦИЕНТА
- Если b = 2k, удобнее: D₁ = k² − ac, x = (−k ± √D₁)/a.

Иллюстрация: три параболы (пересекает ось Ox в двух точках, касается, не пересекает) с подписями D>0, D=0, D<0.

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 20. ФОРМУЛА КОРНЕЙ КВАДРАТНОГО УРАВНЕНИЯ / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ
- Привести уравнение к виду ax²+bx+c=0 и выписать a, b, c (со знаками!).
- Вычислить D = b² − 4ac.
- Если D ≥ 0 — подставить в формулу корней; если D < 0 — записать «корней нет».
2. РАЗБОР ПРИМЕРОВ
- x² − 7x + 12 = 0: D = 49 − 48 = 1; x = (7±1)/2 ⇒ x₁=4, x₂=3.
- 2x² + 5x − 3 = 0: D = 25 + 24 = 49; x = (−5±7)/4 ⇒ x₁=0,5, x₂=−3.
- x² − 6x + 9 = 0: D = 0 ⇒ x = 3 (один корень).
- x² + x + 5 = 0: D = 1 − 20 = −19 < 0 ⇒ корней нет.
3. ЧТО НУЖНО ЗАПОМНИТЬ
- D = b² − 4ac; знак D определяет число корней.
- Коэффициенты выписывай вместе со знаками — главная причина ошибок.
- Число корней уравнения = числу точек пересечения параболы с осью Ox.

Иллюстрация: четыре решения с выделенным дискриминантом и ответами.

## § 21. Теорема Виета

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 21. ТЕОРЕМА ВИЕТА / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. ТЕОРЕМА ВИЕТА (в рамке)
- Если x₁ и x₂ — корни уравнения ax² + bx + c = 0, то x₁ + x₂ = −b/a, x₁·x₂ = c/a.
2. ДЛЯ ПРИВЕДЁННОГО УРАВНЕНИЯ (в рамке)
- Для x² + px + q = 0: x₁ + x₂ = −p, x₁·x₂ = q.
3. ТЕОРЕМА, ОБРАТНАЯ ТЕОРЕМЕ ВИЕТА
- Если числа m и n таковы, что m + n = −p и m·n = q, то m и n — корни уравнения x² + px + q = 0.

Врезка «Запомни!»: Теорема Виета работает только при D ≥ 0 (когда корни существуют). Она позволяет подобрать корни устно, не считая дискриминант.

Иллюстрация: схема «сумма = −p, произведение = q» с двумя стрелками к корням; пример x²−5x+6=0 ⇒ 2 и 3.

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 21. ТЕОРЕМА ВИЕТА / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ УСТНОГО ПОДБОРА
- Найти пары целых чисел с произведением q.
- Выбрать пару, сумма которой равна −p.
- Проверить подстановкой в уравнение.
2. РАЗБОР ПРИМЕРОВ
- x² − 9x + 20 = 0: произведение 20, сумма 9 ⇒ корни 4 и 5.
- x² + 3x − 10 = 0: произведение −10, сумма −3 ⇒ корни −5 и 2.
- Составить уравнение с корнями 6 и −1: p = −(6+(−1)) = −5, q = 6·(−1) = −6 ⇒ x² − 5x − 6 = 0.
3. ЧТО НУЖНО ЗАПОМНИТЬ
- x₁ + x₂ = −p, x₁·x₂ = q для приведённого уравнения.
- Знак произведения показывает, одинаковы ли знаки корней: q > 0 — одинаковые, q < 0 — разные.
- Обратная теорема позволяет составить уравнение по его корням.

Иллюстрация: три разбора, подобранные пары корней выделены цветом.

## § 22. Квадратный трёхчлен

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 22. КВАДРАТНЫЙ ТРЁХЧЛЕН / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЯ (в рамках)
- Квадратным трёхчленом называют многочлен вида ax² + bx + c, где a ≠ 0.
- Корнем квадратного трёхчлена называют значение переменной, при котором значение трёхчлена равно нулю.
2. КАК НАЙТИ КОРНИ
- Решить соответствующее квадратное уравнение ax² + bx + c = 0; число корней определяется знаком D = b² − 4ac.
3. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ (в рамке)
- Если x₁ и x₂ — корни квадратного трёхчлена, то ax² + bx + c = a(x − x₁)(x − x₂).
- Если D < 0, трёхчлен на линейные множители не раскладывается.

Иллюстрация: трёхчлен 2x²−10x+12 с найденными корнями 2 и 3 и его разложением 2(x−2)(x−3).

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 22. КВАДРАТНЫЙ ТРЁХЧЛЕН / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ РАЗЛОЖЕНИЯ
- Приравнять трёхчлен к нулю и найти корни (через D или по теореме Виета).
- Подставить в формулу a(x − x₁)(x − x₂).
- Проверить раскрытием скобок.
2. РАЗБОР ПРИМЕРОВ
- x² − 5x + 6 = (x−2)(x−3).
- 3x² + 3x − 6 = 3(x−1)(x+2).
- Сократить дробь (x²−4)/(x²−x−2): числитель (x−2)(x+2), знаменатель (x−2)(x+1) ⇒ (x+2)/(x+1).
3. ЧТО НУЖНО ЗАПОМНИТЬ
- ax²+bx+c = a(x−x₁)(x−x₂) — не забывай множитель a перед скобками!
- При D < 0 разложения на линейные множители не существует.
- Разложение трёхчлена — главный инструмент сокращения дробей.

Иллюстрация: сокращение дроби с разложением числителя и знаменателя на множители.

## § 23. Решение уравнений, сводящихся к квадратным

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 23. УРАВНЕНИЯ, СВОДЯЩИЕСЯ К КВАДРАТНЫМ / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. БИКВАДРАТНОЕ УРАВНЕНИЕ (в рамке)
- Уравнение вида ax⁴ + bx² + c = 0 (a ≠ 0) называют биквадратным.
- Заменой x² = t оно сводится к квадратному: at² + bt + c = 0.
2. МЕТОД ЗАМЕНЫ ПЕРЕМЕННОЙ
- Если в уравнении несколько раз встречается одно и то же выражение, его обозначают буквой t и решают уравнение относительно t, затем возвращаются к x.
3. ВАЖНОЕ УСЛОВИЕ
- Так как t = x² ≥ 0, отрицательные значения t отбрасывают.

Врезка «Важно!»: После нахождения t обязательно возвращайся к переменной x — решение не закончено, пока не найдены сами корни исходного уравнения.

Иллюстрация: схема «x⁴−13x²+36=0 → замена x²=t → t²−13t+36=0 → t=4, t=9 → x=±2, ±3».

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 23. УРАВНЕНИЯ, СВОДЯЩИЕСЯ К КВАДРАТНЫМ / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ
- Ввести замену (x² = t или t = выражение в скобках).
- Решить полученное квадратное уравнение относительно t.
- Отбросить недопустимые значения t (например, отрицательные при t = x²).
- Вернуться к x и найти все корни.
2. РАЗБОР ПРИМЕРОВ
- x⁴ − 13x² + 36 = 0: t² −13t +36 = 0 ⇒ t=4, t=9 ⇒ x = ±2, ±3.
- x⁴ − 3x² − 4 = 0: t²−3t−4=0 ⇒ t=4, t=−1 (отбрасываем) ⇒ x = ±2.
- (x²−2x)² − 2(x²−2x) − 3 = 0: t = x²−2x ⇒ t=3, t=−1 ⇒ x²−2x−3=0 (x=3, x=−1) и x²−2x+1=0 (x=1).
3. ЧТО НУЖНО ЗАПОМНИТЬ
- Биквадратное уравнение может иметь 4, 3, 2, 1 корня или ни одного.
- t = x² не может быть отрицательным.
- Замена переменной работает не только для x⁴, но и для повторяющихся скобок.

Иллюстрация: три решения с этапами замены и обратного перехода.

## § 24. Рациональные уравнения как математические модели реальных ситуаций

### Карточка 1 из 2 — «Теория»
ЗАГОЛОВОК: § 24. РАЦИОНАЛЬНЫЕ УРАВНЕНИЯ КАК МАТЕМАТИЧЕСКИЕ МОДЕЛИ / ТЕОРИЯ. Индикатор: 1 из 2.

КОНТЕНТ:
1. ЭТАПЫ МАТЕМАТИЧЕСКОГО МОДЕЛИРОВАНИЯ
- Составление математической модели (уравнения) по условию задачи.
- Решение полученного уравнения.
- Ответ на вопрос задачи с проверкой по смыслу условия.
2. ОСНОВНЫЕ ФОРМУЛЫ (в рамках)
- Движение: S = v·t, t = S/v; по течению v+u, против течения v−u.
- Работа: A = p·t, где p — производительность; t = A/p.
- Проценты/смеси: масса вещества = масса раствора × концентрация.
3. ТИПОВАЯ СТРУКТУРА УРАВНЕНИЯ
- Чаще всего уравнение составляют на РАЗНОСТЬ времён или на равенство суммарных величин.

Иллюстрация: таблица S–v–t для двух участников движения с обозначением x у искомой величины.

### Карточка 2 из 2 — «Практика и итог»
ЗАГОЛОВОК: § 24. РАЦИОНАЛЬНЫЕ УРАВНЕНИЯ КАК МАТЕМАТИЧЕСКИЕ МОДЕЛИ / ПРАКТИКА И ИТОГ. Индикатор: 2 из 2.

КОНТЕНТ:
1. АЛГОРИТМ
- Обозначить неизвестную величину буквой x (обычно ту, что спрашивают, или меньшую скорость).
- Заполнить таблицу S–v–t (или A–p–t) для каждого объекта.
- Составить уравнение по условию (разница времён, общее время).
- Решить и отбросить посторонние корни (отрицательные скорости, время и т.п.).
2. РАЗБОР ПРИМЕРА
- Катер прошёл 48 км по течению и 48 км против течения, затратив на обратный путь на 2 ч больше. Скорость течения 2 км/ч. Найти собственную скорость катера.
- Пусть x — собственная скорость (x > 2): 48/(x−2) − 48/(x+2) = 2.
- Умножаем на (x−2)(x+2): 48(x+2) − 48(x−2) = 2(x²−4) ⇒ 192 = 2x² − 8 ⇒ x² = 100 ⇒ x = 10 (корень −10 отбрасываем).
- Ответ: 10 км/ч.
3. ЧТО НУЖНО ЗАПОМНИТЬ
- Таблица S–v–t превращает текст задачи в уравнение.
- Дробно-рациональное уравнение всегда проверяй на допустимые значения.
- Отрицательные скорость, время и количество деталей — посторонние корни.

Иллюстрация: заполненная таблица S–v–t для движения по течению и против, ниже — составленное уравнение.
