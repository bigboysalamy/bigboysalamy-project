# Конспекты по алгебре, 8 класс (учебник Мерзляка)

Промпты для генерации карточек-конспектов через ChatGPT (image generation).
Источник — учебник **«Алгебра. 8 класс», А. Г. Мерзляк, В. Б. Полонский, М. С. Якир**
(М.: Просвещение, 2022), файл `1726663043_merzlyak_a__algebra_8_klass.pdf` в этой папке.
Структура и терминология взяты из оглавления и текста параграфов учебника.

Серия сокращена до **2 карточек на параграф**, чтобы быстро сгенерировать весь курс:

1. **«Теория»** — определения, правила, формулы параграфа.
2. **«Практика и итог»** — алгоритм решения, разбор типового примера, блок «Что нужно запомнить».

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Вставь СТИЛЬ + КОНТЕНТ нужной карточки одним сообщением в ChatGPT.
3. Указывай номер карточки в серии (1 из 2 / 2 из 2).

## Содержание (по оглавлению учебника)

- `01-ratsionalnye-vyrazheniya.md` — Глава 1. Рациональные выражения (§1–§10, 10 тем × 2 = 20 карточек)
- `02-kvadratnye-korni.md` — Глава 2. Квадратные корни. Действительные числа (§11–§18, 8 тем × 2 = 16 карточек)
- `03-kvadratnye-uravneniya.md` — Глава 3. Квадратные уравнения (§19–§24, 6 тем × 2 = 12 карточек)

Итого: 24 параграфа, 48 карточек-промптов.
