# СТИЛЬ (вставлять перед каждым промптом-карточкой)

Шаблон для конспектов по алгебре 8 класса (учебник Мерзляк А. Г., Полонский В. Б., Якир М. С.).
Серия — **2 карточки на параграф**: «Теория» и «Практика и итог».

```
Создай инфографику-конспект для подготовки школьника к уроку алгебры,
в формате вертикальной карточки A4, как обучающий плакат.

ОБЩИЙ СТИЛЬ:
— Белый фон, тонкая пунктирная рамка по периметру.
— Заголовок крупным жирным шрифтом тёмно-серым/чёрным цветом в две строки:
  первая строка — номер и название параграфа заглавными буквами, вторая строка —
  тип карточки («ТЕОРИЯ» или «ПРАКТИКА И ИТОГ»), заглавными буквами,
  синим цветом (#1a3aab).
— Под заголовком — горизонтальный индикатор страниц: 2 кружка в ряд,
  один из них закрашен синим (текущая карточка), второй — пустой контур.
— Контент разбит на пронумерованные блоки-секции (1., 2., 3...), каждый блок
  имеет заголовок капсом со значком (ромб ♦ синего цвета) и пунктирную
  линию-разделитель снизу.
— Внутри блоков — списки с маркерами-ромбиками; определения, правила и формулы
  выделены в отдельные прямоугольники со скруглёнными углами и светло-голубой
  заливкой; ключевые термины внутри текста — жирным синим.
— Врезки-подсказки (где уместно) — прямоугольник со скруглёнными углами,
  светло-серая/светло-голубая заливка, синяя иконка восклицательного знака
  в кружке слева, заголовок врезки жирным («Важно!», «Запомни!», «Частая ошибка!»).
— Справа или внизу — аккуратная иллюстрация по теме: график функции с осями
  и подписанными точками, числовая прямая, диаграмма Эйлера, схема преобразования
  дроби со стрелками — в зависимости от темы; разные цвета для наглядности.
— На второй карточке серии внизу — горизонтальный блок «ЧТО НУЖНО ЗАПОМНИТЬ»
  с иконкой мозга слева и 2–4 короткими тезисами-выводами с ромбовидными маркерами.
— Палитра: тёмно-синий, голубой, серый текст, акцентные цвета иллюстрации —
  малиновый/зелёный/оранжевый (как в учебных плакатах), много воздуха,
  не перегружать.
— Весь текст — на русском языке, математические обозначения без ошибок.

ДАЛЕЕ — СОДЕРЖАНИЕ ЭТОЙ КОНКРЕТНОЙ КАРТОЧКИ:
```

После этого блока вставляй текст из поля «КОНТЕНТ» нужной карточки (см. файлы глав).
