## Тема 2.1. Треугольник и его элементы

### Карточка 1 из 4 — «Что такое треугольник»
ЗАГОЛОВОК: ТРЕУГОЛЬНИК И ЕГО ЭЛЕМЕНТЫ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Треугольник — фигура из трёх точек, не лежащих на одной прямой, и трёх отрезков, соединяющих эти точки попарно.
- Точки A, B, C — вершины; отрезки AB, BC, CA — стороны; углы при вершинах — углы треугольника.
- Обозначается △ABC.
2. ПЕРИМЕТР
Формула в рамке: P = AB + BC + CA — сумма длин всех сторон.

Иллюстрация: треугольник ABC с подписанными вершинами, сторонами и внутренними углами разного цвета.

### Карточка 2 из 4 — «Виды треугольников по сторонам»
ЗАГОЛОВОК: ТРЕУГОЛЬНИК И ЕГО ЭЛЕМЕНТЫ / ВИДЫ ПО СТОРОНАМ. Индикатор: 2 из 4.

КОНТЕНТ:
1. КЛАССИФИКАЦИЯ
- Разносторонний — все стороны разной длины.
- Равнобедренный — две стороны равны (боковые), третья — основание.
- Равносторонний — все три стороны равны.

Врезка «Важно!»: Равносторонний треугольник — частный случай равнобедренного.

Иллюстрация: три маленьких треугольника рядом — разносторонний, равнобедренный (с засечками на равных сторонах), равносторонний.

### Карточка 3 из 4 — «Виды треугольников по углам»
ЗАГОЛОВОК: ТРЕУГОЛЬНИК И ЕГО ЭЛЕМЕНТЫ / ВИДЫ ПО УГЛАМ. Индикатор: 3 из 4.

КОНТЕНТ:
1. КЛАССИФИКАЦИЯ
- Остроугольный — все углы острые (меньше 90°).
- Прямоугольный — один угол прямой (90°); стороны, образующие его, — катеты, третья сторона — гипотенуза.
- Тупоугольный — один угол тупой (больше 90°).

Иллюстрация: три треугольника рядом, в прямоугольном отмечен прямой угол квадратиком, катеты и гипотенуза подписаны.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ТРЕУГОЛЬНИК И ЕГО ЭЛЕМЕНТЫ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: периметр равнобедренного треугольника равен 26 см, основание — 6 см. Найти боковую сторону.
Решение в рамке: 2x + 6 = 26 ⇒ 2x = 20 ⇒ x = 10 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Треугольник задаётся тремя вершинами, не лежащими на одной прямой.
- По сторонам: разносторонний, равнобедренный, равносторонний.
- По углам: остроугольный, прямоугольный, тупоугольный.

## Тема 2.2. Первый признак равенства треугольников

### Карточка 1 из 4 — «Равные треугольники»
ЗАГОЛОВОК: ПЕРВЫЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / РАВНЫЕ ТРЕУГОЛЬНИКИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Два треугольника называются равными, если их можно совместить наложением — то есть у них соответственно равны все стороны и все углы.
- Соответственные элементы равных треугольников отмечают одинаковыми значками (засечки на сторонах, дуги на углах).

Иллюстрация: два одинаковых треугольника ABC и A₁B₁C₁ с одинаковыми засечками на соответствующих сторонах.

### Карточка 2 из 4 — «Формулировка признака»
ЗАГОЛОВОК: ПЕРВЫЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ПО ДВУМ СТОРОНАМ И УГЛУ МЕЖДУ НИМИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ТЕОРЕМА (ПЕРВЫЙ ПРИЗНАК)
Формула в рамке: если AB = A₁B₁, AC = A₁C₁ и ∠A = ∠A₁ (угол между этими сторонами), то △ABC = △A₁B₁C₁.

Врезка «Важно!»: Угол обязательно должен быть заключён именно между указанными равными сторонами.

Иллюстрация: два треугольника с одинаковыми засечками на сторонах AB, AC и одинаковой дугой при угле A.

### Карточка 3 из 4 — «Идея доказательства»
ЗАГОЛОВОК: ПЕРВЫЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ДОКАЗАТЕЛЬСТВО. Индикатор: 3 из 4.

КОНТЕНТ:
1. ДОКАЗАТЕЛЬСТВО (МЕТОДОМ НАЛОЖЕНИЯ)
- Наложим △ABC на △A₁B₁C₁ так, чтобы вершина A совпала с A₁, а сторона AB легла на луч A₁B₁.
- Так как AB = A₁B₁, точка B совпадёт с B₁.
- Так как ∠A = ∠A₁, луч AC пойдёт по лучу A₁C₁; так как AC = A₁C₁, точка C совпадёт с C₁.
- Значит, треугольники полностью совпали, то есть они равны.

Иллюстрация: схема наложения — полупрозрачный треугольник ABC «сдвигается» стрелкой на A₁B₁C₁.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПЕРВЫЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: на сторонах угла O отложены равные отрезки OA = OB и OC = OD, ∠AOC общий. Доказать, что △AOC = △BOD при условии OA=OB, OC=OD.
Решение в рамке: OA = OB, OC = OD, угол O — общий ⇒ по первому признаку (по двум сторонам и углу между ними) △AOC = △BOD.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Признак: по двум сторонам и углу между ними.
- Угол должен лежать именно между равными сторонами.
- Доказывается методом наложения.

## Тема 2.3. Медианы, биссектрисы и высоты треугольника

### Карточка 1 из 4 — «Медиана»
ЗАГОЛОВОК: МЕДИАНЫ, БИССЕКТРИСЫ И ВЫСОТЫ / МЕДИАНА ТРЕУГОЛЬНИКА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Медиана треугольника — отрезок, соединяющий вершину треугольника с серединой противоположной стороны.
- В треугольнике три медианы, и все они пересекаются в одной точке.

Врезка «Запомни!»: Точка пересечения медиан делит каждую из них в отношении 2:1, считая от вершины.

Иллюстрация: треугольник ABC, медиана AM из вершины A к середине M стороны BC, отмечены равные отрезки BM = MC.

### Карточка 2 из 4 — «Биссектриса»
ЗАГОЛОВОК: МЕДИАНЫ, БИССЕКТРИСЫ И ВЫСОТЫ / БИССЕКТРИСА ТРЕУГОЛЬНИКА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Биссектриса треугольника — отрезок биссектрисы угла треугольника, соединяющий вершину с точкой на противоположной стороне.
- Биссектриса угла делит его на два равных угла.
- В треугольнике три биссектрисы, все они пересекаются в одной точке.

Иллюстрация: треугольник ABC, биссектриса AL из вершины A, дугами отмечены равные углы ∠BAL = ∠LAC.

### Карточка 3 из 4 — «Высота»
ЗАГОЛОВОК: МЕДИАНЫ, БИССЕКТРИСЫ И ВЫСОТЫ / ВЫСОТА ТРЕУГОЛЬНИКА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Высота треугольника — перпендикуляр, опущенный из вершины треугольника на прямую, содержащую противоположную сторону.
- В треугольнике три высоты, все они (или их продолжения) пересекаются в одной точке.

Врезка «Почему это так?»: В тупоугольном треугольнике две высоты падают не на сторону, а на её продолжение — поэтому говорят «прямую, содержащую сторону».

Иллюстрация: три треугольника — остроугольный (высоты внутри), прямоугольный (две высоты совпадают с катетами), тупоугольный (высоты — на продолжении сторон, пунктиром).

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: МЕДИАНЫ, БИССЕКТРИСЫ И ВЫСОТЫ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. СРАВНИТЕЛЬНАЯ ТАБЛИЦА (3 колонки)
- Медиана — к середине стороны.
- Биссектриса — делит угол пополам.
- Высота — перпендикуляр к стороне (или её продолжению).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Все три медианы пересекаются в одной точке (отношение 2:1 от вершины).
- Все три биссектрисы пересекаются в одной точке.
- Все три высоты (или их продолжения) пересекаются в одной точке.
- В равностороннем треугольнике медиана, биссектриса и высота, проведённые к одной стороне, совпадают.

## Тема 2.4. Равнобедренный треугольник и его свойства

### Карточка 1 из 4 — «Определение и элементы»
ЗАГОЛОВОК: РАВНОБЕДРЕННЫЙ ТРЕУГОЛЬНИК / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Равнобедренный треугольник — треугольник, у которого две стороны равны.
- Эти стороны называются боковыми, третья сторона — основанием.
- Угол между боковыми сторонами — угол при вершине, остальные два — углы при основании.

Иллюстрация: треугольник ABC с AB = BC (засечки), основание AC, вершина B сверху.

### Карточка 2 из 4 — «Свойство углов при основании»
ЗАГОЛОВОК: РАВНОБЕДРЕННЫЙ ТРЕУГОЛЬНИК / СВОЙСТВО УГЛОВ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
Формула в рамке: в равнобедренном треугольнике углы при основании равны: ∠A = ∠C.

Врезка «Почему это так?»: Если провести биссектрису угла при вершине B, она разобьёт треугольник на два равных (по первому признаку: BA=BC, общий угол при B пополам, BD — общая сторона) — отсюда равенство углов A и C.

Иллюстрация: треугольник ABC с проведённой биссектрисой BD к основанию, дугами отмечены равные углы A и C.

### Карточка 3 из 4 — «Свойство медианы-биссектрисы-высоты»
ЗАГОЛОВОК: РАВНОБЕДРЕННЫЙ ТРЕУГОЛЬНИК / СОВПАДЕНИЕ МЕДИАНЫ, БИССЕКТРИСЫ, ВЫСОТЫ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
- В равнобедренном треугольнике медиана, биссектриса и высота, проведённые из вершины к основанию, совпадают — это один и тот же отрезок.

Врезка «Запомни!»: Это свойство — признак равнобедренности: если в треугольнике медиана совпадает с высотой (или с биссектрисой), то треугольник равнобедренный.

Иллюстрация: треугольник ABC, из вершины B к середине основания AC проведён один отрезок BD, подписанный сразу тремя названиями: «медиана = биссектриса = высота».

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: РАВНОБЕДРЕННЫЙ ТРЕУГОЛЬНИК / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: в равнобедренном треугольнике угол при вершине равен 40°. Найти углы при основании.
Решение в рамке: 2x + 40° = 180° ⇒ x = 70° — каждый угол при основании.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- В равнобедренном треугольнике углы при основании равны.
- Медиана, биссектриса и высота к основанию совпадают.
- Это работает и в обратную сторону: совпадение этих отрезков ⇒ треугольник равнобедренный.

## Тема 2.5. Второй признак равенства треугольников

### Карточка 1 из 4 — «Формулировка»
ЗАГОЛОВОК: ВТОРОЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ПО СТОРОНЕ И ДВУМ ПРИЛЕЖАЩИМ УГЛАМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА (ВТОРОЙ ПРИЗНАК)
Формула в рамке: если AB = A₁B₁, ∠A = ∠A₁ и ∠B = ∠B₁ (углы, прилежащие к этой стороне), то △ABC = △A₁B₁C₁.

Врезка «Важно!»: Оба угла должны быть прилежащими именно к равной стороне — то есть лежать на её концах.

Иллюстрация: два треугольника с одинаковыми засечками на стороне AB и одинаковыми дугами на углах A и B.

### Карточка 2 из 4 — «Идея доказательства»
ЗАГОЛОВОК: ВТОРОЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ДОКАЗАТЕЛЬСТВО. Индикатор: 2 из 4.

КОНТЕНТ:
1. ДОКАЗАТЕЛЬСТВО (МЕТОДОМ НАЛОЖЕНИЯ)
- Наложим △ABC на △A₁B₁C₁ так, чтобы AB совпало с A₁B₁ (так как AB = A₁B₁).
- Так как ∠A = ∠A₁, луч AC пойдёт по лучу A₁C₁; так как ∠B = ∠B₁, луч BC пойдёт по лучу B₁C₁.
- Точка C — пересечение лучей AC и BC — совпадёт с точкой C₁ — пересечением лучей A₁C₁ и B₁C₁.
- Треугольники совпали полностью, значит они равны.

Иллюстрация: схема наложения двух треугольников с подписанными совпадающими лучами.

### Карточка 3 из 4 — «Применение признака»
ЗАГОЛОВОК: ВТОРОЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ПРИМЕР ПРИМЕНЕНИЯ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: отрезки AC и BD пересекаются в точке O — середине каждого из них, ∠A = ∠B. Доказать равенство треугольников AOD и BOC.
Решение в рамке: AO = BO (O — середина AC и BD... уточнение по чертежу), ∠AOD = ∠BOC (вертикальные), ∠A = ∠B ⇒ треугольники равны по второму признаку.

Иллюстрация: пересекающиеся отрезки AC и BD в точке O, треугольники AOD и BOC закрашены разными полупрозрачными цветами.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ВТОРОЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. СРАВНЕНИЕ С ПЕРВЫМ ПРИЗНАКОМ (мини-таблица)
- 1-й признак: две стороны + угол между ними.
- 2-й признак: сторона + два прилежащих к ней угла.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Признак: по стороне и двум прилежащим к ней углам.
- Углы обязательно прилежат именно к равной стороне (на её концах).
- Доказывается методом наложения, как и первый признак.

## Тема 2.6. Третий признак равенства треугольников

### Карточка 1 из 4 — «Формулировка»
ЗАГОЛОВОК: ТРЕТИЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ПО ТРЁМ СТОРОНАМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА (ТРЕТИЙ ПРИЗНАК)
Формула в рамке: если AB = A₁B₁, BC = B₁C₁ и CA = C₁A₁, то △ABC = △A₁B₁C₁.

Врезка «Запомни!»: Это единственный признак, где не требуется ни одного равенства углов — достаточно всех трёх сторон.

Иллюстрация: два треугольника с одинаковыми засечками (разного «рисунка» — одна, две, три чёрточки) на всех трёх парах сторон.

### Карточка 2 из 4 — «Идея доказательства»
ЗАГОЛОВОК: ТРЕТИЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ДОКАЗАТЕЛЬСТВО. Индикатор: 2 из 4.

КОНТЕНТ:
1. ДОКАЗАТЕЛЬСТВО (ИДЕЯ)
- Приложим △ABC к △A₁B₁C₁ так, чтобы сторона AB совпала с A₁B₁, а вершины C и C₁ оказались по разные стороны от неё.
- Соединим C и C₁: получаются два равнобедренных треугольника (по построению BC = B₁C₁ и AC = A₁C₁), у которых углы при основании C-C₁ равны.
- Отсюда следует, что ∠ACB = ∠A₁C₁B₁, и треугольники равны по первому признаку.

Иллюстрация: треугольник ABC и его «отражённая» копия с общей стороной AB, точки C и C₁ соединены пунктирной линией.

### Карточка 3 из 4 — «Жёсткость треугольника»
ЗАГОЛОВОК: ТРЕТИЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ПРИМЕНЕНИЕ В ЖИЗНИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. СВОЙСТВО ЖЁСТКОСТИ
- Треугольник с заданными длинами сторон нельзя деформировать, не меняя длины сторон — он «жёсткий».
- В отличие от треугольника, четырёхугольник с теми же сторонами можно «перекосить» — поэтому в технике (фермы мостов, стропила крыш) используют именно треугольные конструкции.

Иллюстрация: слева жёсткий треугольный каркас, справа — четырёхугольный каркас, изображённый перекошенным стрелкой деформации.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ТРЕТИЙ ПРИЗНАК РАВЕНСТВА ТРЕУГОЛЬНИКОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. ВСЕ ТРИ ПРИЗНАКА РАВЕНСТВА (сводная таблица)
- I — по двум сторонам и углу между ними.
- II — по стороне и двум прилежащим углам.
- III — по трём сторонам.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Третий признак: три пары равных сторон ⇒ треугольники равны.
- Углы при этом сравнивать не нужно.
- Треугольник — единственный многоугольник, жёстко определяемый длинами сторон.

## Тема 2.7. Окружность и её элементы

### Карточка 1 из 4 — «Определение окружности»
ЗАГОЛОВОК: ОКРУЖНОСТЬ / ОПРЕДЕЛЕНИЕ И ЭЛЕМЕНТЫ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Окружность — множество всех точек плоскости, равноудалённых от данной точки O (центра) на расстояние R (радиус).
- Круг — часть плоскости, ограниченная окружностью (вместе с самой окружностью).
2. ЭЛЕМЕНТЫ
- Радиус — отрезок, соединяющий центр с точкой окружности.
- Хорда — отрезок, соединяющий две точки окружности.
- Диаметр — хорда, проходящая через центр; D = 2R.

Иллюстрация: окружность с центром O, отмечены радиус OA, хорда BC, диаметр DE через центр.

### Карточка 2 из 4 — «Окружность, описанная около треугольника»
ЗАГОЛОВОК: ОКРУЖНОСТЬ / ОПИСАННАЯ ОКОЛО ТРЕУГОЛЬНИКА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Окружность называется описанной около треугольника, если она проходит через все три его вершины.
- Центр такой окружности — точка пересечения серединных перпендикуляров к сторонам треугольника, равноудалённая от всех трёх вершин.

Врезка «Запомни!»: Около любого треугольника можно описать окружность, и притом только одну.

Иллюстрация: треугольник ABC, вписанный в окружность, центр O соединён радиусами с A, B, C.

### Карточка 3 из 4 — «Окружность, вписанная в треугольник»
ЗАГОЛОВОК: ОКРУЖНОСТЬ / ВПИСАННАЯ В ТРЕУГОЛЬНИК. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Окружность называется вписанной в треугольник, если она касается всех трёх его сторон.
- Центр такой окружности — точка пересечения биссектрис треугольника, равноудалённая от всех трёх сторон.

Врезка «Почему это так?»: Любая точка биссектрисы угла равноудалена от его сторон — поэтому точка пересечения всех трёх биссектрис равноудалена от всех трёх сторон треугольника.

Иллюстрация: треугольник ABC с вписанной окружностью, центр O в точке пересечения биссектрис, перпендикуляры из O к каждой стороне отмечены равными отрезками.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ОКРУЖНОСТЬ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. СРАВНЕНИЕ (две колонки)
- Описанная окружность: проходит через вершины, центр — пересечение серединных перпендикуляров.
- Вписанная окружность: касается сторон, центр — пересечение биссектрис.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- R — радиус, D = 2R — диаметр, хорда — отрезок между двумя точками окружности.
- Около любого треугольника можно описать ровно одну окружность.
- В любой треугольник можно вписать ровно одну окружность.

## Тема 2.8. Задачи на построение циркулем и линейкой

### Карточка 1 из 4 — «Базовые построения»
ЗАГОЛОВОК: ЗАДАЧИ НА ПОСТРОЕНИЕ / ИНСТРУМЕНТЫ И ВОЗМОЖНОСТИ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ЧТО МОЖНО ДЕЛАТЬ
- Циркулем — строить окружность данного радиуса с центром в данной точке.
- Линейкой (без делений) — проводить прямую через две данные точки.
2. ОТКЛАДЫВАНИЕ УГЛА, РАВНОГО ДАННОМУ
- Построение выполняется через две дуги одинакового радиуса и засечку третьей дугой — копирует угол без транспортира.

Иллюстрация: циркуль и линейка как пиктограммы, рядом схема построения равного угла с дугами.

### Карточка 2 из 4 — «Построение биссектрисы угла»
ЗАГОЛОВОК: ЗАДАЧИ НА ПОСТРОЕНИЕ / БИССЕКТРИСА УГЛА. Индикатор: 2 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Из вершины угла проводим дугу произвольного радиуса, отмечаем точки пересечения со сторонами угла.
- Из этих двух точек проводим дуги одинакового радиуса до их пересечения внутри угла.
- Соединяем вершину угла с точкой пересечения дуг — это и есть биссектриса.

Иллюстрация: пошаговая схема в 3 мини-окошках, показывающая последовательность дуг.

### Карточка 3 из 4 — «Построение серединного перпендикуляра»
ЗАГОЛОВОК: ЗАДАЧИ НА ПОСТРОЕНИЕ / СЕРЕДИННЫЙ ПЕРПЕНДИКУЛЯР К ОТРЕЗКУ. Индикатор: 3 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Из концов отрезка AB проводим две дуги одинакового радиуса (больше половины AB) по обе стороны от отрезка.
- Точки пересечения дуг соединяем прямой — она проходит через середину AB и перпендикулярна ему.

Врезка «Важно!»: Этим способом строят центр окружности, описанной около треугольника — как пересечение серединных перпендикуляров к двум сторонам.

Иллюстрация: отрезок AB, две пересекающиеся пары дуг сверху и снизу, проведённая через точки пересечения вертикальная линия.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ЗАДАЧИ НА ПОСТРОЕНИЕ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. ЧЕТЫРЕ КЛАССИЧЕСКИЕ ЗАДАЧИ (список с иконками)
- Деление угла пополам.
- Построение перпендикуляра в данной точке прямой.
- Построение серединного перпендикуляра к отрезку.
- Построение угла, равного данному.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Циркуль и линейка без делений — единственные разрешённые инструменты.
- Все построения опираются на свойства равных радиусов и равнобедренных треугольников.
- Построения используют для нахождения центров вписанной и описанной окружностей треугольника.
