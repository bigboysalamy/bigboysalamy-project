# Конспекты по геометрии, 7 класс

Промпты для генерации карточек-конспектов через ChatGPT (image generation), в стиле референса
(белый фон, тёмно-синий заголовок, цветная иллюстрация справа/снизу, ромбовидные маркеры,
врезки «Важно!» / «Запомни!» / «Почему это так?», индикатор страниц вверху, блок
«Что нужно запомнить» внизу с иконкой мозга).

Источник материала: yaklass.ru → Геометрия, 7 класс (раздел «Геометрия»),
учебник Атанасяна — структура разбивки совпадает с программой.

## Как пользоваться

1. Открой файл `00-shablon-stilya.md` — это базовый блок СТИЛЬ. Он одинаков для всех карточек.
2. В каждом файле главы (`01-...md`, `02-...md` и т.д.) — темы, разбитые на серии из
   **4 карточек** (как требуется: минимум 4 конспекта на тему).
3. Для каждой карточки: скопируй блок СТИЛЬ + блок КОНТЕНТ карточки → вставь одним
   сообщением в ChatGPT (с включённой генерацией изображений) → получишь картинку-конспект.
4. Индикатор страниц (X из 4 кружков) — обязательно укажи, какой кружок закрашен,
   чтобы серия карточек смотрелась как набор.

## Содержание (главы по программе 7 класса)

- `01-nachalnye-svedeniya.md` — Начальные геометрические сведения (5 тем × 4 карточки = 20)
- `02-treugolniki.md` — Треугольники (8 тем × 4 карточки = 32)
- `03-parallelnye-pryamye.md` — Параллельные прямые (3 темы × 4 карточки = 12)
- `04-sootnosheniya.md` — Соотношения между сторонами и углами треугольника (5 тем × 4 карточки = 20)

Итого: 21 тема, 84 карточки-промпта.
