## Тема 3.1. Параллельные прямые и секущая

### Карточка 1 из 4 — «Определение параллельности»
ЗАГОЛОВОК: ПАРАЛЛЕЛЬНЫЕ ПРЯМЫЕ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Две прямые на плоскости называются параллельными, если они не пересекаются (или совпадают).
- Обозначение: a ∥ b.
- Секущая — прямая, пересекающая обе данные прямые в двух разных точках.

Иллюстрация: две горизонтальные параллельные прямые a и b, пересечённые наклонной секущей c, в точках пересечения отмечены 8 углов (по 4 в каждой точке).

### Карточка 2 из 4 — «Виды углов при секущей»
ЗАГОЛОВОК: ПАРАЛЛЕЛЬНЫЕ ПРЯМЫЕ / УГЛЫ ПРИ СЕКУЩЕЙ. Индикатор: 2 из 4.

КОНТЕНТ:
1. НАЗВАНИЯ ПАР УГЛОВ
- Накрест лежащие углы — лежат между прямыми a и b, по разные стороны от секущей.
- Соответственные углы — лежат по одну сторону от секущей, один над прямой, другой под ней, на одном уровне.
- Односторонние углы — лежат между прямыми a и b, по одну сторону от секущей.

Иллюстрация: те же две прямые с секущей, три пары углов закрашены тремя разными цветами с подписями («накрест лежащие», «соответственные», «односторонние»).

### Карточка 3 из 4 — «Признаки параллельности по углам»
ЗАГОЛОВОК: ПАРАЛЛЕЛЬНЫЕ ПРЯМЫЕ / ПРИЗНАКИ ПАРАЛЛЕЛЬНОСТИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТЕОРЕМЫ (ПРИЗНАКИ)
- Если накрест лежащие углы равны, то прямые параллельны.
- Если соответственные углы равны, то прямые параллельны.
- Если сумма односторонних углов равна 180°, то прямые параллельны.

Врезка «Запомни!»: Достаточно проверить одно из трёх условий — остальные выполнятся автоматически.

Иллюстрация: схема с прямыми a, b и секущей c, один накрест лежащий угол подписан 50°, второй — тоже 50°, стрелка-вывод «⇒ a ∥ b».

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПАРАЛЛЕЛЬНЫЕ ПРЯМЫЕ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: при пересечении прямых a и b секущей один из односторонних углов равен 110°, другой — 70°. Параллельны ли a и b?
Решение в рамке: 110° + 70° = 180° ⇒ по признаку односторонних углов a ∥ b.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- a ∥ b — прямые не пересекаются.
- Три признака параллельности: накрест лежащие равны / соответственные равны / односторонние в сумме 180°.
- Признаки доказываются от противного с опорой на теорему о внешнем угле треугольника.

## Тема 3.2. Аксиома параллельных прямых

### Карточка 1 из 4 — «Формулировка аксиомы»
ЗАГОЛОВОК: АКСИОМА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ / ФОРМУЛИРОВКА. Индикатор: 1 из 4.

КОНТЕНТ:
1. АКСИОМА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ
Формула в рамке: через точку, не лежащую на данной прямой, проходит только одна прямая, параллельная данной.

Врезка «Запомни!»: Это знаменитый «пятый постулат» Евклида — без него возможны другие (неевклидовы) геометрии.

Иллюстрация: прямая a, точка M вне неё, единственная прямая b через M, параллельная a; пунктиром показаны другие прямые через M, которые обязательно пересекут a.

### Карточка 2 из 4 — «Следствия аксиомы»
ЗАГОЛОВОК: АКСИОМА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ / СЛЕДСТВИЯ. Индикатор: 2 из 4.

КОНТЕНТ:
1. СЛЕДСТВИЯ
- Если прямая пересекает одну из двух параллельных прямых, то она пересекает и другую.
- Если две прямые параллельны третьей прямой, то они параллельны между собой.

Иллюстрация: схема 1 — прямая c пересекает a, обязательно пересекает и b ∥ a; схема 2 — a ∥ c, b ∥ c ⇒ a ∥ b (три параллельные прямые подписаны).

### Карточка 3 из 4 — «Обратные теоремы: свойства параллельных прямых»
ЗАГОЛОВОК: АКСИОМА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ / СВОЙСТВА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТЕОРЕМЫ (ОБРАТНЫЕ К ПРИЗНАКАМ)
- Если две прямые параллельны, то накрест лежащие углы равны.
- Если две прямые параллельны, то соответственные углы равны.
- Если две прямые параллельны, то сумма односторонних углов равна 180°.

Врезка «Почему это так?»: Эти теоремы доказываются от противного с использованием самой аксиомы параллельных прямых (единственности параллельной).

Иллюстрация: прямые a ∥ b с секущей c, все 8 углов подписаны конкретными градусами (например, 65° и 115° чередуются), показывающими согласованность по всем трём правилам.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: АКСИОМА ПАРАЛЛЕЛЬНЫХ ПРЯМЫХ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: a ∥ b, секущая c образует с a угол 55°. Найти соответственный, накрест лежащий и односторонний углы при прямой b.
Решение в рамке: соответственный = 55°, накрест лежащий = 55°, односторонний = 180° − 55° = 125°.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Через точку вне прямой проходит ровно одна параллельная ей прямая.
- Признаки (углы равны/в сумме 180° ⇒ прямые параллельны) и свойства (прямые параллельны ⇒ углы равны/в сумме 180°) — взаимно обратные утверждения.
- Если a ∥ c и b ∥ c, то a ∥ b.

## Тема 3.3. Применение параллельности прямых

### Карточка 1 из 4 — «Перпендикулярность к параллельным»
ЗАГОЛОВОК: ПРИМЕНЕНИЕ ПАРАЛЛЕЛЬНОСТИ / ПЕРПЕНДИКУЛЯР К ПАРАЛЛЕЛЬНЫМ ПРЯМЫМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
- Если прямая перпендикулярна одной из двух параллельных прямых, то она перпендикулярна и другой.

Иллюстрация: a ∥ b, прямая c пересекает обе под прямым углом, в обеих точках пересечения — значок прямого угла (квадратик).

### Карточка 2 из 4 — «Сумма углов треугольника через параллельность (анонс)»
ЗАГОЛОВОК: ПРИМЕНЕНИЕ ПАРАЛЛЕЛЬНОСТИ / ПОДГОТОВКА К СЛЕДУЮЩЕЙ ТЕМЕ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ИДЕЯ
- Через вершину треугольника можно провести прямую, параллельную противоположной стороне.
- Это вспомогательное построение — главный приём для доказательства теоремы о сумме углов треугольника (следующая глава).

Врезка «Важно!»: Вспомогательная параллельная прямая — один из самых частых приёмов в геометрических доказательствах.

Иллюстрация: треугольник ABC, через вершину B проведена прямая, параллельная стороне AC, накрест лежащие углы с углами треугольника закрашены одинаковыми цветами.

### Карточка 3 из 4 — «Параллельность в жизни и черчении»
ЗАГОЛОВОК: ПРИМЕНЕНИЕ ПАРАЛЛЕЛЬНОСТИ / ГДЕ ЭТО ИСПОЛЬЗУЕТСЯ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРИМЕРЫ
- Рельсы железной дороги, разметка дороги, линии тетради — все эти линии построены как параллельные.
- Чертёжный угольник и линейка позволяют быстро провести прямую, параллельную данной, через нужную точку.

Иллюстрация: схематичные рельсы уходящие вдаль, рядом — угольник, скользящий вдоль линейки, проводящий параллельную линию.

### Карточка 4 из 4 — «Итог главы 3»
ЗАГОЛОВОК: ПАРАЛЛЕЛЬНЫЕ ПРЯМЫЕ / ИТОГ ГЛАВЫ. Индикатор: 4 из 4.

КОНТЕНТ:
1. КАРТА ПОНЯТИЙ ГЛАВЫ
- Секущая и углы → Признаки параллельности → Аксиома параллельных → Свойства параллельных прямых.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Признаки доказывают параллельность по равенству углов.
- Аксиома гарантирует единственность параллельной прямой через точку.
- Свойства — обратные теоремы, применяются, когда параллельность уже известна.
- Тема — фундамент для доказательства суммы углов треугольника (глава 4).
