## Тема 3.1. Синус, косинус, тангенс произвольного угла

### Карточка 1 из 4 — «Расширение понятия угла»
ЗАГОЛОВОК: СИНУС, КОСИНУС, ТАНГЕНС ПРОИЗВОЛЬНОГО УГЛА / ЕДИНИЧНАЯ ПОЛУОКРУЖНОСТЬ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ ЧЕРЕЗ ЕДИНИЧНУЮ ПОЛУОКРУЖНОСТЬ
- Рассматривают верхнюю единичную полуокружность с центром O(0;0) и радиусом 1.
- Для угла α (0° ≤ α ≤ 180°) между Ox и радиусом OM берут точку M(x;y) на полуокружности.
Формула в рамке: sin α = y (ордината точки M), cos α = x (абсцисса точки M).

Иллюстрация: единичная полуокружность, радиус OM под углом α к оси Ox, точка M с подписанными координатами (cos α; sin α).

### Карточка 2 из 4 — «Тангенс и знаки функций»
ЗАГОЛОВОК: СИНУС, КОСИНУС, ТАНГЕНС ПРОИЗВОЛЬНОГО УГЛА / ТАНГЕНС И ЗНАКИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ ТАНГЕНСА
Формула в рамке: tg α = sin α / cos α (при cos α ≠ 0, то есть α ≠ 90°).
2. ЗНАКИ ФУНКЦИЙ
- Для угла от 0° до 90° (острый): sin α > 0, cos α > 0.
- Для угла от 90° до 180° (тупой): sin α > 0, cos α < 0.

Иллюстрация: полуокружность, разделённая на две зоны — «острые углы» слева от вертикали (cos>0) и «тупые» справа (cos<0), в обеих sin>0 (верхняя полуокружность).

### Карточка 3 из 4 — «Значения для ключевых углов и формулы приведения»
ЗАГОЛОВОК: СИНУС, КОСИНУС, ТАНГЕНС ПРОИЗВОЛЬНОГО УГЛА / КЛЮЧЕВЫЕ ЗНАЧЕНИЯ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТАБЛИЦА ЗНАЧЕНИЙ (0°, 90°, 180°)
- sin 0° = 0, cos 0° = 1.
- sin 90° = 1, cos 90° = 0.
- sin 180° = 0, cos 180° = −1.
2. ФОРМУЛА ПРИВЕДЕНИЯ
Формула в рамке: sin(180° − α) = sin α, cos(180° − α) = −cos α.

Иллюстрация: полуокружность с двумя симметричными относительно вертикального диаметра точками — для угла α и угла (180°−α), с подписанными координатами.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СИНУС, КОСИНУС, ТАНГЕНС ПРОИЗВОЛЬНОГО УГЛА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: зная sin 30° = 1/2 и cos 30° = √3/2, найти sin 150° и cos 150°.
Решение в рамке: sin 150° = sin(180°−30°) = sin 30° = 1/2; cos 150° = −cos 30° = −√3/2.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- sin α и cos α определяются как координаты точки на единичной полуокружности.
- Для тупых углов cos α отрицателен, а sin α остаётся положительным.
- Формулы приведения связывают угол α с (180° − α).

## Тема 3.2. Теорема косинусов

### Карточка 1 из 4 — «Формулировка теоремы»
ЗАГОЛОВОК: ТЕОРЕМА КОСИНУСОВ / ФОРМУЛИРОВКА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
Формула в рамке: квадрат стороны треугольника равен сумме квадратов двух других сторон минус удвоенное произведение этих сторон на косинус угла между ними: c² = a² + b² − 2ab·cos C.

Врезка «Запомни!»: При C = 90° (cos C = 0) формула превращается в обычную теорему Пифагора — теорема косинусов её обобщение.

Иллюстрация: треугольник ABC со сторонами a, b, c и углом C между сторонами a и b, формула рядом.

### Карточка 2 из 4 — «Применение: нахождение стороны»
ЗАГОЛОВОК: ТЕОРЕМА КОСИНУСОВ / НАХОЖДЕНИЕ СТОРОНЫ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: a = 5, b = 8, угол C = 60°. Найти c.
Решение в рамке: c² = 25 + 64 − 2·5·8·cos60° = 89 − 80·0.5 = 89 − 40 = 49 ⇒ c = 7.

Иллюстрация: треугольник с подписанными сторонами 5 и 8, углом 60° между ними, найденной стороной c=7.

### Карточка 3 из 4 — «Применение: нахождение угла»
ЗАГОЛОВОК: ТЕОРЕМА КОСИНУСОВ / НАХОЖДЕНИЕ УГЛА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛА (ВЫРАЖЕННЫЙ КОСИНУС)
Формула в рамке: cos C = (a² + b² − c²) / (2ab).

Врезка «Почему это так?»: Просто выражаем cos C из основной формулы теоремы косинусов.

Пример: a=6, b=7, c=9 ⇒ cos C = (36+49−81)/(2·6·7) = 4/84 ≈ 0.048 ⇒ угол C близок к 87°.

Иллюстрация: треугольник со сторонами 6, 7, 9, угол C отмечен дугой с вопросительным знаком, рядом формула.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ТЕОРЕМА КОСИНУСОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: стороны треугольника 4 см, 5 см, угол между ними 120°. Найти третью сторону.
Решение в рамке: c² = 16+25−2·4·5·cos120° = 41 − 40·(−0.5) = 41+20 = 61 ⇒ c = √61 ≈ 7.8 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- c² = a² + b² − 2ab·cos C — обобщение теоремы Пифагора на любой треугольник.
- Используется, когда известны две стороны и угол между ними (найти третью сторону), либо все три стороны (найти угол).
- При тупом угле cos C < 0, третье слагаемое становится положительным — сторона удлиняется.

## Тема 3.3. Теорема синусов

### Карточка 1 из 4 — «Формулировка теоремы»
ЗАГОЛОВОК: ТЕОРЕМА СИНУСОВ / ФОРМУЛИРОВКА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
Формула в рамке: стороны треугольника пропорциональны синусам противолежащих углов: a/sin A = b/sin B = c/sin C.

Иллюстрация: треугольник ABC, каждая сторона подписана рядом с противолежащим углом того же цвета, формула снизу.

### Карточка 2 из 4 — «Расширенная теорема синусов»
ЗАГОЛОВОК: ТЕОРЕМА СИНУСОВ / СВЯЗЬ С ОПИСАННОЙ ОКРУЖНОСТЬЮ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ТЕОРЕМА (РАСШИРЕННАЯ)
Формула в рамке: a/sin A = b/sin B = c/sin C = 2R, где R — радиус окружности, описанной около треугольника.

Врезка «Почему это так?»: Вписанный угол, опирающийся на сторону как на хорду, связан с этой хордой через диаметр описанной окружности — отсюда постоянное отношение 2R.

Иллюстрация: треугольник ABC, вписанный в окружность радиуса R с центром O, сторона a и противолежащий угол A выделены цветом.

### Карточка 3 из 4 — «Применение теоремы синусов»
ЗАГОЛОВОК: ТЕОРЕМА СИНУСОВ / ПРИМЕНЕНИЕ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРИМЕР
Условие: угол A = 30°, угол B = 45°, сторона a = 10. Найти сторону b.
Решение в рамке: a/sin A = b/sin B ⇒ b = a·sin B/sin A = 10 · (√2/2) / (1/2) = 10√2 ≈ 14.1.

Иллюстрация: треугольник с подписанными углами 30° и 45°, сторона a=10 напротив угла A, искомая сторона b напротив угла B.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ТЕОРЕМА СИНУСОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: сторона треугольника 12 см лежит против угла 30°. Найти радиус описанной окружности.
Решение в рамке: 2R = a/sin A = 12/0.5 = 24 ⇒ R = 12 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- a/sin A = b/sin B = c/sin C — постоянное отношение для любого треугольника.
- Это отношение равно 2R (диаметру описанной окружности).
- Теорема синусов удобна, когда известны угол и противолежащая сторона.

## Тема 3.4. Формулы площади треугольника

### Карточка 1 из 4 — «Площадь через синус угла»
ЗАГОЛОВОК: ФОРМУЛЫ ПЛОЩАДИ ТРЕУГОЛЬНИКА / ЧЕРЕЗ ДВЕ СТОРОНЫ И УГОЛ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
Формула в рамке: площадь треугольника равна половине произведения двух сторон на синус угла между ними: S = (1/2)·a·b·sin C.

Врезка «Почему это так?»: Высота, опущенная на сторону a, равна b·sin C — подставляя в обычную формулу S=(a·h)/2, получаем эту формулу.

Иллюстрация: треугольник со сторонами a и b, углом C между ними, высота h = b·sin C показана пунктиром.

### Карточка 2 из 4 — «Площадь через радиус описанной окружности»
ЗАГОЛОВОК: ФОРМУЛЫ ПЛОЩАДИ ТРЕУГОЛЬНИКА / ЧЕРЕЗ R. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: S = (a·b·c) / (4R), где R — радиус описанной окружности.

Иллюстрация: треугольник, вписанный в окружность радиуса R, все три стороны подписаны.

### Карточка 3 из 4 — «Площадь через радиус вписанной окружности»
ЗАГОЛОВОК: ФОРМУЛЫ ПЛОЩАДИ ТРЕУГОЛЬНИКА / ЧЕРЕЗ r И ФОРМУЛА ГЕРОНА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛЫ
Формула в рамке: S = r · p, где r — радиус вписанной окружности, p — полупериметр (p = (a+b+c)/2).
2. ФОРМУЛА ГЕРОНА
Формула в рамке: S = √(p(p−a)(p−b)(p−c)).

Иллюстрация: треугольник со вписанной окружностью радиуса r, отрезки от центра до сторон отмечены как r, рядом формула Герона.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ФОРМУЛЫ ПЛОЩАДИ ТРЕУГОЛЬНИКА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: стороны треугольника a=5, b=6, угол между ними C=60°. Найти площадь.
Решение в рамке: S = (1/2)·5·6·sin60° = 15·(√3/2) = 7.5√3 ≈ 13 см².
2. ЧТО НУЖНО ЗАПОМНИТЬ
- S = (1/2)ab·sin C — универсальная формула через две стороны и угол.
- S = abc/(4R) и S = r·p — формулы через радиусы окружностей.
- Формула Герона нужна, когда известны все три стороны.

## Тема 3.5. Скалярное произведение векторов

### Карточка 1 из 4 — «Угол между векторами и определение»
ЗАГОЛОВОК: СКАЛЯРНОЕ ПРОИЗВЕДЕНИЕ ВЕКТОРОВ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. УГОЛ МЕЖДУ ВЕКТОРАМИ
- Угол между ненулевыми векторами a→ и b→ — угол между лучами, на которых лежат эти векторы, если их отложить от общей точки.
2. ОПРЕДЕЛЕНИЕ
Формула в рамке: скалярное произведение a→ · b→ = |a→| · |b→| · cos φ, где φ — угол между векторами.

Иллюстрация: два вектора a→ и b→, отложенные от общей точки, угол φ между ними отмечен дугой.

### Карточка 2 из 4 — «Скалярное произведение в координатах»
ЗАГОЛОВОК: СКАЛЯРНОЕ ПРОИЗВЕДЕНИЕ ВЕКТОРОВ / В КООРДИНАТАХ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: если a→=(x₁;y₁), b→=(x₂;y₂), то a→ · b→ = x₁x₂ + y₁y₂.

Врезка «Запомни!»: Скалярное произведение вектора самого на себя равно квадрату его длины: a→ · a→ = |a→|².

Иллюстрация: два вектора на координатной плоскости с подписанными координатами и вычислением их произведения.

### Карточка 3 из 4 — «Условие перпендикулярности векторов»
ЗАГОЛОВОК: СКАЛЯРНОЕ ПРОИЗВЕДЕНИЕ ВЕКТОРОВ / ПЕРПЕНДИКУЛЯРНОСТЬ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
Формула в рамке: ненулевые векторы a→ и b→ перпендикулярны тогда и только тогда, когда a→ · b→ = 0.

Врезка «Почему это так?»: При φ = 90° cos φ = 0, значит и всё произведение |a→|·|b→|·cos φ равно 0.

Иллюстрация: два перпендикулярных вектора, отмеченных прямым углом (квадратик), рядом подпись «a→ · b→ = 0».

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: СКАЛЯРНОЕ ПРОИЗВЕДЕНИЕ ВЕКТОРОВ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: a→ = (3; 4), b→ = (4; −3). Проверить, перпендикулярны ли векторы.
Решение в рамке: a→ · b→ = 3·4 + 4·(−3) = 12 − 12 = 0 ⇒ векторы перпендикулярны.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- a→ · b→ = |a→|·|b→|·cos φ — определение через длины и угол.
- a→ · b→ = x₁x₂ + y₁y₂ — вычисление через координаты.
- a→ · b→ = 0 ⇔ векторы перпендикулярны (для ненулевых векторов).
