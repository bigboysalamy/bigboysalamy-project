## Тема 4.1. Правильные многоугольники

### Карточка 1 из 4 — «Определение»
ЗАГОЛОВОК: ПРАВИЛЬНЫЕ МНОГОУГОЛЬНИКИ / ОПРЕДЕЛЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Правильный многоугольник — выпуклый многоугольник, у которого все стороны равны и все углы равны.
- Примеры: равносторонний треугольник, квадрат, правильный пятиугольник, правильный шестиугольник.
2. ФОРМУЛА УГЛА
Формула в рамке: угол правильного n-угольника равен (n−2)·180°/n.

Иллюстрация: ряд правильных многоугольников от треугольника до восьмиугольника, каждый вписан в свою окружность.

### Карточка 2 из 4 — «Окружности, вписанная и описанная около правильного многоугольника»
ЗАГОЛОВОК: ПРАВИЛЬНЫЕ МНОГОУГОЛЬНИКИ / ВПИСАННАЯ И ОПИСАННАЯ ОКРУЖНОСТИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ТЕОРЕМА
- Около любого правильного многоугольника можно описать окружность, и в него можно вписать окружность, причём центры обеих окружностей совпадают — это центр правильного многоугольника.

Врезка «Запомни!»: Радиус вписанной окружности называют апофемой правильного многоугольника.

Иллюстрация: правильный шестиугольник с центром O, описанная окружность через вершины, вписанная окружность, касающаяся середин сторон, апофема подписана.

### Карточка 3 из 4 — «Формулы стороны, площади и апофемы»
ЗАГОЛОВОК: ПРАВИЛЬНЫЕ МНОГОУГОЛЬНИКИ / ФОРМУЛЫ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛЫ (R — радиус описанной окружности)
- Сторона: a = 2R·sin(180°/n).
- Апофема: r = R·cos(180°/n).
- Площадь: S = (1/2)·P·r, где P — периметр многоугольника.

Иллюстрация: правильный n-угольник, один треугольник (из центра до двух соседних вершин) выделен цветом с подписанными R, r, центральным углом 360°/n.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПРАВИЛЬНЫЕ МНОГОУГОЛЬНИКИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: сторона правильного шестиугольника равна радиусу описанной окружности. Почему это так? Проверить формулой.
Решение в рамке: a = 2R·sin(180°/6) = 2R·sin30° = 2R·0.5 = R — подтверждено формулой.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- В правильном многоугольнике все стороны и углы равны, центры вписанной и описанной окружностей совпадают.
- Апофема — радиус вписанной окружности.
- Площадь правильного многоугольника: S = (1/2)·P·r.

## Тема 4.2. Длина окружности

### Карточка 1 из 4 — «Число π и формула длины окружности»
ЗАГОЛОВОК: ДЛИНА ОКРУЖНОСТИ / ФОРМУЛА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ЧИСЛО π
- Отношение длины окружности к её диаметру одинаково для всех окружностей — это число обозначают π (пи), π ≈ 3.14159.
2. ФОРМУЛА
Формула в рамке: длина окружности C = π·D = 2π·R.

Иллюстрация: окружность радиуса R, рядом «развёрнутая» в отрезок длина окружности с подписью 2πR.

### Карточка 2 из 4 — «Вывод через периметры правильных многоугольников»
ЗАГОЛОВОК: ДЛИНА ОКРУЖНОСТИ / ИДЕЯ ВЫВОДА ФОРМУЛЫ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ИДЕЯ
- При увеличении числа сторон n правильного многоугольника, вписанного в окружность, его периметр всё точнее приближается к длине окружности.
- Именно так исторически и определяли и вычисляли число π.

Иллюстрация: три вписанных в одну окружность многоугольника — шестиугольник, двенадцатиугольник, двадцатичетырёхугольник — показывающие, как контур приближается к окружности.

### Карточка 3 из 4 — «Длина дуги окружности»
ЗАГОЛОВОК: ДЛИНА ОКРУЖНОСТИ / ДЛИНА ДУГИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: длина дуги окружности с центральным углом α° равна l = (π·R·α) / 180°.

Иллюстрация: окружность радиуса R с выделенной дугой, соответствующей центральному углу α, подпись формулы рядом.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ДЛИНА ОКРУЖНОСТИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: радиус окружности 6 см. Найти длину окружности и длину дуги с центральным углом 60°.
Решение в рамке: C = 2π·6 = 12π ≈ 37.7 см; l = (π·6·60)/180 = 2π ≈ 6.28 см.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- C = 2πR — длина окружности.
- l = πRα/180° — длина дуги с центральным углом α (в градусах).
- π — постоянное отношение длины окружности к диаметру.

## Тема 4.3. Площадь круга

### Карточка 1 из 4 — «Формула площади круга»
ЗАГОЛОВОК: ПЛОЩАДЬ КРУГА / ФОРМУЛА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: площадь круга радиуса R равна S = π·R².

Иллюстрация: круг радиуса R, закрашенный светло-голубым цветом, формула площади подписана внутри или рядом.

### Карточка 2 из 4 — «Идея вывода формулы»
ЗАГОЛОВОК: ПЛОЩАДЬ КРУГА / ИДЕЯ ВЫВОДА. Индикатор: 2 из 4.

КОНТЕНТ:
1. ИДЕЯ
- Площадь круга — предел площадей правильных n-угольников, вписанных в окружность, при неограниченном увеличении n.
- Площадь такого многоугольника S = (1/2)·P·r стремится к (1/2)·(2πR)·R = πR², так как P → 2πR, r → R.

Иллюстрация: вписанный в окружность многоугольник с большим числом сторон (например 16-угольник), почти сливающийся с окружностью.

### Карточка 3 из 4 — «Площадь кругового сектора»
ЗАГОЛОВОК: ПЛОЩАДЬ КРУГА / ПЛОЩАДЬ СЕКТОРА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ И ФОРМУЛА
- Круговой сектор — часть круга, ограниченная двумя радиусами и дугой между ними.
Формула в рамке: площадь сектора с центральным углом α°: S = (π·R²·α) / 360°.

Иллюстрация: круг с выделенным закрашенным сектором с центральным углом α, формула рядом.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПЛОЩАДЬ КРУГА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: радиус круга 10 см. Найти площадь круга и площадь сектора с углом 90°.
Решение в рамке: S(круга) = π·100 ≈ 314 см²; S(сектора) = π·100·90/360 = 25π ≈ 78.5 см².
2. ЧТО НУЖНО ЗАПОМНИТЬ
- S(круга) = πR².
- S(сектора) = πR²α/360° — доля площади круга, пропорциональная центральному углу.
- Сектор с углом 90° — четверть круга.
