## Тема 2.1. Координаты вектора

### Карточка 1 из 4 — «Разложение вектора по координатным векторам»
ЗАГОЛОВОК: КООРДИНАТЫ ВЕКТОРА / РАЗЛОЖЕНИЕ ПО ОСЯМ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- i→ и j→ — единичные векторы координатных осей Ox и Oy (орты).
- Любой вектор a→ можно единственным образом разложить: a→ = x·i→ + y·j→, где x и y — координаты вектора a→.
Формула в рамке: записывают a→ = (x; y).

Иллюстрация: координатная плоскость, векторы i→ (вдоль Ox) и j→ (вдоль Oy), вектор a→ показан как сумма x·i→ и y·j→ пунктирными проекциями.

### Карточка 2 из 4 — «Координаты вектора через координаты точек»
ЗАГОЛОВОК: КООРДИНАТЫ ВЕКТОРА / ЧЕРЕЗ НАЧАЛО И КОНЕЦ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: если A(x₁; y₁), B(x₂; y₂), то вектор AB→ имеет координаты (x₂ − x₁; y₂ − y₁).

Иллюстрация: координатная плоскость с точками A и B, подписанными координатами, стрелка AB между ними, рядом вычисление разности координат.

### Карточка 3 из 4 — «Действия над векторами в координатах»
ЗАГОЛОВОК: КООРДИНАТЫ ВЕКТОРА / ДЕЙСТВИЯ В КООРДИНАТАХ. Индикатор: 3 из 4.

КОНТЕНТ:
1. ПРАВИЛА
- При сложении векторов их соответствующие координаты складываются: (x₁;y₁) + (x₂;y₂) = (x₁+x₂; y₁+y₂).
- При вычитании — вычитаются: (x₁;y₁) − (x₂;y₂) = (x₁−x₂; y₁−y₂).
- При умножении на число k — обе координаты умножаются на k: k·(x;y) = (kx; ky).

Иллюстрация: два вектора a→=(2;3) и b→=(1;-1) на плоскости и их сумма a+b=(3;2), показанная построением.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: КООРДИНАТЫ ВЕКТОРА / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: A(1; 2), B(4; 6). Найти координаты вектора AB→.
Решение в рамке: AB→ = (4−1; 6−2) = (3; 4).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Координаты вектора = координаты конца минус координаты начала.
- При сложении/вычитании векторов координаты складываются/вычитаются отдельно.
- При умножении на число обе координаты умножаются на это число.

## Тема 2.2. Простейшие задачи в координатах

### Карточка 1 из 4 — «Длина вектора по координатам»
ЗАГОЛОВОК: ПРОСТЕЙШИЕ ЗАДАЧИ / ДЛИНА ВЕКТОРА. Индикатор: 1 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: длина вектора a→ = (x; y) равна |a→| = √(x² + y²).

Врезка «Почему это так?»: Это теорема Пифагора: x и y — катеты прямоугольного треугольника, а |a→| — гипотенуза.

Иллюстрация: вектор a→=(3;4) на координатной плоскости, пунктирные проекции на оси длиной 3 и 4, гипотенуза-вектор длиной 5.

### Карточка 2 из 4 — «Расстояние между точками»
ЗАГОЛОВОК: ПРОСТЕЙШИЕ ЗАДАЧИ / РАССТОЯНИЕ МЕЖДУ ТОЧКАМИ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: расстояние между точками A(x₁;y₁) и B(x₂;y₂): AB = √((x₂−x₁)² + (y₂−y₁)²).

Иллюстрация: точки A и B на координатной плоскости, прямоугольный треугольник с катетами (x₂−x₁) и (y₂−y₁), гипотенуза AB.

### Карточка 3 из 4 — «Координаты середины отрезка»
ЗАГОЛОВОК: ПРОСТЕЙШИЕ ЗАДАЧИ / СЕРЕДИНА ОТРЕЗКА. Индикатор: 3 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: координаты середины отрезка AB, где A(x₁;y₁), B(x₂;y₂): x = (x₁+x₂)/2, y = (y₁+y₂)/2.

Иллюстрация: отрезок AB на координатной плоскости, точка M посередине, подписаны координаты всех трёх точек.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: ПРОСТЕЙШИЕ ЗАДАЧИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: A(2; -1), B(6; 3). Найти расстояние AB и координаты середины отрезка AB.
Решение в рамке: AB = √((6−2)²+(3−(−1))²) = √(16+16) = √32 = 4√2; середина: ((2+6)/2; (−1+3)/2) = (4; 1).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- |a→| = √(x² + y²) — длина вектора по координатам.
- Расстояние между точками — тот же корень из суммы квадратов разностей координат.
- Координаты середины отрезка — среднее арифметическое координат концов.

## Тема 2.3. Уравнение окружности

### Карточка 1 из 4 — «Вывод уравнения окружности»
ЗАГОЛОВОК: УРАВНЕНИЕ ОКРУЖНОСТИ / ВЫВОД УРАВНЕНИЯ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ВЫВОД
- Окружность с центром C(a; b) и радиусом R — множество точек M(x;y), для которых CM = R.
- По формуле расстояния: √((x−a)² + (y−b)²) = R.
Формула в рамке: (x − a)² + (y − b)² = R² — уравнение окружности с центром (a;b) и радиусом R.

Иллюстрация: окружность на координатной плоскости с центром в точке (a;b), точка M на окружности, отрезок CM = R.

### Карточка 2 из 4 — «Окружность с центром в начале координат»
ЗАГОЛОВОК: УРАВНЕНИЕ ОКРУЖНОСТИ / ЧАСТНЫЙ СЛУЧАЙ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ЧАСТНЫЙ СЛУЧАЙ
Формула в рамке: если центр окружности — начало координат O(0;0), уравнение упрощается: x² + y² = R².

Иллюстрация: окружность с центром в точке O(0;0), радиус R подписан вдоль оси Ox.

### Карточка 3 из 4 — «Проверка принадлежности точки окружности»
ЗАГОЛОВОК: УРАВНЕНИЕ ОКРУЖНОСТИ / ПРОВЕРКА ТОЧКИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. АЛГОРИТМ
- Чтобы проверить, лежит ли точка M(x₀;y₀) на окружности (x−a)²+(y−b)²=R², подставляют координаты точки в левую часть уравнения.
- Если получилось R² — точка на окружности; если меньше R² — внутри круга; если больше — вне круга.

Иллюстрация: окружность, точка внутри (закрашена зелёным), точка на окружности (синим), точка снаружи (красным), с подписанными результатами подстановки.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: УРАВНЕНИЕ ОКРУЖНОСТИ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: составить уравнение окружности с центром (2; −3) и радиусом 5.
Решение в рамке: (x − 2)² + (y + 3)² = 25.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- (x−a)² + (y−b)² = R² — уравнение окружности с центром (a;b), радиусом R.
- x² + y² = R² — окружность с центром в начале координат.
- Подстановка координат точки в уравнение проверяет её положение относительно окружности.

## Тема 2.4. Уравнение прямой

### Карточка 1 из 4 — «Вывод уравнения прямой»
ЗАГОЛОВОК: УРАВНЕНИЕ ПРЯМОЙ / ОБЩЕЕ УРАВНЕНИЕ. Индикатор: 1 из 4.

КОНТЕНТ:
1. ОПРЕДЕЛЕНИЕ
- Уравнение вида ax + by + c = 0 (где a и b не равны нулю одновременно) называется уравнением прямой на плоскости — ему удовлетворяют координаты всех точек этой прямой и только они.

Иллюстрация: прямая на координатной плоскости, подписано её общее уравнение ax+by+c=0, отмечены 2-3 точки, лежащие на ней.

### Карточка 2 из 4 — «Уравнение прямой с угловым коэффициентом»
ЗАГОЛОВОК: УРАВНЕНИЕ ПРЯМОЙ / УГЛОВОЙ КОЭФФИЦИЕНТ. Индикатор: 2 из 4.

КОНТЕНТ:
1. ФОРМУЛА
Формула в рамке: y = kx + m, где k — угловой коэффициент (тангенс угла наклона прямой к оси Ox), m — координата точки пересечения с осью Oy.

Врезка «Запомни!»: Чем больше |k|, тем круче наклон прямой; при k=0 прямая горизонтальна.

Иллюстрация: координатная плоскость с несколькими прямыми разного наклона (k=1, k=2, k=0), точка пересечения с Oy подписана как m.

### Карточка 3 из 4 — «Уравнение прямой через две точки. Условие параллельности»
ЗАГОЛОВОК: УРАВНЕНИЕ ПРЯМОЙ / ЧЕРЕЗ ДВЕ ТОЧКИ. Индикатор: 3 из 4.

КОНТЕНТ:
1. УРАВНЕНИЕ ЧЕРЕЗ ДВЕ ТОЧКИ
- Через любые две несовпадающие точки A(x₁;y₁), B(x₂;y₂) проходит единственная прямая.
2. УСЛОВИЕ ПАРАЛЛЕЛЬНОСТИ
Формула в рамке: две прямые y = k₁x + m₁ и y = k₂x + m₂ параллельны тогда и только тогда, когда k₁ = k₂.

Иллюстрация: две параллельные прямые с одинаковым наклоном (одинаковый k), подписанным на каждой.

### Карточка 4 из 4 — «Итог темы»
ЗАГОЛОВОК: УРАВНЕНИЕ ПРЯМОЙ / ОТРАБОТКА И ИТОГ. Индикатор: 4 из 4.

КОНТЕНТ:
1. РАЗБОР ЗАДАЧИ
Условие: составить уравнение прямой, проходящей через точку (0; 3) с угловым коэффициентом k = 2.
Решение в рамке: y = 2x + 3 (так как m = 3 — точка пересечения с осью Oy).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Общее уравнение прямой: ax + by + c = 0.
- Уравнение с угловым коэффициентом: y = kx + m.
- Прямые параллельны ⇔ равны их угловые коэффициенты.
