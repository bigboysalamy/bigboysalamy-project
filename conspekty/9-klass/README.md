# Конспекты по геометрии, 9 класс

Промпты для генерации карточек-конспектов через ChatGPT (image generation) —
формат и правила использования такие же, как для 7 и 8 классов
(см. `conspekty/7-klass/README.md`). Источник материала: yaklass.ru →
Геометрия, 9 класс, структура совпадает с программой (учебник Атанасяна).

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Для каждой карточки вставь СТИЛЬ + КОНТЕНТ карточки одним сообщением в ChatGPT.
3. Не забывай указывать номер карточки в серии (X из 4).

## Содержание (главы по программе 9 класса)

- `01-vektory.md` — Векторы (4 темы × 4 карточки = 16)
- `02-metod-koordinat.md` — Метод координат (4 темы × 4 карточки = 16)
- `03-sootnosheniya-i-skalyarnoe-proizvedenie.md` — Соотношения между сторонами и углами треугольника. Скалярное произведение векторов (5 тем × 4 карточки = 20)
- `04-dlina-okruzhnosti-i-ploshchad-kruga.md` — Длина окружности и площадь круга (4 темы × 4 карточки = 16)
- `05-dvizheniya.md` — Движения (4 темы × 4 карточки = 16)

Итого: 21 тема, 84 карточки-промпта.
