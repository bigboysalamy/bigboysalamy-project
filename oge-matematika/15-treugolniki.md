# Задание 15. Треугольники и их элементы

## Тема 15-А. Углы треугольника (вариации 15.1–15.5)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / УГЛЫ ТРЕУГОЛЬНИКА: ТЕОРИЯ. Плашка: вариации 15.1–15.5.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 15.1: два угла даны — найти третий.
- 15.2: дан угол — найти внешний при той же вершине.
- 15.3: острый угол прямоугольного треугольника — найти второй.
- 15.4: равнобедренный, дан угол при вершине — найти угол при основании.
- 15.5: равнобедренный, дан внешний угол при основании — найти угол при вершине.
2. ТЕОРИЯ (формулы в рамках)
- Сумма углов треугольника: ∠A+∠B+∠C = 180°.
- Внешний угол = 180° − внутренний = сумме двух несмежных внутренних.
- В прямоугольном: сумма острых углов = 90°.
- В равнобедренном углы при основании равны.

Иллюстрация: треугольник с тремя углами и внешним углом при одной вершине, формулы рядом.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / УГЛЫ ТРЕУГОЛЬНИКА: МЕТОД. Плашка: вариации 15.1–15.5.

КОНТЕНТ:
1. АЛГОРИТМ
- Определи вид треугольника (произвольный/прямоугольный/равнобедренный).
- Запиши уравнение на 180° (или 90° для острых углов прямоугольного).
- Реши уравнение на неизвестный угол.

Врезка «Ловушка!»: В равнобедренном треугольнике равны углы ПРИ ОСНОВАНИИ. Если AB=BC, то основание — AC, и равны ∠A и ∠C (а не тот угол, что «выглядит» симметрично на рисунке).

Иллюстрация: равнобедренный треугольник с отмеченными равными углами при основании.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / УГЛЫ ТРЕУГОЛЬНИКА: РАЗБОР. Плашка: вариации 15.1–15.5.

КОНТЕНТ:
1. РАЗБОРЫ
- 15.1: 180−28−93 = 59°.
- 15.2: внешний при C = 180−97 = 83°.
- 15.3: 90−18 = 72°.
- 15.4: AB=BC, ∠ABC=102° ⇒ ∠BCA = (180−102)/2 = 39°.
- 15.5: внешний при C = 123° ⇒ ∠BCA = 57° = ∠BAC ⇒ ∠ABC = 180−2·57 = 66°.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- 180° — главное число задания 15.
- Внешний угол — смежный с внутренним (в сумме 180°).

Иллюстрация: пять маленьких треугольников с ответами.

## Тема 15-Б. Медиана, биссектриса, высота и средняя линия (вариации 15.6–15.17)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / МЕДИАНА, БИССЕКТРИСА, ВЫСОТА, СРЕДНЯЯ ЛИНИЯ: ТЕОРИЯ. Плашка: вариации 15.6–15.17.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 15.6/15.7: биссектриса — половина угла; равнобедренные конфигурации с AK=CK.
- 15.8: высота в остроугольном — угол ABH = 90°−∠A.
- 15.9: медиана BM=AM=MC — прямой угол B (медиана равна половине стороны).
- 15.10: медиана делит сторону пополам: AM = AC/2.
- 15.11–15.16: равносторонний треугольник — связь стороны a и высоты/медианы/биссектрисы h = a√3/2 (в обе стороны).
- 15.17: средняя линия MN = AC/2.
2. ФОРМУЛЫ (в рамках)
- Высота (=медиана=биссектриса) равностороннего треугольника: h = a·√3/2; обратно a = 2h/√3.
- Средняя линия параллельна стороне и равна её половине.
- Если медиана равна половине стороны, к которой проведена, — треугольник прямоугольный.

Иллюстрация: равносторонний треугольник с высотой, подписанной a√3/2; отдельно треугольник со средней линией.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / МЕДИАНА, БИССЕКТРИСА, ВЫСОТА: МЕТОД. Плашка: вариации 15.6–15.17.

КОНТЕНТ:
1. АЛГОРИТМ
- Определи, какой элемент дан: медиана (делит сторону пополам), биссектриса (делит угол пополам), высота (перпендикуляр), средняя линия (соединяет середины).
- Примени соответствующее свойство напрямую.
- Для равностороннего треугольника — формула h = a√3/2 в нужную сторону.
2. РАВНОБЕДРЕННЫЕ КОНФИГУРАЦИИ (15.7, 15.9)
- AK=CK ⇒ треугольник AKC равнобедренный ⇒ ∠KAC=∠C; дальше счёт углов.

Врезка «Ловушка!»: Медиана 9√3 равностороннего треугольника ⇒ сторона a = 2·9√3/√3 = 18. Корень √3 сокращается — ответ целый; если корень остался, проверь вычисления.

Иллюстрация: преобразование a = 2h/√3 с сокращением корня.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / МЕДИАНА, БИССЕКТРИСА, ВЫСОТА: РАЗБОР. Плашка: вариации 15.6–15.17.

КОНТЕНТ:
1. РАЗБОРЫ
- 15.6: биссектриса AD делит ∠BAC=24° пополам ⇒ ∠BAD = 12°.
- 15.8: ∠ABH = 90° − 9° = 81°.
- 15.9: BM=AM=MC ⇒ ∠B = 90° ⇒ ∠A = 90−57 = 33°.
- 15.10: AM = 12/2 = 6 (длина медианы BM=11 — отвлекающие данные!).
- 15.11: медиана 9√3 ⇒ сторона = 18.
- 15.16: сторона 10√3 ⇒ высота = 10√3·√3/2 = 15.
- 15.17: MN = 26/2 = 13 (стороны 24 и 13 — лишние данные).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- В вариациях 15.10 и 15.17 есть лишние числа — не дай им себя запутать.
- Средняя линия смотрит на ТРЕТЬЮ сторону (которой параллельна).

Иллюстрация: семь мини-чертежей с ответами.

## Тема 15-В. Площадь треугольника (вариации 15.18–15.20)

### Карточка 1 из 2 — «Теория и метод»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / ПЛОЩАДЬ ТРЕУГОЛЬНИКА: ТЕОРИЯ И МЕТОД. Плашка: вариации 15.18–15.20.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 15.18: по двум катетам.
- 15.19: по двум сторонам и синусу угла между ними.
- 15.20: по стороне и высоте к ней.
2. ФОРМУЛЫ (в рамках)
- Прямоугольный: S = (катет₁·катет₂)/2.
- Общий случай: S = (1/2)·a·h.
- Через синус: S = (1/2)·a·b·sin∠(a,b).
3. АЛГОРИТМ
- Выбери формулу по тому, что дано; подставь; не забудь 1/2.

Иллюстрация: три треугольника — прямоугольный с катетами, с высотой, с углом между сторонами — и три формулы.

### Карточка 2 из 2 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / ПЛОЩАДЬ ТРЕУГОЛЬНИКА: РАЗБОР. Плашка: вариации 15.18–15.20.

КОНТЕНТ:
1. РАЗБОРЫ
- 15.18: S = 4·9/2 = 18.
- 15.19: S = (1/2)·6·10·(1/3) = 10.
- 15.20: S = (1/2)·8·31 = 124.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Забытая 1/2 — ошибка №1 в задачах на площадь.
- Формула с синусом работает для ЛЮБОГО угла между данными сторонами.

Иллюстрация: три коротких вычисления с ответами в зелёных рамках.

## Тема 15-Г. Прямоугольный треугольник (вариации 15.21–15.28)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / ПРЯМОУГОЛЬНЫЙ ТРЕУГОЛЬНИК: ТЕОРИЯ. Плашка: вариации 15.21–15.28.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 15.21/15.22: теорема Пифагора — найти гипотенузу или катет.
- 15.23–15.28: тригонометрия острого угла: найти sin/cos/tg или сторону через них.
2. ФОРМУЛЫ (в рамках)
- c² = a² + b² (Пифагор).
- sinB = противолежащий катет / гипотенуза = AC/AB.
- cosB = прилежащий катет / гипотенуза = BC/AB.
- tgB = противолежащий / прилежащий = AC/BC.

Иллюстрация: прямоугольный треугольник ABC (∠C=90°) с подписанными «противолежащий/прилежащий к углу B» на катетах.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / ПРЯМОУГОЛЬНЫЙ ТРЕУГОЛЬНИК: МЕТОД. Плашка: вариации 15.21–15.28.

КОНТЕНТ:
1. АЛГОРИТМ
- Отметь прямой угол и пойми, какая сторона гипотенуза (напротив 90°).
- Для Пифагора: c=√(a²+b²) или катет=√(c²−a²).
- Для тригонометрии: подпиши, какой катет противолежит углу, какой прилежит, и выбери отношение.
- Из уравнения sinB = x/c выражай неизвестную сторону умножением.

Врезка «Ловушка!»: «Противолежащий» определяется ОТНОСИТЕЛЬНО УГЛА: для угла B противолежащий катет — AC (не содержит буквы B!). Пифагоровы тройки 3-4-5, 5-12-13, 7-24-25, 8-15-17 экономят время.

Иллюстрация: треугольник с выделенным углом B и стрелкой к противолежащему катету AC.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 15 / ПРЯМОУГОЛЬНЫЙ ТРЕУГОЛЬНИК: РАЗБОР. Плашка: вариации 15.21–15.28.

КОНТЕНТ:
1. РАЗБОРЫ
- 15.21: c = √(7²+24²) = √625 = 25 (тройка 7-24-25).
- 15.22: катет = √(13²−5²) = √144 = 12.
- 15.23: sinB = AC/AB = 4/5 = 0,8.
- 15.24: AC = AB·sinB = 21·(3/7) = 9.
- 15.25: cosB = BC/AB = 7/20 = 0,35.
- 15.26: BC = AB·cosB = 10·(2/5) = 4.
- 15.27: AC = BC·tgB = 12·(3/4) = 9.
- 15.28: tgB = AC/BC = 3/5 = 0,6.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- sin — «напротив», cos — «рядом», tg — их отношение.
- Дробный ответ переводи в десятичную запись (0,8, а не 4/5).

Иллюстрация: восемь мини-чертежей с ответами.
