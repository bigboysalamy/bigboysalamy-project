## Тема 13-А. Линейные неравенства (вариация 13.1)

### Карточка 1 из 2 — «Теория и метод»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / ЛИНЕЙНЫЕ НЕРАВЕНСТВА: ТЕОРИЯ И МЕТОД. Плашка: вариация 13.1.

КОНТЕНТ:
1. ТИП ВАРИАЦИИ
- Указать решение неравенства вида −3−x < 4x+7 среди четырёх интервалов.
2. ТЕОРИЯ
- Перенос слагаемых через знак неравенства — со сменой знака слагаемого.
- Деление обеих частей на ПОЛОЖИТЕЛЬНОЕ число не меняет знак неравенства; на ОТРИЦАТЕЛЬНОЕ — меняет на противоположный.
3. АЛГОРИТМ
- Собери x слева, числа справа; раздели на коэффициент, следя за его знаком; сопоставь с вариантами интервалов.

Иллюстрация: неравенство с переносами-стрелками и числовая прямая с заштрихованным лучом.

### Карточка 2 из 2 — «Разбор вариации»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / ЛИНЕЙНЫЕ НЕРАВЕНСТВА: РАЗБОР. Плашка: вариация 13.1.

КОНТЕНТ:
1. РАЗБОР 13.1
- −3−x < 4x+7 ⇒ −x−4x < 7+3 ⇒ −5x < 10 ⇒ x > −2 (знак сменился при делении на −5).
- Ответ: интервал (−2; +∞) — вариант 2.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Деление на отрицательное число = разворот знака неравенства.
- Строгое неравенство ⇒ круглая скобка у границы.

Иллюстрация: решение с выделенной сменой знака и лучом (−2; +∞) на прямой.

## Тема 13-Б. Линейные системы неравенств (вариации 13.2–13.3)

### Карточка 1 из 2 — «Теория и метод»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / СИСТЕМЫ НЕРАВЕНСТВ: ТЕОРИЯ И МЕТОД. Плашка: вариации 13.2–13.3.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 13.2: система {x+3 ≥ −2; x+1,1 ≥ 0} — выбрать штриховку на прямой.
- 13.3: система {x−2,6 ≤ 0; x−1 ≥ 1} — выбрать интервал.
2. ТЕОРИЯ И АЛГОРИТМ
- Реши каждое неравенство отдельно.
- Отметь оба решения на одной прямой.
- Решение системы = ПЕРЕСЕЧЕНИЕ (общая часть) лучей/отрезков.

Врезка «Ловушка!»: Если оба неравенства «смотрят в одну сторону» (x≥−5 и x≥−1,1), пересечение — более сильное условие: x≥−1,1, а не объединение!

Иллюстрация: две штриховки на одной прямой, общая часть выделена третьим цветом.

### Карточка 2 из 2 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / СИСТЕМЫ НЕРАВЕНСТВ: РАЗБОР. Плашка: вариации 13.2–13.3.

КОНТЕНТ:
1. РАЗБОРЫ
- 13.2: x ≥ −5 и x ≥ −1,1 ⇒ пересечение: x ≥ −1,1 (луч от −1,1 вправо).
- 13.3: x ≤ 2,6 и x ≥ 2 ⇒ пересечение: [2; 2,6]. Ответ: 1.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Система = «И», решение — пересечение множеств.
- Нестрогие неравенства дают квадратные скобки/закрашенные точки.

Иллюстрация: два разбора на числовых прямых с выделенным пересечением.

## Тема 13-В. Квадратичные неравенства (вариации 13.4–13.10)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / КВАДРАТИЧНЫЕ НЕРАВЕНСТВА: ТЕОРИЯ. Плашка: вариации 13.4–13.10.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 13.4/13.5: x−x² ≥ 0 и x−x² < 0 — с выносом множителя.
- 13.6/13.7: уже разложенные: (x+1)(x−6) ≤ 0; (x+3)(x−6) > 0.
- 13.8/13.9: вида x² < 9; x²−25 > 0.
- 13.10: ОБРАТНАЯ задача — по рисунку штриховки выбрать неравенство.
2. ТЕОРИЯ (метод параболы)
- Найди корни квадратного трёхчлена — это точки смены знака.
- Ветви вверх (a>0): «+» вне корней, «−» между корнями.
- Ветви вниз (a<0): наоборот.

Иллюстрация: парабола с корнями и подписанными знаками «+ − +» на трёх участках прямой.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / КВАДРАТИЧНЫЕ НЕРАВЕНСТВА: МЕТОД. Плашка: вариации 13.4–13.10.

КОНТЕНТ:
1. АЛГОРИТМ
- Разложи на множители (вынеси x или примени разность квадратов), найди корни.
- Нарисуй эскиз параболы или расставь знаки по интервалам.
- Выбери интервалы нужного знака, учитывая строгость (≤,≥ — границы включаются).

Врезка «Ловушка!»: x−x² ≥ 0 — здесь a = −1 (ветви ВНИЗ): x(1−x) ≥ 0 выполняется МЕЖДУ корнями: [0; 1]. Не решай по привычной схеме «вне корней»!

Иллюстрация: перевёрнутая парабола y=x−x² с положительной частью между 0 и 1, закрашенной зелёным.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 13 / КВАДРАТИЧНЫЕ НЕРАВЕНСТВА: РАЗБОР. Плашка: вариации 13.4–13.10.

КОНТЕНТ:
1. РАЗБОРЫ
- 13.4: x−x² ≥ 0 ⇒ x∈[0;1] (отрезок между корнями, ветви вниз).
- 13.5: x−x² < 0 ⇒ x∈(−∞;0)∪(1;+∞).
- 13.6: (x+1)(x−6) ≤ 0 ⇒ x∈[−1;6].
- 13.7: (x+3)(x−6) > 0 ⇒ x∈(−∞;−3)∪(6;+∞). Ответ: 3.
- 13.8: x² < 9 ⇒ −3 < x < 3.
- 13.9: x²−25 > 0 ⇒ x∈(−∞;−5)∪(5;+∞). Ответ: 1.
- 13.10: штриховка вне отрезка [0;7] с выколотыми концами ⇒ x²−7x > 0. Ответ: 3.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- x² < c² ⇒ −c < x < c; x² > c² ⇒ x вне [−c; c].
- Обратная задача (13.10): по корням штриховки восстанови множители.

Иллюстрация: семь мини-прямых со штриховками и ответами.
