# Карточки-разборы заданий ОГЭ по математике

Промпты для генерации карточек через ChatGPT (image generation).
Источник: «Открытый банк задач ФИПИ. ОГЭ по математике» (сост. А. Д. Остромогильский),
файл `банк математика ОГЭ v3.pdf` в корне репозитория — использован основной раздел
с вариациями (страницы 5–130), БЕЗ раздела «Аналоги».

## Принцип

Внутри каждого задания ОГЭ (№1–25) вариации сгруппированы по ТЕМАМ
(типам задач). На каждую тему — 2–3 карточки:

1. **Карточка «Теория»** — определения и формулы, необходимые для этого типа задач.
2. **Карточка «Метод решения»** — пошаговый алгоритм + типичные ловушки.
3. **Карточка «Разбор»** — решение 1–2 типовых вариаций из банка с ответом.

## Как пользоваться

1. Возьми блок СТИЛЬ из `00-shablon-stilya.md`.
2. Вставь СТИЛЬ + КОНТЕНТ нужной карточки одним сообщением в ChatGPT.
