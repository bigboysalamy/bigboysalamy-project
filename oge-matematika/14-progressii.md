## Тема 14-А. Арифметическая прогрессия (вариации 14.1–14.8)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ: ТЕОРИЯ. Плашка: вариации 14.1–14.8.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ (все — текстовые сюжеты)
- 14.1: амфитеатр, известно a₁ и d — найти n-й ряд.
- 14.2: амфитеатр, известны два члена (5-й и 8-й ряды) — найти последний.
- 14.3: амфитеатр — найти СУММУ всех мест.
- 14.4: охлаждение вещества на 9° в минуту — найти температуру через 6 минут.
- 14.5–14.8: торможение/разгон/падение — путь за первые n секунд (сумма) или до остановки.
2. ФОРМУЛЫ (в рамках)
- aₙ = a₁ + d(n−1) — n-й член.
- Sₙ = (a₁+aₙ)·n/2 = (2a₁+d(n−1))·n/2 — сумма n членов.
- d = (aₘ−aₖ)/(m−k) — разность по двум известным членам.

Иллюстрация: ряды амфитеатра с растущим числом мест, подписаны a₁, d.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ: МЕТОД. Плашка: вариации 14.1–14.8.

КОНТЕНТ:
1. АЛГОРИТМ
- Переведи сюжет в термины прогрессии: что такое a₁, что такое d (уменьшение ⇒ d<0).
- Пойми, что ищут: ЧЛЕН прогрессии (aₙ) или СУММУ (Sₙ).
- Подставь в нужную формулу.
2. ОСОБЫЙ СЛУЧАЙ — «до полной остановки» (14.6)
- Найди, сколько секунд длится движение: последний положительный член; затем считай сумму только этих членов.

Врезка «Ловушка!»: В 14.4 «через 6 минут» — это a₇ или a₆? Начальная температура — член a₁ в момент t=0, через 6 минут прошло 6 шагов: T = −6 + 6·(−9) = −60. Считай ШАГИ, а не номера!

Иллюстрация: временная шкала 0–6 минут с 6 стрелками-шагами по −9°.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / АРИФМЕТИЧЕСКАЯ ПРОГРЕССИЯ: РАЗБОР. Плашка: вариации 14.1–14.8.

КОНТЕНТ:
1. РАЗБОРЫ
- 14.1: a₈ = 25 + 3·7 = 46 мест.
- 14.2: d = (36−27)/(8−5) = 3; a₁₄ = a₅ + 3·9 = 27+27 = 54 места.
- 14.3: a₁₀ = 19+3·9 = 46; S₁₀ = (19+46)·10/2 = 325 мест.
- 14.4: T = −6 + 6·(−9) = −60 °C.
- 14.5: S₅ = (2·30 + (−4)·4)·5/2 = (60−16)·2,5 = 110 м.
- 14.6: члены 20,16,12,8,4 (затем 0) ⇒ S = 60 м.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- «Сколько всего/за первые n секунд» = сумма; «сколько в n-м ряду/через n минут» = член.
- Отрицательная разность — нормально для задач на замедление/охлаждение.

Иллюстрация: шесть кратких решений с выделенными формулами.

## Тема 14-Б. Геометрическая прогрессия (вариации 14.9–14.11)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ: ТЕОРИЯ. Плашка: вариации 14.9–14.11.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 14.9: радиоактивный распад — масса уменьшается вдвое каждые 6 минут; найти массу через 42 минуты.
- 14.10: колония микроорганизмов ×3 каждые 20 минут; масса через 80 минут.
- 14.11: мячик, каждый прыжок вдвое ниже; при каком прыжке высота станет меньше 20 см.
2. ФОРМУЛА (в рамке)
- bₙ = b₁·qⁿ⁻¹; на каждый «период» изменения умножай на q ещё раз.
- Количество периодов = (всё время)/(один период).

Иллюстрация: цепочка делений массы 640 → 320 → 160 → ... со стрелками «÷2».

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ: МЕТОД. Плашка: вариации 14.9–14.11.

КОНТЕНТ:
1. АЛГОРИТМ
- Найди число периодов: 42 мин / 6 мин = 7 периодов.
- Умножь (или раздели) начальное значение на q столько раз, сколько периодов.
- Для «первый раз меньше порога» — выписывай члены подряд до нарушения условия.

Врезка «Ловушка!»: Число периодов — это число УМНОЖЕНИЙ, а не номер члена: через 7 периодов масса = 640·(1/2)⁷, что соответствует b₈ в формуле bₙ=b₁qⁿ⁻¹.

Иллюстрация: таблица «время → число периодов → множитель q в степени».

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 14 / ГЕОМЕТРИЧЕСКАЯ ПРОГРЕССИЯ: РАЗБОР. Плашка: вариации 14.9–14.11.

КОНТЕНТ:
1. РАЗБОРЫ
- 14.9: периодов 42/6 = 7 ⇒ m = 640/2⁷ = 640/128 = 5 мг.
- 14.10: периодов 80/20 = 4 ⇒ m = 3·3⁴ = 3·81 = 243 мг.
- 14.11: высоты 5,6; 2,8; 1,4; 0,7; 0,35; 0,175 м — шестой прыжок первым станет ниже 0,2 м. Ответ: 6.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Дели время на длину периода — получишь показатель степени.
- В задачах «первый раз меньше/больше» надёжнее выписать цепочку значений.

Иллюстрация: три разбора с цепочками значений, ответы в зелёных рамках.
