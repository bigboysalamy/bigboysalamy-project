## Тема 20-А. Выражения (вариация 20.1)

### Карточка 1 из 2 — «Теория и метод»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / ВЫРАЖЕНИЯ: ТЕОРИЯ И МЕТОД. Плашка: вариация 20.1.

КОНТЕНТ:
1. ТИП ВАРИАЦИИ
- Дано равенство дробей (3a−6b+4)/(6a−3b+4) = 7; найти значение выражения 39a−15b+25.
2. ИДЕЯ РЕШЕНИЯ
- Из условия выведи линейную связь между a и b: перемножь крест-накрест, приведи подобные.
- Затем выражение представь через полученную комбинацию — оно специально подобрано как её кратное.

Иллюстрация: схема «дробное равенство → линейное соотношение → подстановка в искомое выражение».

### Карточка 2 из 2 — «Разбор вариации»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / ВЫРАЖЕНИЯ: РАЗБОР. Плашка: вариация 20.1.

КОНТЕНТ:
1. РАЗБОР 20.1
- (3a−6b+4) = 7(6a−3b+4) ⇒ 3a−6b+4 = 42a−21b+28 ⇒ 15b−39a = 24 ⇒ 39a−15b = −24.
- Тогда 39a−15b+25 = −24+25 = 1.
- Ответ: 1.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Не пытайся найти a и b по отдельности — их бесконечно много; нужна только комбинация 39a−15b.
- Оформи в развёрнутом ответе цепочку преобразований.

Иллюстрация: выкладка с выделенной цветом комбинацией 39a−15b.

## Тема 20-Б. Уравнения (вариации 20.2–20.9)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / УРАВНЕНИЯ ВЫСШИХ СТЕПЕНЕЙ: ТЕОРИЯ. Плашка: вариации 20.2–20.9.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 20.2/20.3: кубические с группировкой: x³+4x²=9x+36; x³+5x²−x−5=0.
- 20.4: x(x²+2x+1)=6(x+1) — общий множитель (x+1).
- 20.5: x⁴=(x−2)² — разность квадратов.
- 20.6: дробное: 1/x² + 4/x − 12 = 0 — замена t=1/x.
- 20.7: биквадратная замена: (x−4)⁴−4(x−4)²−21=0.
- 20.8: с корнем: x²−2x+√(3−x) = √(3−x)+8 — ОДЗ!
- 20.9: сумма квадратов равна нулю: (x²−36)²+(x²+4x−12)²=0.
2. КЛЮЧЕВЫЕ ПРИЁМЫ (в рамках)
- Группировка и вынесение общего множителя; ab=0 ⇔ a=0 или b=0.
- Замена переменной t = (повторяющееся выражение).
- A²+B²=0 ⇔ A=0 И B=0 одновременно.

Иллюстрация: три приёма в трёх рамках со стрелками к типам уравнений.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / УРАВНЕНИЯ ВЫСШИХ СТЕПЕНЕЙ: МЕТОД. Плашка: вариации 20.2–20.9.

КОНТЕНТ:
1. АЛГОРИТМ
- Перенеси всё влево, попробуй группировку по парам слагаемых.
- Вынеси общую скобку, разложи оставшийся множитель (разность квадратов и т.п.).
- Каждый множитель приравняй к нулю и реши.
- Проверь корни по ОДЗ, если есть корень или дробь.

Врезка «Ловушка!»: В 20.8 слагаемое √(3−x) сокращается, но ОДЗ 3−x≥0 (x≤3) ОСТАЁТСЯ! Из корней x²−2x−8=0 (x=4, x=−2) подходит только x=−2.

Иллюстрация: уравнение 20.8 с перечёркнутым посторонним корнем x=4 и выделенной ОДЗ.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / УРАВНЕНИЯ ВЫСШИХ СТЕПЕНЕЙ: РАЗБОР. Плашка: вариации 20.2–20.9.

КОНТЕНТ:
1. РАЗБОРЫ
- 20.2: x²(x+4)=9(x+4) ⇒ (x+4)(x²−9)=0 ⇒ x=−4, x=±3.
- 20.3: x²(x+5)−(x+5)=0 ⇒ (x+5)(x−1)(x+1)=0 ⇒ x=−5, ±1.
- 20.4: x(x+1)²−6(x+1)=0 ⇒ (x+1)(x²+x−6)=0 ⇒ x=−1, x=2, x=−3.
- 20.5: x⁴−(x−2)²=0 ⇒ (x²−x+2)(x²+x−2)=0 ⇒ первый без корней (D<0), второй: x=1, x=−2.
- 20.7: t=(x−4)²: t²−4t−21=0 ⇒ t=7 (t=−3 не подходит) ⇒ x=4±√7.
- 20.9: x²=36 И x²+4x−12=0 одновременно ⇒ общий корень x=−6... проверка: 36−36=0 ✓, 36−24−12=0 ✓. Ответ: x=−6 (x=6 не удовлетворяет второму).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Отрицательное t при замене t=(...)² отбрасывается.
- В сумме квадратов ищи ОБЩИЙ корень обоих выражений.

Иллюстрация: шесть кратких решений с ответами.

## Тема 20-В. Системы уравнений (вариации 20.10–20.13)

### Карточка 1 из 2 — «Теория и метод»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / СИСТЕМЫ УРАВНЕНИЙ: ТЕОРИЯ И МЕТОД. Плашка: вариации 20.10–20.13.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 20.10: y выражен в обоих уравнениях — приравнивание: 3x²−2x = 3x−2.
- 20.11: сложение уравнений исключает y: x²+y=5; 6x²−y=2.
- 20.12: пропорциональные левые части: 5x²+y²=36; 10x²+2y²=36x.
- 20.13: произведение равно нулю + дробное условие — разбор случаев с проверкой знаменателя.
2. МЕТОДЫ (в рамках)
- Подстановка / приравнивание правых частей.
- Алгебраическое сложение для исключения переменной.
- Для (A)(B)=0 — два случая, каждый подставляй во второе уравнение; проверяй знаменатели!

Иллюстрация: три метода-ветки со стрелками к типам систем.

### Карточка 2 из 2 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / СИСТЕМЫ УРАВНЕНИЙ: РАЗБОР. Плашка: вариации 20.10–20.13.

КОНТЕНТ:
1. РАЗБОРЫ
- 20.10: 3x²−2x = 3x−2 ⇒ 3x²−5x+2=0 ⇒ x=1, x=2/3; y=3x−2 ⇒ (1;1) и (2/3;0).
- 20.11: сложение: 7x² = 7 ⇒ x=±1, y = 5−x² = 4 ⇒ (1;4), (−1;4).
- 20.12: удвоим первое: 10x²+2y²=72; сравнив со вторым: 36x=72 ⇒ x=2; y²=36−20=16 ⇒ y=±4 ⇒ (2;4), (2;−4).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Ответ системы — ПАРЫ (x;y), выписывай обе координаты.
- После решения подставь пары в ОБА уравнения для проверки.

Иллюстрация: три решения с парами-ответами в зелёных рамках.

## Тема 20-Г. Неравенства (вариации 20.14–20.24)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / НЕРАВЕНСТВА 2 ЧАСТИ: ТЕОРИЯ. Плашка: вариации 20.14–20.24.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 20.14/20.15: дробь с числовым числителем: −12/(x²−7x−8) ≤ 0.
- 20.16: (x−7)² < √11(x−7) — общий множитель.
- 20.17–20.20: произведения скобок и трёхчленов: (7−x)(x²−49)≥0 и подобные.
- 20.21: дробь: (3x²−18x+27)/(x+7) ≤ 0 — полный квадрат в числителе.
- 20.22–20.24: с переносом дроби: x ≤ 64/x; 1/x ≥ 1/(x−5).
2. ГЛАВНЫЙ ИНСТРУМЕНТ (в рамке)
- Метод интервалов: все нули числителя и знаменателя на прямую; знаменатель — всегда выколот; знаки чередуются с учётом кратности корней.

Иллюстрация: числовая прямая с закрашенными и выколотыми точками, знаки на интервалах.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / НЕРАВЕНСТВА 2 ЧАСТИ: МЕТОД. Плашка: вариации 20.14–20.24.

КОНТЕНТ:
1. АЛГОРИТМ
- Перенеси всё в одну часть, приведи к виду (произведение/дробь) ∨ 0.
- Разложи на множители каждый трёхчлен.
- Метод интервалов: у корней ЧЁТНОЙ кратности знак НЕ меняется (например (x−3)² в 20.21).
- Запиши ответ объединением промежутков, отдельные точки — если нестрогое неравенство.

Врезка «Ловушка!»: В 20.22 НЕЛЬЗЯ умножать на x (знак неизвестен!): переноси и приводи к дроби (x²−64)/x ≤ 0 ⇒ метод интервалов: x∈(−∞;−8]∪(0;8].

Иллюстрация: перечёркнутое умножение на x, правильный путь через дробь.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 20 / НЕРАВЕНСТВА 2 ЧАСТИ: РАЗБОР. Плашка: вариации 20.14–20.24.

КОНТЕНТ:
1. РАЗБОРЫ
- 20.14: −12/(x²−7x−8) ≤ 0 ⇔ x²−7x−8 > 0 (делим на −12, знак меняется; знаменатель ≠0) ⇒ (x+1)(x−8)>0 ⇒ x∈(−∞;−1)∪(8;+∞).
- 20.16: (x−7)(x−7−√11) < 0 ⇒ x∈(7; 7+√11).
- 20.17: (7−x)(x−7)(x+7) ≥ 0 ⇒ −(x−7)²(x+7) ≥ 0 ⇒ (x−7)²(x+7) ≤ 0 ⇒ x ≤ −7 или x=7. Ответ: (−∞;−7]∪{7}.
- 20.21: 3(x−3)²/(x+7) ≤ 0 ⇒ x < −7 или x=3. Ответ: (−∞;−7)∪{3}.
- 20.24: 1/x − 1/(x−5) ≥ 0 ⇒ −5/(x(x−5)) ≥ 0 ⇒ x(x−5) < 0 ⇒ x∈(0;5).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Отдельные точки-решения {7}, {3} — визитная карточка чётных кратностей; не теряй их!
- Знаменатель никогда не включается в ответ.

Иллюстрация: пять прямых метода интервалов с ответами.
