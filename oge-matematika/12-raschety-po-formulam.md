## Тема 12-А. Линейная зависимость (вариации 12.1–12.8)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / ЛИНЕЙНЫЕ ФОРМУЛЫ: ТЕОРИЯ. Плашка: вариации 12.1–12.8.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 12.1/12.2: стоимость колодца C = 6000 + 4100n — прямая подстановка.
- 12.3/12.4: перевод температур: t꜀ = (5/9)(t_F − 32) и t_F = 1,8t꜀ + 32.
- 12.5: сила Архимеда F = ρgV — подстановка.
- 12.6: кинетическая энергия E = mv²/2 — найти v (обратная задача).
- 12.7: потенциальная энергия P = mgh — найти m.
- 12.8: площадь S = d₁d₂sinα/2 — найти d₁.
2. ПРИНЦИП
- Два режима: ПРЯМОЙ (подставь числа, вычисли) и ОБРАТНЫЙ (вырази неизвестную из формулы, потом подставь).

Иллюстрация: формула-«машина»: слева входы (известные величины), справа выход (искомая), стрелка «выразить» в обратную сторону.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / ЛИНЕЙНЫЕ ФОРМУЛЫ: МЕТОД. Плашка: вариации 12.1–12.8.

КОНТЕНТ:
1. АЛГОРИТМ
- Выпиши формулу и подпиши, что известно, что ищем.
- Если ищем «выходную» величину — подставляй и считай по порядку действий.
- Если искомая внутри формулы — сначала вырази её алгебраически, затем подставь.
- Проверь единицы измерения (метры/сантиметры, кг/г).

Врезка «Ловушка!»: В 12.3 сначала вычисляется скобка: t꜀ = (5/9)(−112−32) = (5/9)·(−144) = −80. Не умножай 5/9 только на t_F, забыв про −32!

Иллюстрация: пошаговое вычисление с выделенной скобкой первым действием.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / ЛИНЕЙНЫЕ ФОРМУЛЫ: РАЗБОР. Плашка: вариации 12.1–12.8.

КОНТЕНТ:
1. РАЗБОРЫ
- 12.1: C = 6000 + 4100·4 = 22 400 руб.
- 12.3: t꜀ = (5/9)(−112−32) = −80 °C.
- 12.5: F = 1000·9,8·0,05 = 490 Н.
- 12.6: 240000 = 1200·v²/2 ⇒ v² = 400 ⇒ v = 20 м/с.
- 12.7: 980 = m·9,8·5 ⇒ m = 980/49 = 20 кг.
- 12.8: 4 = d₁·7·(2/7)/2 = d₁ ⇒ d₁ = 4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Обратная задача = сначала алгебра, потом арифметика.
- Из v² = 400 берём положительный корень — скорость не бывает отрицательной.

Иллюстрация: шесть решений, обратные задачи помечены значком «⇦».

## Тема 12-Б. Квадратичная зависимость (вариации 12.9–12.11)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / КВАДРАТИЧНЫЕ ФОРМУЛЫ: ТЕОРИЯ. Плашка: вариации 12.9–12.11.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 12.9: мощность тока P = I²R — найти R.
- 12.10: центростремительное ускорение a = ω²R — найти R.
- 12.11: энергия конденсатора W = CU²/2 — прямой расчёт с малыми числами (C = 10⁻⁴).
2. ОСОБЕННОСТЬ
- В формуле есть КВАДРАТ одной из величин: при подстановке возводи её в квадрат ДО остальных действий.
- При обратной задаче дели на квадрат: R = P/I².

Иллюстрация: формула P = I²R с выделенным квадратом и порядком действий 1) I², 2) деление.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / КВАДРАТИЧНЫЕ ФОРМУЛЫ: МЕТОД. Плашка: вариации 12.9–12.11.

КОНТЕНТ:
1. АЛГОРИТМ
- Возведи в квадрат ту величину, что стоит в квадрате (I² = 1,5² = 2,25).
- Вырази искомую величину и раздели/умножь.
- Со степенями десяти работай отдельно: 10⁻⁴·144/2 = 72·10⁻⁴ = 0,0072.

Врезка «Ловушка!»: 1,5² = 2,25, а не 3,0! Квадрат десятичной дроби считай столбиком или как (3/2)² = 9/4.

Иллюстрация: вычисление 1,5² столбиком, красная пометка на типичной ошибке «×2».

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 12 / КВАДРАТИЧНЫЕ ФОРМУЛЫ: РАЗБОР. Плашка: вариации 12.9–12.11.

КОНТЕНТ:
1. РАЗБОРЫ
- 12.9: R = P/I² = 6,75/2,25 = 3 Ом.
- 12.10: R = a/ω² = 1,5/0,25 = 6 м.
- 12.11: W = 10⁻⁴·12²/2 = 10⁻⁴·144/2 = 0,0072 Дж.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Квадрат вычисляй первым действием.
- Ответ с 10⁻⁴ записывай десятичной дробью: 0,0072.

Иллюстрация: три решения с промежуточными шагами, ответы в зелёных рамках.
