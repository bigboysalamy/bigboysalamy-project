# Задание 6. Дроби

Перед каждой карточкой вставляй блок СТИЛЬ из `00-shablon-stilya.md`.
Темы задания (по банку ФИПИ): Десятичные дроби (вариации 6.1–6.4), Обыкновенные дроби (вариации 6.5–6.10).

## Тема 6-А. Десятичные дроби (вариации 6.1–6.4)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ДЕСЯТИЧНЫЕ ДРОБИ: ТЕОРИЯ. Плашка: вариации 6.1–6.4.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 6.1 — сложение: «Найдите значение выражения 5,6 + 9,7».
- 6.2 — вычитание: «Найдите значение выражения 3,3 − 1,9».
- 6.3 — умножение: «Найдите значение выражения 1,6 · 5,1».
- 6.4 — деление: «Найдите значение выражения 9,6 / 1,6».
2. ТЕОРИЯ
- Сложение/вычитание десятичных дробей — поразрядно, «запятая под запятой».
- Умножение — перемножаем как целые числа, затем отделяем справа столько знаков, сколько их после запятых у обоих множителей вместе.
- Деление — переносим запятую в делителе и делимом вправо на одинаковое число знаков, чтобы делитель стал целым, затем делим уголком.

Иллюстрация: столбик сложения 5,6+9,7 с выровненными запятыми; рядом схема умножения 1,6·5,1 с подсчётом знаков после запятой.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ДЕСЯТИЧНЫЕ ДРОБИ: МЕТОД. Плашка: вариации 6.1–6.4.

КОНТЕНТ:
1. АЛГОРИТМ
- Определи действие (сложение, вычитание, умножение, деление).
- Выполни столбиком или переносом запятой (для деления).
- Проверь порядок величины ответа прикидкой (5,6+9,7 ≈ 6+10 = 16 — ответ должен быть рядом).

Врезка «Ловушка!»: При вычитании типа 3,3−1,9 не забудь про «заём» из целой части; при умножении не потеряй знак после запятой (1,6·5,1 — два знака после запятой в ответе).

Иллюстрация: числовая прикидка на шкале, ответ «в окрестности» оценки.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ДЕСЯТИЧНЫЕ ДРОБИ: РАЗБОР. Плашка: вариации 6.1–6.4.

КОНТЕНТ:
1. РЕШЕНИЕ ВСЕХ ЧЕТЫРЁХ ТИПОВ
- 6.1: 5,6 + 9,7 = 15,3.
- 6.2: 3,3 − 1,9 = 1,4.
- 6.3: 1,6 · 5,1 = 8,16.
- 6.4: 9,6 : 1,6 = 96 : 16 = 6.
2. ОФОРМЛЕНИЕ ОТВЕТА
- В бланк ОГЭ десятичный ответ записывается через запятую (например «8,16»), без единиц измерения.

Иллюстрация: четыре мини-вычисления столбиком, ответы обведены зелёными рамками.

## Тема 6-Б. Обыкновенные дроби (вариации 6.5–6.10)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ОБЫКНОВЕННЫЕ ДРОБИ: ТЕОРИЯ. Плашка: вариации 6.5–6.10.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 6.5/6.6 — сложение/вычитание с разными знаменателями: 1/2 + 11/10; 1/2 − 9/10.
- 6.7/6.8 — умножение/деление: (15/2)·(7/5); (21/2):(3/5).
- 6.9 — приведение к заданному знаменателю: представить 3/5 − 2/7 дробью со знаменателем 70, в ответ — числитель.
- 6.10 — «многоэтажная» дробь: 1 / (1/30 + 1/42).
2. ТЕОРИЯ (формулы в рамках)
- a/b ± c/d = (ad ± cb)/(bd); удобнее общий знаменатель = НОК(b, d).
- a/b · c/d = ac/bd; a/b : c/d = a/b · d/c.
- Сокращение до умножения экономит вычисления.

Иллюстрация: схема приведения 1/2 и 11/10 к знаменателю 10, рядом «переворот» дроби при делении.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ОБЫКНОВЕННЫЕ ДРОБИ: МЕТОД. Плашка: вариации 6.5–6.10.

КОНТЕНТ:
1. АЛГОРИТМ
- Приведи дроби к общему знаменателю (для ±) или сократи крест-накрест (для ·, :).
- Выполни действие с числителями.
- Переведи результат в десятичную дробь, если ответ должен быть числом (15,3, а не 153/10).
2. ОСОБЫЙ СЛУЧАЙ — «многоэтажная» дробь (6.10)
- Сначала вычисли знаменатель: 1/30 + 1/42 = 7/210 + 5/210 = 12/210 = 2/35.
- Затем «переверни»: 1 : (2/35) = 35/2 = 17,5.

Врезка «Ловушка!»: В вариации 6.9 в ответ идёт ЧИСЛИТЕЛЬ полученной дроби, а не вся дробь: 3/5−2/7 = 21/35−10/35 = 11/35 = 22/70 ⇒ ответ 22.

Иллюстрация: «многоэтажная» дробь с пронумерованным порядком действий (низ → верх).

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 6 / ОБЫКНОВЕННЫЕ ДРОБИ: РАЗБОР. Плашка: вариации 6.5–6.10.

КОНТЕНТ:
1. РЕШЕНИЯ
- 6.5: 1/2 + 11/10 = 5/10 + 11/10 = 16/10 = 1,6.
- 6.6: 1/2 − 9/10 = 5/10 − 9/10 = −4/10 = −0,4.
- 6.7: (15/2)·(7/5) = (15·7)/(2·5) = 105/10 = 10,5.
- 6.8: (21/2):(3/5) = (21/2)·(5/3) = 105/6 = 17,5.
- 6.9: 3/5 − 2/7 = 22/70 ⇒ ответ: 22.
- 6.10: 1/(1/30+1/42) = 1/(2/35) = 17,5.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Ответ переводи в десятичную запись, если дробь конечная.
- Отрицательный ответ (6.6) — это нормально, минус пишется в бланк.

Иллюстрация: шесть коротких строк-решений, ответы в зелёных рамках.
