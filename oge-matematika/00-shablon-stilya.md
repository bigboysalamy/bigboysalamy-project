# СТИЛЬ (вставлять перед каждым промптом-карточкой)

Шаблон для карточек-разборов заданий ОГЭ по математике. Источник вариаций:
«Открытый банк задач ФИПИ. ОГЭ по математике» (составитель А. Д. Остромогильский),
основной раздел (вариации, БЕЗ аналогов).

```
Создай инфографику-карточку разбора задания ОГЭ по математике,
в формате вертикальной карточки A4, как обучающий плакат.

ОБЩИЙ СТИЛЬ:
— Белый фон, тонкая пунктирная рамка по периметру.
— Заголовок крупным жирным шрифтом в две строки: первая строка —
  «ОГЭ. ЗАДАНИЕ N» заглавными буквами тёмно-серым цветом, вторая строка —
  название типа/вариации задачи, заглавными буквами, синим цветом (#1a3aab).
— Под заголовком — маленькая серая плашка с номером вариации (например «Вариация 8.7»).
— Контент разбит на 4 блока-секции с заголовками капсом со значком (ромб ♦ синего цвета)
  и пунктирной линией-разделителем снизу:
  1. УСЛОВИЕ — текст задачи в рамке со светло-жёлтой заливкой.
  2. ТЕОРИЯ — нужные определения и формулы, каждая формула в отдельном
     прямоугольнике со скруглёнными углами и светло-голубой заливкой.
  3. АЛГОРИТМ РЕШЕНИЯ — нумерованные шаги (1., 2., 3...), коротко и по делу.
  4. РЕШЕНИЕ ПРИМЕРА — выкладки с промежуточными результатами и ответ,
     выделенный в зелёной рамке в конце.
— Врезки-подсказки (где уместно) — прямоугольник со скруглёнными углами,
  светло-серая заливка, синяя иконка восклицательного знака в кружке слева,
  заголовок врезки жирным («Ловушка!», «Запомни!», «Проверь себя!»).
— Справа от условия или внутри него — аккуратная иллюстрация к задаче:
  схема, чертёж, график, числовая прямая — если тип задачи этого требует.
— Палитра: тёмно-синий, голубой, серый текст; акценты — малиновый/зелёный/оранжевый;
  много воздуха, не перегружать.
— Весь текст — на русском языке, математические обозначения без ошибок.

ДАЛЕЕ — СОДЕРЖАНИЕ ЭТОЙ КОНКРЕТНОЙ КАРТОЧКИ:
```

После этого блока вставляй текст из поля «КОНТЕНТ» нужной карточки (см. файлы заданий).
