## Тема 11-А. Линейные функции (вариации 11.1–11.4)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / ЛИНЕЙНЫЕ ФУНКЦИИ: ТЕОРИЯ. Плашка: вариации 11.1–11.4.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 11.1/11.2: соответствие «знаки коэффициентов k и b ↔ графики» (в обе стороны).
- 11.3/11.4: соответствие «формулы y=kx+b ↔ графики».
2. ТЕОРИЯ: РОЛЬ КОЭФФИЦИЕНТОВ y = kx + b
- k > 0 — прямая возрастает (идёт вверх слева направо); k < 0 — убывает.
- b — точка пересечения с осью Oy: b > 0 — выше нуля, b < 0 — ниже.
- Чем больше |k|, тем круче наклон.

Иллюстрация: четыре прямые с разными комбинациями знаков k и b, каждая подписана (k>0,b>0 и т.д.).

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / ЛИНЕЙНЫЕ ФУНКЦИИ: МЕТОД. Плашка: вариации 11.1–11.4.

КОНТЕНТ:
1. АЛГОРИТМ
- Для каждого графика определи два признака: направление (возрастает/убывает ⇒ знак k) и точку пересечения с Oy (выше/ниже нуля ⇒ знак b).
- Сопоставь пару признаков с вариантами.
- Для формул (11.3/11.4): сравни также сами значения — прямые y=−2x−1 и y=−2x+1 параллельны, различаются только сдвигом по Oy.

Врезка «Ловушка!»: Смотри на пересечение именно с осью Oy (вертикальной), а не Ox. Прямая может пересекать Ox в положительной точке при b<0.

Иллюстрация: график с выделенной точкой пересечения с Oy и стрелкой направления роста.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / ЛИНЕЙНЫЕ ФУНКЦИИ: РАЗБОР. Плашка: вариации 11.1–11.4.

КОНТЕНТ:
1. РАЗБОР 11.3 (формулы 1) y=−2x−1; 2) y=−2x+1; 3) y=2x+1)
- График А: убывает, пересекает Oy ниже нуля ⇒ k<0, b<0 ⇒ формула 1.
- График Б: убывает, пересекает Oy выше нуля ⇒ формула 2.
- График В: возрастает, Oy выше нуля ⇒ формула 3.
- Ответ: 123 (последовательность цифр по порядку А-Б-В).
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Два признака (наклон + сдвиг) однозначно определяют прямую среди вариантов.
- Ответ в бланк — последовательность цифр без пробелов.

Иллюстрация: три графика с подписанными признаками и итоговой таблицей А-Б-В.

## Тема 11-Б. Квадратичные функции (вариации 11.5–11.6)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / КВАДРАТИЧНЫЕ ФУНКЦИИ: ТЕОРИЯ. Плашка: вариации 11.5–11.6.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- Соответствие «знаки коэффициентов a и c параболы y=ax²+bx+c ↔ графики» (в обе стороны).
2. ТЕОРИЯ: РОЛЬ КОЭФФИЦИЕНТОВ
- a > 0 — ветви параболы вверх; a < 0 — ветви вниз.
- c — точка пересечения параболы с осью Oy (значение y при x=0): c > 0 — выше нуля, c < 0 — ниже.

Иллюстрация: три параболы — ветви вверх/Oy выше нуля, ветви вниз/Oy выше нуля, ветви вверх/Oy ниже нуля — с подписями знаков.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / КВАДРАТИЧНЫЕ ФУНКЦИИ: МЕТОД. Плашка: вариации 11.5–11.6.

КОНТЕНТ:
1. АЛГОРИТМ
- По каждому графику ответь на 2 вопроса: куда смотрят ветви (знак a)? где парабола пересекает ось Oy (знак c)?
- Составь пару знаков и найди её среди вариантов.

Врезка «Ловушка!»: Знак c определяется по пересечению с ОСЬЮ Oy, а не по положению вершины! Вершина может быть ниже нуля при c>0.

Иллюстрация: парабола с вершиной ниже оси Ox, но пересечением Oy выше нуля — подписано «c > 0, хотя вершина внизу».

### Карточка 3 из 3 — «Разбор вариации»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / КВАДРАТИЧНЫЕ ФУНКЦИИ: РАЗБОР. Плашка: вариации 11.5–11.6.

КОНТЕНТ:
1. РАЗБОР 11.5 (А: a>0,c>0; Б: a<0,c>0; В: a>0,c<0)
- Ищем график с ветвями вверх и пересечением Oy выше нуля → А.
- Ветви вниз, Oy выше нуля → Б.
- Ветви вверх, Oy ниже нуля → В.
- Ответ — последовательность номеров графиков в порядке А-Б-В.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Два признака: направление ветвей (a) и точка на Oy (c).
- Коэффициент b в этих вариациях не нужен — не трать на него время.

Иллюстрация: три параболы с выделенными точками пересечения с Oy и стрелками ветвей.

## Тема 11-В. Смешанные задачи (вариации 11.7–11.10)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / СМЕШАННЫЕ ГРАФИКИ: ТЕОРИЯ. Плашка: вариации 11.7–11.10.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- Соответствие «графики ↔ формулы» для смеси: прямая, парабола, гипербола, корень (y=kx, y=ax²+c, y=k/x, y=√x).
2. ОПОЗНАВАТЕЛЬНЫЕ ПРИЗНАКИ ГРАФИКОВ (мини-таблица)
- Прямая — y=kx+b (линейная).
- Парабола — y=ax²+bx+c (квадратичная).
- Гипербола (две ветви в противоположных четвертях) — y=k/x.
- «Половина параболы, лежащая на боку», из точки (0;0) вправо — y=√x.

Иллюстрация: четыре мини-графика с подписями типов.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / СМЕШАННЫЕ ГРАФИКИ: МЕТОД. Плашка: вариации 11.7–11.10.

КОНТЕНТ:
1. АЛГОРИТМ
- Сначала определи ТИП каждого графика (прямая/парабола/гипербола/корень) — это сразу распределяет большинство формул.
- Если типы совпадают, уточняй по знакам: направление ветвей, четверти гиперболы (k>0 — I и III; k<0 — II и IV), наклон прямой.

Врезка «Ловушка!»: y=−x²−2 — парабола ветвями ВНИЗ, целиком ниже оси Ox (вершина (0;−2)). Знак «−» перед x² и сдвиг −2 читай прямо из формулы.

Иллюстрация: гипербола в I-III четвертях (k>0) и в II-IV (k<0) рядом для сравнения.

### Карточка 3 из 3 — «Разбор вариации»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 11 / СМЕШАННЫЕ ГРАФИКИ: РАЗБОР. Плашка: вариации 11.7–11.10.

КОНТЕНТ:
1. РАЗБОР 11.7 (формулы: 1) y=1/x; 2) y=−x²−2; 3) y=(1/2)x)
- График-гипербола → формула 1.
- Парабола ветвями вниз, ниже оси → формула 2.
- Возрастающая прямая через начало координат → формула 3.
2. РАЗБОР 11.10 (1) y=−x²−3; 2) y=−2x−4; 3) y=√x)
- «Лежачая полупарабола» из нуля → 3; парабола вниз → 1; убывающая прямая → 2.
3. ЧТО НУЖНО ЗАПОМНИТЬ
- Опознание типа графика решает 90% задачи.
- Ответ — последовательность цифр по порядку А-Б-В без пробелов.

Иллюстрация: смешанный набор графиков с подписанными типами и таблицей ответа.
