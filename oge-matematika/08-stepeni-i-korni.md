## Тема 8-А. Вычисления со степенями (вариации 8.1–8.8)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ СО СТЕПЕНЯМИ: ТЕОРИЯ. Плашка: вариации 8.1–8.8.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 8.1: 2⁻⁹·(2⁷)² — произведение со степенью в степени.
- 8.3: (1/2)⁻¹¹ · (1/2)⁷-типа — степени дробей с отрицательным показателем.
- 8.4/8.5: дроби вида (2⁻³·2¹⁹)/2¹³, (2⁴)⁻⁶/2⁻²⁷.
- 8.6–8.8: разные основания: (3¹³·7¹⁰)/21¹⁰, 6⁵/(2³·3⁴), (2·5)⁶/(2⁴·5⁵).
2. СВОЙСТВА СТЕПЕНЕЙ (формулы в рамках)
- aᵐ·aⁿ = aᵐ⁺ⁿ; aᵐ/aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ.
- (ab)ⁿ = aⁿbⁿ; a⁻ⁿ = 1/aⁿ; a⁰ = 1.

Иллюстрация: таблица свойств степеней в шести голубых рамках.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ СО СТЕПЕНЯМИ: МЕТОД. Плашка: вариации 8.1–8.8.

КОНТЕНТ:
1. АЛГОРИТМ
- Приведи всё к одинаковым основаниям (21 = 3·7; 6 = 2·3; 10 = 2·5).
- Сложи/вычти показатели по свойствам степеней.
- Доведи до небольшой степени и вычисли ответ числом.

Врезка «Ловушка!»: (2⁷)² = 2¹⁴ (показатели УМНОЖАЮТСЯ), а 2⁷·2² = 2⁹ (показатели складываются) — не перепутай два правила!

Иллюстрация: два примера рядом — (aᵐ)ⁿ и aᵐ·aⁿ — с подчёркнутой разницей операций над показателями.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ СО СТЕПЕНЯМИ: РАЗБОР. Плашка: вариации 8.1–8.8.

КОНТЕНТ:
1. РАЗБОРЫ
- 8.1: 2⁻⁹·(2⁷)² = 2⁻⁹·2¹⁴ = 2⁵ = 32.
- 8.4: (2⁻³·2¹⁹)/2¹³ = 2¹⁶/2¹³ = 2³ = 8.
- 8.6: (3¹³·7¹⁰)/21¹⁰ = (3¹³·7¹⁰)/(3¹⁰·7¹⁰) = 3³ = 27.
- 8.7: 6⁵/(2³·3⁴) = (2⁵·3⁵)/(2³·3⁴) = 2²·3 = 12.
- 8.8: (2·5)⁶/(2⁴·5⁵) = (2⁶·5⁶)/(2⁴·5⁵) = 2²·5 = 20.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Составное основание раскладывай на простые множители.
- Ответ всегда получается «красивым» целым или конечной десятичной дробью.

Иллюстрация: цепочки преобразований с выделенными цветом показателями.

## Тема 8-Б. Вычисления с квадратными корнями (вариации 8.9–8.21)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ С КОРНЯМИ: ТЕОРИЯ. Плашка: вариации 8.9–8.21.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 8.9–8.11: произведения корней: √2·45·√10; 2√13·5√2·√26.
- 8.12/8.13: разность квадратов: (√11−3)(√11+3); (√5−√2)(√5+√2).
- 8.14/8.15: раскрытие скобок: (√8±√2)·√2.
- 8.16: квадрат разности: (√15−2)² + 4√15.
- 8.17–8.19: дроби с корнями: 48/(2√6)²; √15·√12/√20.
- 8.20/8.21: сумма/разность дробей с сопряжёнными знаменателями: 1/(2+√3) + 1/(2−√3).
2. СВОЙСТВА (формулы в рамках)
- √a·√b = √(ab); √a/√b = √(a/b); (√a)² = a.
- (a−b)(a+b) = a²−b²; (a±b)² = a²±2ab+b².

Иллюстрация: таблица свойств корней и формул сокращённого умножения.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ С КОРНЯМИ: МЕТОД. Плашка: вариации 8.9–8.21.

КОНТЕНТ:
1. АЛГОРИТМ
- Ищи разность квадратов: (√a−b)(√a+b) = a−b² — корень исчезает мгновенно.
- В произведениях собирай корни под один: √2·√10 = √20 = 2√5.
- В дробях с сопряжёнными знаменателями приводи к общему знаменателю — он станет разностью квадратов: (2+√3)(2−√3) = 4−3 = 1.

Врезка «Ловушка!»: (√15−2)² = 15 − 4√15 + 4, а не 15−4! Средний член 2ab не забывай — в вариации 8.16 он специально сокращается с +4√15.

Иллюстрация: раскрытие (√15−2)² по формуле квадрата разности с подчёркнутым средним членом.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫЧИСЛЕНИЯ С КОРНЯМИ: РАЗБОР. Плашка: вариации 8.9–8.21.

КОНТЕНТ:
1. РАЗБОРЫ
- 8.13: (√5−√2)(√5+√2) = 5−2 = 3.
- 8.14: (√8+√2)·√2 = √16+√4 = 4+2 = 6.
- 8.16: (√15−2)²+4√15 = 15−4√15+4+4√15 = 19.
- 8.17: 48/(2√6)² = 48/(4·6) = 2.
- 8.19: √15·√12/√20 = √(15·12/20) = √9 = 3.
- 8.20: 1/(2+√3)+1/(2−√3) = ((2−√3)+(2+√3))/((2+√3)(2−√3)) = 4/1 = 4.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Разность квадратов и сопряжённые выражения — главные приёмы.
- Под корнем всё перемножай/сокращай ДО извлечения.

Иллюстрация: шесть коротких цепочек, зелёные рамки на ответах.

## Тема 8-В. Выражения со степенями (вариации 8.22–8.29)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ СО СТЕПЕНЯМИ: ТЕОРИЯ. Плашка: вариации 8.22–8.29.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ (во всех — упростить и подставить значение a)
- 8.22: a⁶·a¹⁹:a²² при a=3.
- 8.23: a⁻⁹·(a²)⁶ при a=5.
- 8.24: (a²)⁻⁶:a⁻¹⁵ при a=4.
- 8.25–8.28: дроби: a⁹·a¹²/a¹⁸; (a⁵)⁴/a¹⁶; (a³)⁴·a¹²/a²¹.
- 8.29: две переменные: a¹⁴·(b⁴)³/(a·b)¹² при a=3, b=√3.
2. ПРИНЦИП
- Сначала УПРОСТИ выражение по свойствам степеней до маленькой степени, потом подставляй число — никогда наоборот.

Иллюстрация: схема «упрости → подставь → вычисли» с тремя стрелками.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ СО СТЕПЕНЯМИ: МЕТОД. Плашка: вариации 8.22–8.29.

КОНТЕНТ:
1. АЛГОРИТМ
- Раскрой степени в степени: (a²)⁶ = a¹².
- Сложи показатели в числителе, вычти показатели знаменателя.
- Подставь значение a в получившуюся малую степень.

Врезка «Ловушка!»: Деление на отрицательную степень = прибавление: (a²)⁻⁶ : a⁻¹⁵ = a⁻¹²⁻⁽⁻¹⁵⁾ = a³. Следи за знаками показателей!

Иллюстрация: выкладка a⁻¹²⁻⁽⁻¹⁵⁾ с выделенным двойным минусом.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ СО СТЕПЕНЯМИ: РАЗБОР. Плашка: вариации 8.22–8.29.

КОНТЕНТ:
1. РАЗБОРЫ
- 8.22: a⁶·a¹⁹:a²² = a³; при a=3: 27.
- 8.23: a⁻⁹·a¹² = a³; при a=5: 125.
- 8.24: a⁻¹²:a⁻¹⁵ = a³; при a=4: 64.
- 8.27: a²⁰/a¹⁶ = a⁴; при a=2: 16.
- 8.29: a¹⁴·b¹²/(a¹²·b¹²) = a²; при a=3: 9.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Почти всегда выражение сводится к a², a³ или a⁴.
- В 8.29 переменная b полностью сокращается — её значение не нужно (это проверка внимательности).

Иллюстрация: пять цепочек упрощения, подстановка выделена оранжевым.

## Тема 8-Г. Выражения с квадратными корнями (вариации 8.30–8.35)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ С КОРНЯМИ: ТЕОРИЯ. Плашка: вариации 8.30–8.35.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 8.30: √(a²·(−a)²) при a=4.
- 8.31: √((1/4)·x²·y⁸) при x=5, y=2.
- 8.32/8.33: √(4a¹⁶/a¹²), √(4x²/y⁶) — дроби под корнем.
- 8.34/8.35: полный квадрат под корнем: √(a²+4ab+4b²), √(a²−6ab+9b²).
2. ТЕОРИЯ (формулы в рамках)
- √(x²) = |x| — модуль, а не просто x!
- √(a²b²) = |a|·|b|; √(a²ⁿ) = |aⁿ|.
- a²±2ab+b² = (a±b)² — сворачивание полного квадрата.

Иллюстрация: формула √(x²)=|x| в крупной рамке с примером √((−5)²) = 5.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ С КОРНЯМИ: МЕТОД. Плашка: вариации 8.30–8.35.

КОНТЕНТ:
1. АЛГОРИТМ
- Сверни выражение под корнем в полный квадрат (если это трёхчлен).
- Извлеки корень с модулем: √((a−3b)²) = |a−3b|.
- Подставь числа В МОДУЛЬ и раскрой его по знаку результата.

Врезка «Ловушка!»: В 8.35 при a=3, b=6: a−3b = 3−18 = −15, поэтому √((a−3b)²) = |−15| = 15, а НЕ −15. Модуль — главный источник ошибок в этой теме!

Иллюстрация: выкладка с модулем, минус внутри модуля превращается в плюс, подчёркнуто красным → зелёным.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 8 / ВЫРАЖЕНИЯ С КОРНЯМИ: РАЗБОР. Плашка: вариации 8.30–8.35.

КОНТЕНТ:
1. РАЗБОРЫ
- 8.30: √(a²·a²) = a² (при a=4): 16.
- 8.31: √((1/4)x²y⁸) = (1/2)·|x|·y⁴ = 0,5·5·16 = 40.
- 8.32: √(4a¹⁶/a¹²) = √(4a⁴) = 2a² = 2·25 = 50.
- 8.33: √(4x²/y⁶) = 2|x|/|y|³ = 2·8/8 = 2.
- 8.34: √((a+2b)²) = |a+2b| = |2−8| = 6.
- 8.35: √((a−3b)²) = |a−3b| = |3−18| = 15.
2. ЧТО НУЖНО ЗАПОМНИТЬ
- Полный квадрат: ищи «квадрат + удвоенное произведение + квадрат».
- После извлечения корня всегда ставь модуль и раскрывай его по знаку.

Иллюстрация: шесть решений, модули выделены цветом.
