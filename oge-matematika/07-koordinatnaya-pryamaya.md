## Тема 7-А. Сравнение выражения с нулём (вариации 7.1–7.5)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / СРАВНЕНИЕ ВЫРАЖЕНИЙ С НУЛЁМ: ТЕОРИЯ. Плашка: вариации 7.1–7.5.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 7.1 — одно число a на прямой, выбрать верное утверждение вида a−5<0, 5−a<0, a−7>0, 6−a>0.
- 7.2/7.3 — два числа (x и y, или a и b), утверждения вида x+y>0, xy²<0, x−y<0, x²y>0.
- 7.4/7.5 — три числа a, b, c, выбрать положительную/отрицательную разность.
2. ТЕОРИЯ
- Правее на координатной прямой — больше; левее — меньше.
- Разность a−b > 0 ⇔ a > b (a правее b); a−b < 0 ⇔ a левее b.
- Знаки произведений: чётная степень всегда ≥ 0 (y², x²), поэтому знак xy² совпадает со знаком x (при y≠0).

Иллюстрация: координатная прямая с точками x<0 и y>0, подписи «левее ⇒ меньше», «правее ⇒ больше».

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / СРАВНЕНИЕ ВЫРАЖЕНИЙ С НУЛЁМ: МЕТОД. Плашка: вариации 7.1–7.5.

КОНТЕНТ:
1. АЛГОРИТМ
- Оцени по рисунку примерные значения чисел (например, a ≈ 0,5 между 0 и 1; x ≈ −2, y ≈ 3).
- Подставь оценки в каждое из четырёх утверждений.
- Выбери то единственное, которое выполняется при любых допустимых положениях точек.

Врезка «Ловушка!»: Чётная степень «съедает» знак: xy² имеет знак x, а x²y — знак y. Не путай, какой множитель в квадрате.

Иллюстрация: таблица проверки четырёх утверждений с плюсами и минусами, верное — обведено зелёным.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / СРАВНЕНИЕ ВЫРАЖЕНИЙ С НУЛЁМ: РАЗБОР. Плашка: вариации 7.1–7.5.

КОНТЕНТ:
1. РАЗБОР 7.1
Условие: a между 0 и 1. Проверяем: a−5 <0 ✓ (a<1<5). Ответ: 1.
2. РАЗБОР 7.2
Условие: x < 0 < y (x левее нуля, y правее). Проверяем: xy² <0 ✓ (x<0, y²>0). Ответ: 2.
3. РАЗБОР 7.4
Условие: a < b < c на прямой. Положительна разность c−a (c правее a). Ответ: 2.
4. ЧТО НУЖНО ЗАПОМНИТЬ
- Работай оценками, точные значения не нужны.
- Проверяй ВСЕ четыре варианта — верный ровно один.

Иллюстрация: три мини-прямые с точками из разборов, стрелки сравнения.

## Тема 7-Б. Сравнение дробей / расположение дробей на прямой (вариации 7.6–7.13)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / ДРОБИ НА КООРДИНАТНОЙ ПРЯМОЙ: ТЕОРИЯ. Плашка: вариации 7.6–7.13.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 7.6/7.7 — сопоставить точку A/B/C/D числу (58/7 или −0,09 среди отрицательных десятичных).
- 7.8/7.9 — какая из дробей k/9 (или k/7) отмечена точкой A на шкале от 0 до 1.
- 7.10 — какая из дробей принадлежит отрезку [8; 9].
- 7.11 — между какими целыми заключено 160/11.
- 7.12 — какое число заключено между 8/3 и 11/4.
- 7.13 — какому промежутку принадлежит 2/7.
2. ТЕОРИЯ
- Чтобы понять положение дроби, выдели целую часть: 58/7 = 8 2/7 ⇒ между 8 и 9.
- Перевод в десятичную: раздели числитель на знаменатель (2/7 ≈ 0,2857).

Иллюстрация: шкала 7—8—9 с точкой 58/7 = 8 2/7 чуть правее 8.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / ДРОБИ НА КООРДИНАТНОЙ ПРЯМОЙ: МЕТОД. Плашка: вариации 7.6–7.13.

КОНТЕНТ:
1. АЛГОРИТМ
- Выдели целую часть дроби ИЛИ переведи её в десятичную с 1-2 знаками.
- Найди, между какими соседними делениями шкалы попадает число.
- Сопоставь с вариантами ответа или точками на рисунке.
2. ДЛЯ ЗАДАЧ ТИПА 7.12 («между 8/3 и 11/4»)
- Переведи обе границы в десятичные: 8/3 ≈ 2,667; 11/4 = 2,75.
- Ищи вариант строго между ними: 2,7 ✓.

Врезка «Ловушка!»: Для отрицательных чисел (7.7) порядок обратный: −0,93 < −0,39 < −0,09 < 0,03 — чем больше модуль, тем левее!

Иллюстрация: две шкалы — положительная и отрицательная, с подписями «порядок обратный» на отрицательной.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / ДРОБИ НА КООРДИНАТНОЙ ПРЯМОЙ: РАЗБОР. Плашка: вариации 7.6–7.13.

КОНТЕНТ:
1. РАЗБОР 7.11
160/11 = 14 6/11 ⇒ между 14 и 15. Ответ: 3.
2. РАЗБОР 7.8
Точка A на шкале 0–1 около 0,55. Проверяем дроби с знаменателем 9: 5/9 ≈ 0,56 ✓ (остальные — 11/9, 13/9, 14/9 — больше 1). Ответ: 1.
3. РАЗБОР 7.13
2/7 ≈ 0,286 ⇒ принадлежит [0,2; 0,3]. Ответ: 2.
4. ЧТО НУЖНО ЗАПОМНИТЬ
- Выделение целой части — самый быстрый приём.
- Дроби больше 1 не могут лежать на шкале от 0 до 1 — сразу отбрасывай лишние варианты.

Иллюстрация: три разобранные шкалы с отмеченными ответами.

## Тема 7-В. Сравнение квадратных корней (вариации 7.14–7.17)

### Карточка 1 из 3 — «Теория»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / КОРНИ НА КООРДИНАТНОЙ ПРЯМОЙ: ТЕОРИЯ. Плашка: вариации 7.14–7.17.

КОНТЕНТ:
1. ТИПЫ ВАРИАЦИЙ
- 7.14 — какой из корней √5, √6, √23, √31 принадлежит промежутку [5; 6].
- 7.15 — между какими целыми числами заключено √27.
- 7.16/7.17 — сопоставить точку A на шкале 5–7 одному из корней √29, √33, √39, √44 (или √28).
2. ТЕОРИЯ (формула в рамке)
- Для сравнения корня с целым числом возводи в квадрат: √27 между 5 и 6, потому что 25 < 27 < 36.
- √a < √b ⇔ a < b (для неотрицательных чисел).
- Полезно помнить квадраты: 5²=25, 6²=36, 7²=49, 8²=64.

Иллюстрация: числовая прямая 5–6–7 с «сеткой квадратов» 25–36–49 под ней и точкой √27.

### Карточка 2 из 3 — «Метод решения и ловушки»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / КОРНИ НА КООРДИНАТНОЙ ПРЯМОЙ: МЕТОД. Плашка: вариации 7.14–7.17.

КОНТЕНТ:
1. АЛГОРИТМ
- Возведи границы промежутка в квадрат: [5; 6] → [25; 36].
- Проверь, какое из подкоренных чисел попадает в этот интервал квадратов.
- Для точки на шкале — оцени положение точки (ближе к 5? к 6? к середине?), затем сравни с квадратами.

Врезка «Ловушка!»: Не пытайся извлекать корни приближённо вручную — быстрее и надёжнее сравнивать квадраты целых чисел с подкоренным выражением.

Иллюстрация: «мост» между прямой чисел и прямой их квадратов, стрелки соответствия.

### Карточка 3 из 3 — «Разбор вариаций»
ЗАГОЛОВОК: ОГЭ. ЗАДАНИЕ 7 / КОРНИ НА КООРДИНАТНОЙ ПРЯМОЙ: РАЗБОР. Плашка: вариации 7.14–7.17.

КОНТЕНТ:
1. РАЗБОР 7.14
[5;6] → квадраты [25;36]. Из чисел 5, 6, 23, 31 в интервал (25;36) попадает 31 ⇒ √31. Ответ: 4.
2. РАЗБОР 7.15
25 < 27 < 36 ⇒ 5 < √27 < 6. Ответ: 1 (между 5 и 6).
3. РАЗБОР 7.16
Точка A между 6 и 7, ближе к 6,5: квадраты 36–49, середина ≈ 42. √39 ≈ 6,2; √44 ≈ 6,6. Сопоставь с положением точки на рисунке (по банку — ответ √44, если точка правее середины).
4. ЧТО НУЖНО ЗАПОМНИТЬ
- Сравнение корней = сравнение подкоренных чисел.
- Держи в голове таблицу квадратов до 15².

Иллюстрация: прямая 5–7 с точками √29, √33, √39, √44 и их приближёнными значениями.
